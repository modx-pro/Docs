# Режимы и настройки

## Strict — предварительное согласие

Режим по умолчанию. Включённые необязательные сервисы запускаются, только когда посетитель разрешил **видимую** назначенную категорию. Для карты или видео до разрешения отображается заглушка; реального iframe ещё нет.

## Legacy — загрузка до первого выбора

Активируется опцией **«Показывать старую кнопку „Принять“»**. При первом посещении без сохранённого решения сервисы включённых видимых категорий могут загрузиться **до клика**. Кнопка «Принять» затем сохраняет разрешения для всех видимых необязательных категорий.

Legacy **не** создаёт фиктивное согласие: `getConsent()` остаётся `null` до решения, а Google Consent Mode не получает вымышленную команду разрешения. Сохранённые отказ, частичный выбор и устаревшие разрешения не обходятся.

::: danger
Legacy — не consent-first. Выбирайте его лишь после проверки применимых требований приватности.
:::

## Оформление баннера

Параметр `banner_position` поддерживает три значения:

| Значение | Вид |
| --- | --- |
| `bottom` | Полоса снизу, стандартный вариант |
| `bottom-right` | Компактная карточка справа снизу |
| `bottom-left` | Компактная карточка слева снизу |

Компактные карточки на узких экранах переходят к нижнему расположению. Переводимый заголовок необязателен: пустой заголовок не занимает места. Стили можно дополнительно переопределять в CSS темы сайта.

## Языки и тексты

Во вкладке **Тексты** задаются локализованные надписи баннера, кнопок, категорий, сервисов и сообщений для встроенного контента. При выводе используется `cultureKey` контекста MODX с резервным переводом. Для карт есть общий текст-заглушка и отдельные варианты для Google и Яндекса. Подстановка `{provider}` заменяется на локализованное имя сервиса.

Изменение только текста и оформления не должно автоматически сбрасывать действующие разрешения.

## Изменение состава категорий

`necessary` всегда обязательна. Пользователь выбирает из видимых категорий `analytics`, `marketing` и `external_content`. Включение или перенос сервиса может обновить версию **затронутой** категории — при следующем посещении она потребует новый выбор. При необходимости администратор может явно запросить повторное согласие **у всех**.

Дополнительно см. [сервисы и категории](services).
