# Сервисы и категории

## Категории

Посетитель разрешает **категории**, а не отдельные сервисы. `necessary` всегда включена; `analytics`, `marketing` и `external_content` можно показывать или скрывать независимо от наличия интеграций.

Администратор назначает любой встроенный сервис одной из необязательных категорий. Рекомендуемая категория — лишь начальная настройка. Подбирайте её по фактическому назначению и требованиям политики сайта.

## Готовые адаптеры

| Назначение | Интеграции |
| --- | --- |
| Аналитика | Яндекс.Метрика, Top.Mail.Ru, Google Analytics 4 |
| Теги и реклама | Google Tag Manager, Google Ads, VK Ads Pixel, Meta Pixel |
| Карты | Google Maps, Яндекс.Карты |
| Видео | YouTube, RUTUBE, VK Видео |
| Собственный код | Custom JavaScript (`custom_js`) |

Порядок: **Сервисы → Добавить сервис → выбрать адаптер → указать ID/параметры → назначить категорию → включить → Сохранить**.

Можно создать дополнительные экземпляры встроенного сервиса с отдельными ключами, например `youtube_help`. Установленные галочки видимости категорий не заменяют переключатель включения конкретного сервиса.

## Собственный JavaScript

Разместите файл на сайте:

```text
/assets/js/integrations/company-widget.js
```

В Manager выберите **«Создать пользовательский сервис»**, задайте название, назначение, категорию и путь. Допустимы локальный URL от корня сайта или полный HTTPS URL на `.js` с допустимыми query-параметрами.

В Strict файл загружается только после разрешения назначенной категории. Не дублируйте его другим `<script>` в шаблоне. Сам файл не собирается вместе со встроенными адаптерами.

::: warning
Custom JS исполняется с обычными правами JavaScript страницы. Проверку безопасности исходника, CSP, внешних зависимостей и поведения после отзыва разрешения выполняет разработчик сайта.
:::

## Google Consent Mode v2 и GTM

Компонент передаёт сигналы Google Consent Mode v2 с учётом сохранённых категорий и режима. Однако **GTM не блокирует произвольные теги автоматически**: для GA4, Google Ads и Custom HTML внутри контейнера настройте соответствующие consent checks. В Legacy до первоначального решения компонент не подменяет выбор посетителя искусственным `granted`.

Для подключения самостоятельных модулей через API см. [JavaScript API](api).
