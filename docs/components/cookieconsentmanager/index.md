# Cookie Consent Manager

**Cookie Consent Manager** управляет разрешениями посетителя и загрузкой подключённых через него сторонних сервисов: аналитики, рекламных пикселей, JavaScript, видео и карт.

Компонент предоставляет панель настройки, готовые интеграции, механизм отложенного встраивания, публичный JavaScript API и журнал согласий. Работает на самом сайте без обязательной внешней CMP-платформы.

## Возможности

- Режимы **Strict** (загрузка после согласия) и **Legacy** (загрузка до первого выбора — только при отсутствии сохранённого решения).
- Три расположения баннера: снизу, справа снизу и слева снизу; на небольших экранах компактные варианты превращаются в нижнюю плашку.
- Переводимые заголовки, кнопки, категории, описания, сервисы и сообщения заглушек; RU/EN из коробки.
- Назначение сервиса любой видимой необязательной категории; дополнительные экземпляры и собственные JavaScript-сервисы.
- Видео YouTube, RUTUBE, VK Видео; Google Maps, Яндекс.Карты; доверенные HTML-встраивания через `<template>`.
- Редактируемые JS-адаптеры с сохранением пользовательских изменений при обновлении и сборкой в один минифицированный файл в админке.
- Журнал согласий (JSONL), просмотр, фильтрация и экспорт CSV.

## Совместимость и статус

Документация охватывает две самостоятельные версии компонента. Для каждой используется свой transport-пакет:

| Платформа | Пакет | Поддерживаемые версии MODX |
| --- | --- | --- |
| MODX 2 | `cookieconsentmanager-1.0.8-pl5` | `>=2.8.4,<3.0.0` |
| MODX 3 | `cookieconsentmanager3-1.0.8-pl7` | `>=3.1.2,<3.3.0` |


Требование к PHP для обеих версий — 8.1+. Совместимость проверена на PHP 8.1/8.2: для MODX 2 — на 2.8.4 и 2.8.8 с отдельной проверкой API промежуточных выпусков; для MODX 3 — на 3.1.2 и 3.2.4; диапазон совместимости ограничен версиями ниже 3.3.0.

::: warning Правовые требования
В Strict компонент откладывает только интеграции, подключённые через его механизмы. Legacy может запускать сторонний код до согласия. Сам по себе компонент не гарантирует соответствие GDPR и другим нормам: это зависит от режима, текстов, сервисов и законодательства.
:::
