# Журнал согласий

Компонент может сохранять события выбора посетителей в **ежемесячные JSONL-файлы** на сервере сайта. Через Manager доступны список, поиск/фильтры, детали и экспорт CSV.

## Настройка

На вкладке **Настройки** задайте путь к каталогу журнала. Предпочтителен каталог, доступный PHP для чтения/записи, но **недоступный по HTTP**, особенно если `core` расположен в публичном дереве сайта.

```text
/var/www/private/cookie-consent-logs/
```

Путь в примере условный: укажите реальный абсолютный путь на сервере. Не вводите публичный URL. Если журналы лежат внутри `core/cache/`, осторожно очищайте кеш вручную: можно удалить и историю согласий.

## Что сохраняется

Среди данных могут быть тип события, категории, серверное время, идентификатор события, технические сведения о браузере/IP и путь страницы (`location.pathname`). **Query-параметры и hash страницы намеренно не записываются** в поле пути. Структура реальных событий зависит от версии схемы: старые записи 1/2 остаются читаемыми, новые категорийные используют schema 3.

::: warning
Журнал содержит потенциально персональные данные. Обеспечьте защиту папки, ограничение доступа, политику хранения и резервное копирование согласно требованиям сайта. Экспорт CSV требует соответствующих прав в Manager.
:::

При штатной деинсталляции журнала согласий автоматически **не удаляются**; сохраните или удалите их отдельно по своей политике хранения. Подробнее: [удаление и переустановка](uninstall).

## Как проверить журнал

1. В приватном окне измените согласие и запишите время события.
2. В Network найдите POST аудита и успешный ответ сервера (`event_id`).
3. Откройте **Журнал согласий** и найдите событие по фильтрам или времени.
4. Сверьте событие с физическим файлом журнала нужного месяца.

Наличие настроенного каталога или успешная отрисовка баннера **не доказывает**, что браузерный POST действительно дошёл до сервера. При `400` проверьте данные и актуальность HTML/JS, при `403` — Origin/права, при `503` — каталог и серверную конфигурацию.

Доступ к журналу может быть выдан отдельно от права изменять настройки компонента.
