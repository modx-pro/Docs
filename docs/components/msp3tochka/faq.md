# FAQ

## Ошибка связи с банком

Сайт `enter.tochka.com` открывается по сертификату Минцифры. В обычном наборе сертификатов PHP этого центра нет, поэтому запрос падает с текстом `Payment provider HTTP error`.

Пакет уже подставляет файл `certs/russian_trusted.pem`. Скачивать его не нужно.

Если ошибка остаётся и сайт ходит в банк в обход пакета, укажите этот файл в `openssl.cafile` в настройках PHP.

## Нет номера операции

После создания ссылки номер операции банка должен сохраниться у попытки оплаты. Если пакет старый, переустановите 1.0.0-pl. Синхронизация, списание холда и возврат без этого номера в банк не ходят.

## Уведомление не привязалось к заказу

В песочнице ответ банка часто без номера ссылки. Пакет тогда читает номер из токена уведомления. Если проверка подписи включена (`msp3tochka_webhook_verify_jwt` = Да), а тело уведомления не токен банка, пакет запрос отклонит.

Уведомление в песочнице пройдёт, только если сумма заказа 100 ₽. Учебный ответ банка говорит, что оплачено именно 100 ₽.

## 403 Forbidden by consent

У токена нет права на эту пару кода компании и торговой точки. Перевыпустите его с правами `MakeAcquiringOperation` и `ReadAcquiringData`.

## Настройки в админке есть, API их не видит

Кеш системных настроек. **Управление → Очистить весь кеш**.
