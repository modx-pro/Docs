# Горячие клавиши

В таблицах **Mod** означает `Ctrl` в Windows/Linux и `Cmd` (`⌘`) в macOS. **Alt** на Mac - это `Option` (`⌥`). Для буквенных команд, где macOS подставляет символы вместо букв, CMX использует отдельные сочетания без Option.

Полная шпаргалка также находится в файле [COMMANDS.md](https://github.com/vitos88/Cmx/blob/main/COMMANDS.md) репозитория.

## CMX и MODX

| Действие | Windows / Linux | macOS |
| --- | --- | --- |
| Сохранить форму MODX | `Ctrl+S` | `Cmd+S` |
| Палитра команд | `Ctrl+Shift+P` | `Cmd+Shift+P` |
| Автодополнение | `Ctrl+Space` | `Ctrl+Space` |
| Выровнять документ или выделение | `Shift+Alt+F` | `Cmd+Shift+F` |
| Перейти к элементу из MODX-тега | `Ctrl` + клик | `Cmd` + клик |
| Выделить строку | Клик по её номеру | Клик по её номеру |
| Выделить диапазон строк | Протягивание по номерам | Протягивание по номерам |

Палитра элементов открывается кнопкой `{ }`, история - кнопкой с часами, быстрые настройки - шестерёнкой. Полноэкранный режим включается кнопкой на панели; `Esc` возвращает обычный размер.

## Основные команды

| Действие | Windows / Linux | macOS |
| --- | --- | --- |
| Отменить | `Ctrl+Z` | `Cmd+Z` |
| Повторить | `Ctrl+Y` или `Ctrl+Shift+Z` | `Cmd+Shift+Z` |
| Выделить всё | `Ctrl+A` | `Cmd+A` |
| Найти и заменить | `Ctrl+F` | `Cmd+F` |
| Перейти к строке | `Ctrl+Alt+G` | `Ctrl+G` |
| Комментарий | `Ctrl+/` | `Cmd+/` |
| Блочный комментарий | `Shift+Alt+A` | `Shift+Ctrl+A` |
| Увеличить отступ | `Tab` или `Ctrl+]` | `Tab` или `Cmd+]` |
| Уменьшить отступ | `Shift+Tab` или `Ctrl+[` | `Shift+Tab` или `Cmd+[` |
| Автоматический отступ выделения | `Ctrl+Alt+\` | `Cmd+Alt+\` |
| Перейти к парной скобке | `Ctrl+Shift+\` | `Cmd+Shift+\` |
| Разрешить Tab переводить фокус | `Ctrl+M` | `Shift+Ctrl+M` |

Если перед курсором Emmet-аббревиатура, `Tab` сначала разворачивает её.

## Строки

| Действие | Windows / Linux | macOS |
| --- | --- | --- |
| Новая строка с автоматическим отступом | `Enter` или `Shift+Enter` | `Enter` или `Shift+Enter` |
| Вставить пустую строку | `Ctrl+Enter` | `Cmd+Enter` |
| Переместить строку/выделение вверх или вниз | `Alt+↑` / `Alt+↓` | `Alt+↑` / `Alt+↓` |
| Скопировать строку/выделение вверх или вниз | `Shift+Alt+↑` / `Shift+Alt+↓` | `Shift+Alt+↑` / `Shift+Alt+↓` |
| Удалить строку | `Ctrl+Shift+K` | `Cmd+Shift+K` |
| Удалить предыдущее слово | `Ctrl+Backspace` | `Alt+Backspace` |
| Удалить следующее слово | `Ctrl+Delete` | `Alt+Delete` |
| Удалить до начала строки | - | `Cmd+Backspace` |
| Удалить до конца строки | - | `Cmd+Delete` |

## Навигация и выделение

Добавление `Shift` к командам перемещения расширяет выделение.

| Действие | Windows / Linux | macOS |
| --- | --- | --- |
| По словам | `Ctrl+←` / `Ctrl+→` | `Alt+←` / `Alt+→` |
| По синтаксическим узлам | `Alt+←` / `Alt+→` | `Ctrl+←` / `Ctrl+→` |
| Начало / конец строки | `Home` / `End` | `Home` / `End` или `Cmd+←` / `Cmd+→` |
| Начало / конец документа | `Ctrl+Home` / `Ctrl+End` | `Cmd+↑` / `Cmd+↓` |
| Выделить текущую строку | `Alt+L` | `Ctrl+L` |
| Выделить родительский узел | `Ctrl+I` | `Cmd+I` |
| Свернуть мультивыделение | `Esc` | `Esc` |

## Мультикурсоры

| Действие | Windows / Linux | macOS |
| --- | --- | --- |
| Курсор строкой выше / ниже | `Ctrl+Alt+↑` / `Ctrl+Alt+↓` | `Cmd+Alt+↑` / `Cmd+Alt+↓` |
| Следующее вхождение слова или выделения | `Ctrl+D` | `Cmd+D` |
| Все вхождения выделения | `Ctrl+Shift+L` | `Cmd+Shift+L` |
| Прямоугольное выделение | `Alt` + протягивание | `Alt` + протягивание |
| Отменить последнее изменение выделения | `Ctrl+U` | `Cmd+U` |
| Повторить отменённое изменение выделения | `Alt+U` | `Cmd+Shift+U` |

## Поиск и автодополнение

| Действие | Сочетание |
| --- | --- |
| Открыть поиск | `Mod+F` |
| Следующее совпадение | `F3` или `Mod+G` |
| Предыдущее совпадение | `Shift+F3` или `Shift+Mod+G` |
| Применить вариант автодополнения | `Enter` при открытом списке |
| Закрыть список | `Esc` |
| Развернуть Emmet | `Tab` |

## Sublime и Vim

При `cmx.keymap = sublime` сохраняются стандартные команды, а текущая строка дополнительно выделяется через `Ctrl+L` / `Cmd+L`.

При `cmx.keymap = vim` доступны Normal, Insert, Visual и Visual Line, операторы, движения, регистры и макросы:

| Действие | Команда |
| --- | --- |
| Insert | `i`, `a`, `o`, `O` |
| Normal | `Esc` |
| Перемещение | `h`, `j`, `k`, `l`, `w`, `b`, `e`, `0`, `^`, `$`, `gg`, `G` |
| Visual / Visual Line | `v` / `V` |
| Удалить символ / строку | `x` / `dd` |
| Скопировать строку | `yy` |
| Вставить после / перед курсором | `p` / `P` |
| Отменить / повторить | `u` / `Ctrl+R` |
| Поиск | `/`, затем `n` и `N` |
| Макрос | `q` + регистр для записи, `@` + регистр для выполнения |
