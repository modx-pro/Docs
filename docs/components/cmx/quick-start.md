# Быстрый старт

## Шаг 1. Установка

1. Установите **CMX** через **Пакеты → Управление пакетами** ([обзор](index#установка))
2. Убедитесь, что плагин **CMX** активен
3. Обновите страницу менеджера; при необходимости очистите кэш MODX и браузера

## Шаг 2. Редактор для элементов

`which_element_editor` = **cmx**.

Откройте сниппет, чанк, шаблон или плагин: стандартное поле кода станет редактором CMX с подсветкой и панелью инструментов.

Чтобы временно вернуть другой редактор, измените значение `which_element_editor`. Удалять CMX для этого не требуется.

## Шаг 3. Код в ресурсах

Учитываются **контекстные** значения `use_editor` и `which_editor`, а также свойство ресурса `richtext`:

| Цель | Настройки |
| --- | --- |
| CMX в поле content у всех ресурсов | `use_editor = Нет`. Тогда же заменяются textarea с классом `modx-richtext` |
| CMX только у ресурсов без richtext | `use_editor = Да`, `which_editor` пустой или `cmx`, richtext выключен |
| TinyMCE / другой RTE | `use_editor = Да`, `which_editor` не `cmx`, у ресурса включён richtext |
| Textarea без CMX | `use_editor = Да`, `which_editor` не `cmx`, richtext выключен |

Подробнее: [Интеграция](integration#ресурсы-и-rte).

## Шаг 4. Проверка

1. Откройте сниппет: должна появиться подсветка PHP
2. В HTML-шаблоне введите `[[` и дождитесь списка элементов или нажмите **Ctrl+Space**
3. Нажмите **Ctrl+Shift+P** / **Cmd+Shift+P**: откроется палитра команд
4. Удерживая **Ctrl** / **Cmd**, нажмите на имя существующего сниппета: оно откроется в новой вкладке
5. Откройте настройки через кнопку с шестерёнкой и выберите тему

## Чеклист

- [ ] `which_element_editor = cmx`
- [ ] Сниппеты и чанки открываются в CMX
- [ ] Для ресурсов настроена связка `use_editor` / `which_editor` под вашу схему
- [ ] Автодополнение `cmx.autocomplete` включено
- [ ] Тема и размер шрифта выбраны в быстром меню или namespace `cmx` ([настройки](settings))
