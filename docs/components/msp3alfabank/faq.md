# FAQ

## Payment is not configured

Пустые логин или пароль. Публичного демо нет. Нужны логин с суффиксом `-api` и пароль из письма банка.

Проверьте properties способа, затем системные настройки, затем кеш.

## Нет номера платежа банка

После создания ссылки номер платежа банка должен сохраниться у попытки оплаты. Если пакет старый, переустановите 1.0.0-pl. Списание, возврат и отмена холда без этого номера в банк не ходят.

## Webhook 401

Обработчик без логина и пароля колбэк не принимает. Заполните **`msp3alfabank_user_name`** и **`msp3alfabank_password`** и очистите кеш.

Адрес в кабинете:

```text
https://ваш-домен.ru/assets/components/msp3alfabank/webhook.php
```

HTTPS без 301.

## Логин `r-` не проходит на pay.alfabank.ru

Задайте **`msp3alfabank_api_base_url`** = `https://payment.alfabank.ru/payment/rest/`. При **`msp3alfabank_test_mode`** = Нет пакет иначе ходит на `https://pay.alfabank.ru/payment/rest/`.

## Настройки есть, создание платежа их не видит

Кеш системных настроек. **Управление → Очистить весь кеш**.
