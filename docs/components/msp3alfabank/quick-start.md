# Быстрый старт

Как принять первый платёж через Альфа-Банк на сайте с MiniShop3.

## Требования

| Требование | Версия |
| --- | --- |
| MODX Revolution | 3.0+ |
| MiniShop3 | 1.14.0-beta1 и новее |
| PHP | 8.2+ |
| Доступ | логин с суффиксом `-api` и пароль из письма банка |
| Сайт | HTTPS на webhook без 301 |

Публичного демо-кабинета в документации банка нет. Настоящей картой в тесте заплатить нельзя. Тестовые карты смотрите в [документации эквайринга](https://alfabank.ru/sme/payservice/internet-acquiring/docs/documentation/).

## Шаг 1: Провайдер modstore и установка пакета

1. **Система → Управление пакетами → Провайдеры** → добавьте **modstore.pro**:
   - URL: `https://modstore.pro/extras/`
   - Email и API-ключ из личного кабинета modstore.pro
2. Убедитесь, что установлен **MiniShop3**.
3. **Управление пакетами** → установите **msp3AlfaBank** (в **Show Details** укажите провайдер **modstore.pro**).
4. **Управление → Очистить кэш**.

Резолвер создаёт два активных способа. Старый `mspAlfaBank`, если он уже стоит, не удаляется.

| Название | Класс |
| --- | --- |
| Оплата через Альфа-Банк | `Msp3AlfaBank\Payment\AlfaBankPayment` |
| Оплата через Альфа-Банк (двухстадийная) | `Msp3AlfaBank\Payment\AlfaBankTwoStagePayment` |

## Откуда брать ключи {#откуда-брать-ключи}

Логин и пароль выдаёт банк в письме после подключения эквайринга. В MODX нужен логин с суффиксом **`-api`**, не логин для входа человека в кабинет.

Это поля **`msp3alfabank_user_name`** и **`msp3alfabank_password`**. В properties способа те же значения можно положить как `user_name` или `login` и `password` или `secret`. Непустые properties перекрывают системные настройки.

Адрес шлюза пакет выбирает по **`msp3alfabank_test_mode`**:

| Режим | Адрес |
| --- | --- |
| Да, тест | `https://alfa.rbsuat.com/payment/rest/` |
| Нет, бой | `https://pay.alfabank.ru/payment/rest/` |

Если логин начинается с `r-` и бой на `pay.alfabank.ru` не проходит, задайте **`msp3alfabank_api_base_url`**: `https://payment.alfabank.ru/payment/rest/`. Непустое поле перекрывает адрес из таблицы.

## Шаг 2: Куда вписать в MODX

1. **Настройки → Системные настройки**, фильтр **`msp3alfabank`**.
2. Для теста: **`msp3alfabank_test_mode`** = Да, логин и пароль из письма.
3. После сохранения: **Управление → Очистить весь кеш**.

Список полей: [Системные настройки](settings).

## Шаг 3: URL колбэка

В кабинете банка укажите тот же адрес, который пакет передаёт при создании платежа:

```text
https://ваш-домен.ru/assets/components/msp3alfabank/webhook.php
```

HTTPS без 301. Без логина и пароля этот адрес отвечает `401` и колбэк не принимает.

## Шаг 4: Способ оплаты в MiniShop3

1. В админке MiniShop3 откройте **Настройки → Оплаты**.
2. Включите **Оплата через Альфа-Банк** или **Оплата через Альфа-Банк (двухстадийная)**.
3. Привяжите способ к доставке.

Если рядом стоит старый `mspAlfaBank`, выключите его. Адрес колбэка сменится на новый `webhook.php`. Подробнее: [Переход](integration#переход-со-старого-mspalfabank).

## Шаг 5: Боевой режим

1. Боевые логин и пароль.
2. **`msp3alfabank_test_mode`** = Нет. Хост по умолчанию: `https://pay.alfabank.ru/payment/rest/`.
3. Для логина с префиксом `r-` часто нужен **`msp3alfabank_api_base_url`** = `https://payment.alfabank.ru/payment/rest/`.
4. Пропишите колбэк из [шага 3](#шаг-3-url-колбэка).
5. Контрольный платёж на небольшую сумму.
6. Выключите **`msp3alfabank_debug`**.

Холд не делает заказ оплаченным, пока не спишете его во вкладке заказа.
