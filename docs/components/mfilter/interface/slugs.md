# Алиасы

Алиас (слаг) — запись значения фильтра в SEO-адресе: «Красный» → `krasnyj`, адрес раздела — `/catalog/color--krasnyj/`. Алиасы хранятся на вкладке **Алиасы**.

## Когда появляется алиас

mFilter создаёт алиас сам, когда значение впервые выводится в фильтре или попадает в адрес. Ещё алиасы создаёт кнопка [**Сгенерировать**](#sgenerirovat).

### Значения без алиаса

Эти значения уходят в адрес как есть:

- **числа**, кроме номеров производителей и разделов;
- **даты** вида `2026-11` или `2026-11-01`;
- **новые значения**, если выключена настройка `mfilter.slugs_auto_generate`, — см. [настройки алиасов](../settings#slagi).

## Как строится алиас

Алиас строится из значения фильтра. Исключение — производители и разделы: их значение — номер, а алиас строится из названия.

1. Кириллица переводится в латиницу.
2. Буквы — в нижний регистр.
3. Пробелы и подчёркивания — в дефис, остальные символы удаляются.
4. Повторяющиеся дефисы схлопываются, дефисы по краям убираются.

| Значение | Алиас |
|----------|-------|
| Apple Inc. | `apple-inc` |
| Красный | `krasnyj` |
| 16 ГБ | `16-gb` |
| Black/White | `blackwhite` |

Если от значения ничего не осталось, алиас — `item-` и восемь символов хеша. Если алиас уже занят другим значением, mFilter разводит их сам — см. [совпадение алиасов](../settings#konflikty-slagov).

## Таблица алиасов

| Колонка | Описание |
|---------|----------|
| **ID** | Номер записи |
| **Фильтр** | Ключ фильтра |
| **Значение** | Значение фильтра. У производителей и разделов — номер |
| **Slug** | Алиас |
| **Источник** | Откуда взялся алиас. На работу не влияет |
| **Статус** | Активен / Выключен — флажок «Активен» в окне алиаса. Выключенный алиас не распознаётся в адресе |
| **Действия** | Изменить, удалить |

Над таблицей — список «Все фильтры» (показать алиасы одного ключа), «Все источники» и поиск. Поиск идёт только по значению, поэтому производителей и разделов по названию не найти — выберите их ключ в «Все фильтры».

## Изменение алиаса

1. Нажмите карандаш в строке.
2. Поменяйте поле **Slug**. Ключ фильтра и значение в окне заблокированы.
3. Нажмите **Сохранить**. Занятый алиас mFilter не сохранит и покажет, у какого значения он уже есть.

Больше mFilter ничего не проверяет, поэтому пишите алиас латиницей, цифрами и дефисами. Не используйте разделитель значений — по умолчанию `-or-`, настройка `mfilter.values_separator`: им в адресе разделяются несколько значений одного фильтра.

Исправленный алиас генерация уже не перепишет.

::: warning Старый адрес перестанет открываться
Новый алиас меняет адрес страницы фильтра, а старый отдаёт 404. Перенаправление со старого адреса mFilter не делает — настройте его на сервере. Индивидуальные SEO-записи от алиаса не зависят и продолжают работать.
:::

## Добавление алиаса

Кнопка **Добавить алиас** нужна для значения, которое ещё ни разу не выводилось. Обязательны поля **Ключ фильтра**, **Значение** и **Slug**. Поле **Язык**:

- пустое — алиас для всех языков;
- с кодом языка, например `en`, — только для контекстов с этим языком.

## Удаление алиасов

- **Корзина в строке** удаляет один алиас.
- **Очистить** удаляет все алиасы, а если в «Все фильтры» выбран ключ — все алиасы этого ключа. Поиск и «Все источники» при этом не учитываются.

Удалённый алиас создаётся заново, когда значение снова выведут в фильтре, — уже по правилам транслитерации. Если алиас исправляли вручную, правка пропадёт, а адрес изменится. Если выключена `mfilter.slugs_auto_generate`, алиас не вернётся.

## Сгенерировать

Кнопка **Сгенерировать** создаёт недостающие алиасы для страниц, привязанных к активным наборам фильтров. Существующие алиасы, в том числе исправленные вручную, она не трогает. Кэш mFilter не очищает — это делают кнопка [«Переиндексация»](maintenance) и задача [`mfl_reindex_slugs`](scheduler#mfl_reindex_slugs).

## Алиасы в адресе

Ключ и значение по умолчанию разделяются `--`, несколько значений — `-or-`:

```
/catalog/vendor--apple/color--krasnyj-or-sinij/
```

Разделители меняются в [настройках URL](../settings#url). С [паттерном](patterns) ключ из адреса можно убрать:

```
/catalog/apple/krasnyj/
```

## Программный доступ

Методы `SlugManager` — в разделе [Сервисы](../development/services#slugmanager).
