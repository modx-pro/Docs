# Интерфейс админки

Админка mFilter открывается в **Пакеты → mFilter**. Нужен установленный пакет VueTools — без него вкладки не загрузятся.

## Права доступа

Менеджеру без флага sudo нужны два права, и пакет их не создаёт:

- `mfilter.view` — пункт меню;
- `mfilter` — запросы админки.

Добавьте их в шаблон политики доступа, создайте по нему политику и назначьте её группе пользователей в контексте `mgr`.

Над вкладками — шапка: версия, счётчики наборов, алиасов, словоформ, конфигураций прогрева и строк индекса фасетов, кнопка [«Переиндексация»](maintenance#knopka-pereindeksaciya-v-shapke). Поиск и листание есть на вкладках «Алиасы», «Индивидуальные SEO» и «Словоформы».

Фоновые задачи mFilter находятся в самом Scheduler — см. [Scheduler-задачи](scheduler).

## Порядок настройки

1. На вкладке **Наборы фильтров** нажмите **Добавить набор**, введите название, кнопкой **Добавить фильтр** добавьте фильтры и отметьте разделы в **Страницах каталога**.
2. Если кнопка в шапке называется **Построить индекс**, нажмите её — без индекса фасетов фильтры работают медленнее.
3. Необязательно: поправьте алиасы на вкладке **Алиасы**. Они появляются, когда раздел открывают на сайте, или по кнопке **Сгенерировать** — см. [Алиасы](slugs#kogda-poyavlyaetsya-alias).
4. Необязательно: на вкладке **SEO шаблоны** создайте SEO-шаблоны для разных комбинаций фильтров и укажите условия применения.

Пошаговая настройка — в [Быстром старте](../quick-start).
