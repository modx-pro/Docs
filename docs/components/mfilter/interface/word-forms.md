# Словоформы

Вкладка хранит падежи слов для SEO-шаблонов. `{$made_in.gen}` выводит «Германии», если для слова «Германия» есть словоформа. Без словоформы выводится само значение, без ошибки.

## Как вывести падеж

Падеж пишется модификатором через точку после ключа фильтра или поля страницы: `{$made_in.gen}`, `{$pagetitle.gen}`.

| Модификатор | Падеж | Значение «Германия» |
|---|---|---|
| `.nom` | Именительный | Германия |
| `.gen` | Родительный | Германии |
| `.dat` | Дательный | Германии |
| `.acc` | Винительный | Германию |
| `.ins` | Творительный | Германией |
| `.pre` | Предложный | Германии |

Множественное число — те же модификаторы с `_plural`: `{$made_in.gen_plural}`.

```
Товары из {$made_in.gen} — купить в {$site_name}
```

Склоняется одно значение: при нескольких выбранных берите первое, `{$made_in_first.gen}`. Остальные плейсхолдеры и модификаторы — в [SEO шаблонах](seo-templates#modifikatory).

## Таблица словоформ

Столбцы: «Слово», именительный и остальные пять падежей единственного числа. Формы множественного числа видны только в форме правки.

| Кнопка | Что делает |
|--------|------------|
| **Добавить** | Открывает форму новой словоформы, см. [Создание словоформы](#sozdanie-slovoformy) |
| **Генерировать** | Заводит словоформу одного слова через morpher.ru, см. [Генерация](#generaciya) |
| **Пакетная генерация** | Заводит словоформы для значений из алиасов |
| **Удалить (N)** | Удаляет отмеченные строки |
| **Очистить всё** | Удаляет все словоформы. Отменить нельзя |

Поиск находит словоформы по части слова. Сортировать можно только по столбцу «Слово».

## Создание словоформы

Нажмите «Добавить», заполните поля и сохраните. Обязательны «Слово» и «Именительный».

**Слово** — то, что стоит в значении фильтра или поле страницы: название цвета, страны, раздела. По нему ищется словоформа, регистр букв при поиске не важен. Изменить «Слово» после сохранения нельзя.

| Падеж | Единственное число | Множественное число |
|-------|--------------------|---------------------|
| Именительный | телефон | телефоны |
| Родительный | телефона | телефонов |
| Дательный | телефону | телефонам |
| Винительный | телефон | телефоны |
| Творительный | телефоном | телефонами |
| Предложный | телефоне | телефонах |

::: warning Заполните все падежи
Незаполненный падеж выводится пустым — исходное слово не подставится. Если у слова «Германия» заполнен только родительный, `{$made_in.dat}` выведет пустоту. Заполните все падежи, в том числе множественного числа.
:::

Словоформа общая: она действует для любого фильтра и поля страницы с этим словом. Для `{$pagetitle.gen}` заводите заголовок страницы целиком.

Несклоняемые названия — Apple, Samsung — заводить не нужно: без словоформы они выводятся как есть.

## Генерация

Словоформы генерируют кнопки «Генерировать» и «Пакетная генерация» через сервис morpher.ru, ключ задаётся в [настройках](../settings#slovoformy). При показе страницы формы не создаются.

- **Пакетная генерация** берёт слова из значений алиасов и пропускает слова, у которых словоформа уже есть. У производителей и разделов в значениях алиасов идентификаторы, а не названия — их словоформы заводите вручную.
- **Генерировать** не меняет существующую словоформу.
- Без флажка «Использовать morpher.ru API» во все падежи записывается само слово.

::: warning Проверьте сгенерированные словоформы
Генерация записывает слово строчными: после неё `{$made_in.nom}` выведет «германия». Если сервис не ответил — исчерпан лимит, нет сети, неверный ключ, — во всех падежах окажется само слово, а ошибки генерация не покажет. После генерации проверьте таблицу и поправьте словоформы вручную.
:::
