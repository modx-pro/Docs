# Словоформы

Словоформы обеспечивают склонение слов в SEO-текстах.

## Назначение

Русский язык требует склонения слов по падежам:

| Падеж | Пример |
|-------|--------|
| Именительный | телефон |
| Родительный | телефон**а** |
| Дательный | телефон**у** |
| Винительный | телефон |
| Творительный | телефон**ом** |
| Предложный | телефон**е** |

## Таблица словоформ

| Столбец | Описание |
|---------|----------|
| **Слово** | Именительный падеж |
| **Родительный** | Форма родительного падежа |
| **Дательный** | Форма дательного падежа |
| **Винительный** | Форма винительного падежа |
| **Творительный** | Форма творительного падежа |
| **Предложный** | Форма предложного падежа |
| **Множественное** | Форма множественного числа |

## Создание словоформы

### 1. Нажмите «Создать»

### 2. Заполните формы

| Поле | Пример |
|------|--------|
| **Слово** | телефон |
| **Родительный** | телефона |
| **Дательный** | телефону |
| **Винительный** | телефон |
| **Творительный** | телефоном |
| **Предложный** | телефоне |
| **Множественное** | телефоны |

### 3. Сохраните

## Использование в SEO-шаблонах

Падеж пишется модификатором через точку после ключа фильтра или поля страницы: `{$made_in.gen}`, `{$pagetitle.gen}`.

| Модификатор | Падеж | Значение «Германия» |
|---|---|---|
| `.nom` | Именительный | Германия |
| `.gen` | Родительный | Германии |
| `.dat` | Дательный | Германии |
| `.acc` | Винительный | Германию |
| `.ins` | Творительный | Германией |
| `.pre` | Предложный | Германии |

Множественное число — те же модификаторы с `_plural`: `{$made_in.gen_plural}`.

```
Товары из {$made_in.gen} — купить в {$site_name}
```

Если слова нет в таблице словоформ, подставится значение как есть — без ошибки. Склоняется одно значение: при нескольких выбранных берите первое, `{$made_in_first.gen}`. Остальные плейсхолдеры и модификаторы — в [SEO шаблонах](seo-templates#modifikatory).

## Автоматическое склонение

Если словоформа не найдена в базе, система попытается:

1. Использовать слово без изменений
2. Применить базовые правила русского языка (если включено)

## Программный доступ

```php
$mfilter = $modx->services->get('mfilter');
$wordForms = $mfilter->getWordFormsManager();

// Получить форму
$genitive = $wordForms->getForm('телефон', 'genitive');
// 'телефона'

// Проверить наличие
$exists = $wordForms->hasWord('телефон');

// Добавить словоформу
$wordForms->add([
    'word' => 'ноутбук',
    'genitive' => 'ноутбука',
    'dative' => 'ноутбуку',
    'accusative' => 'ноутбук',
    'instrumental' => 'ноутбуком',
    'prepositional' => 'ноутбуке',
    'plural' => 'ноутбуки'
]);
```

## Советы

1. **Добавляйте бренды** — Samsung, Apple, Xiaomi обычно не склоняются
2. **Добавляйте категории** — телефон, планшет, ноутбук
3. **Проверяйте результат** — просмотрите сгенерированные тексты
4. **Используйте импорт** — для большого количества слов

## Частые случаи

### Несклоняемые слова

Для иностранных брендов заполните все формы одинаково:

| Поле | Значение |
|------|----------|
| Слово | Apple |
| Родительный | Apple |
| Дательный | Apple |
| ... | Apple |

### Слова с чередованием

| Слово | день |
| Родительный | дня |
| Дательный | дню |
| Винительный | день |
| Творительный | днём |
| Предложный | дне |
