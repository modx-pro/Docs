# Категории и фильтры

## Категории

![Вкладка «Категории» ms3YandexMarket](/components/ms3yandexmarket/screenshots/categories.png)

Флажок слева включает раздел. У включённого раздела появляются флажок **Исключена** и поле **Своё название**. При назначении `placement` этой вкладки нет.

**Сохранить** в шапке карточки пишет флажки и своё название. До этого предпросмотр категорий показывает прошлый сохранённый набор.

Без отметок в выборке все опубликованные товары контекста `web` (`context_key` в `shop_settings`, пустая строка = `web`). `<categories>` пуст, пока не выбраны корни.

Отметка «нужно сгенерировать» и выборка файла смотрят на родителя ресурса и связи товара с разделами. Товар с выбранным разделом только в родителе отмечается и попадает в файл.

Ключ `include_unpublished` в JSON `shop_settings` (в форме нет). Пусто или ложь: в `<categories>` только опубликованные неудалённые разделы. `true` добавляет снятые с публикации. Товары в файле с `published` = `1`. Ключ их не сужает.

Исключённая категория убирает свою ветку. Если все отмеченные категории исключены, в прайс не попадает ни один товар.

Своё название подменяет имя в XML и не меняет ресурс MODX.

## Фильтры

![Форма условия фильтра ms3YandexMarket](/components/ms3yandexmarket/screenshots/filters.png)

Оба списка условий сужают одни и те же товары. **Магазин** пишет условия с `target` = `resource`. **Предложения** пишет с `target` = `offer`. Компонент читает всю таблицу условий и не смотрит на `target`.

Кнопки условий пишут только таблицу `ms3yandexmarket_conditions`. Генерация добавляет строки из JSON `filters.conditions` карточки и отбрасывает повтор «поле, оператор, значение». Новое условие в JSON само не копируется.

Поле условия задаётся как `источник.ключ`: `resource.pagetitle`, `data.price`, `tv.имя`, `option.ключ`.

| Оператор | Когда значение нужно |
| --- | --- |
| `=` `!=` `>` `>=` `<` `<=` | да |
| `like` `not like` | да |
| `in` `not in` | да, список |
| `is null` `is not null` | нет, поле значения скрыто |

Пустое значение у оператора, которому оно нужно, условие не применяет. Каталог из-за пустой строки «равно» не обнуляется.

Список значений в поле условия берёт опубликованные, не удалённые товары, не больше 100 разных строк.
