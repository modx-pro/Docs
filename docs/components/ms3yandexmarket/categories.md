# Категории и фильтры

## Категории

<!-- MEDIA: screenshot-admin | must | Вкладка «Категории»: дерево разделов MiniShop3 с отметками и полем своего названия для XML | На тестовом стенде отметить 2–3 синтетические категории, одной задать своё название -->

На вкладке **Категории** дерево разделов MiniShop3 развёрнуто. Флажок слева включает раздел. У включённого раздела есть флажок **Исключена** и поле **Своё название**. При назначении `placement` этой вкладки нет.

Флажки и своё название держатся в форме. В прайс они попадают по **Сохранить** в шапке карточки. До этого предпросмотр категорий показывает прошлый сохранённый набор.

Без отметок выборка по категориям не сужается: все опубликованные товары контекста `web`. Контекст меняет `context_key` в `shop_settings` (пустая строка = `web`). `<categories>` пуст, пока не выбраны корни.

Исключённая категория убирает свою ветку. Если все отмеченные категории исключены, в прайс не попадает ни один товар.

Своё название подменяет имя категории в XML и не меняет ресурс MODX.

## Фильтры

<!-- MEDIA: screenshot-admin | must | Форма условия фильтра: поле resource.pagetitle / data.price, оператор, значение на вкладке «Магазин» или «Предложения» | На тестовом стенде добавить одно условие с оператором = и одно с is null -->

**Магазин** пишет условия с `target` = `resource`, **Предложения** с `target` = `offer`. Выборка читает всю таблицу условий и не отфильтровывает по `target`. Оба списка сужают одни и те же товары.

Условия дублируются в таблице и в JSON прайса. При генерации списки складываются без повторов «поле, оператор, значение».

Поле условия задаётся как `источник.ключ`: `resource.pagetitle`, `data.price`, `tv.имя`, `option.ключ`.

| Оператор | Когда значение нужно |
| --- | --- |
| `=` `!=` `>` `>=` `<` `<=` | да |
| `like` `not like` | да |
| `in` `not in` | да, список |
| `is null` `is not null` | нет, поле значения скрыто |

Пустое значение у оператора, которому оно нужно, условие не применяет. Каталог из-за пустой строки «равно» не обнуляется.

Список значений в поле условия берёт опубликованные, не удалённые товары, не больше 100 разных строк.
