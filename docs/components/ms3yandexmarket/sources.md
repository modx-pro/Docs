# Источники значений

Значение тега это строка `тип:ключ`. Префикс сравнивается как записан, без смены регистра. Пишите его строчными буквами, как в таблице.

| Префикс | Откуда берётся значение |
| --- | --- |
| `field:` | Колонка ресурса, например `field:pagetitle` |
| `data:` | Колонка данных товара, например `data:article` |
| `tv:` или `tv.` | Дополнительное поле по имени |
| `option:` или `option.` | Опция товара MiniShop3 |
| `setting:` | Системная настройка MODX |
| `value:` | Текст после двоеточия как есть |
| `fenom:` | Шаблон pdoTools. Нужно право `ms3yandexmarket_edit_fenom` |
| `pipeline:price` | Цена с учётом источника предложения |
| `pipeline:old_price` | Старая цена |
| `pipeline:currency_id` | Код валюты |
| `pipeline:image` | Адрес картинки |
| `pipeline:url` | Адрес товара. Для варианта добавляется признак варианта |
| `pipeline:vendor` | Производитель |
| другой `pipeline:` | Пусто, без исключения |

Массив скаляров склеивается через запятую. Вложенный массив кодируется в JSON, чтобы в файл не попало слово `Array`.

Короткие имена без двоеточия `url`, `picture`, `image`, `vendor`, `price`, `oldprice`, `currencyId` разбирает тот же разбор. В редакторе тега храните полную форму с префиксом.

## Тег магазина и тег предложения

Тег внутри `offer` разбирает таблицу выше. Неизвестный префикс возвращается текстом.

Тег внутри `shop` разбирает только `setting:` и `value:`. Остальное, включая `field:`, `data:` и `pipeline:`, пишется в файл как введённая строка. Пустое значение тега магазина берёт ключ `shop_settings` с тем же именем. Для `name`, `company` и `url` у нового прайса этот ключ пустой.

Обработчик Fenom у тега применяется после подстановки, плейсхолдер `input` это уже полученный текст. В карточке тега поля обработчика нет. Префикс `fenom:` в **Откуда брать текст** задаётся там же, где остальные источники.

## Цена, адрес, картинка, производитель

`pipeline:price` читает `data.price`. Ноль и пустая цена дают пусто, тег не пишется. Старая цена (`pipeline:old_price`) отбрасывается, если она не больше текущей. Код валюты (`pipeline:currency_id`) берётся из `offer_settings.currency_id`, иначе из `ms3yandexmarket_default_currency` (`RUB`).

Если в `offer_settings` есть ключи, генератор их тоже читает. В форме карточки этих полей нет.

| Ключ | Эффект |
| --- | --- |
| `price_zero_behavior` | `skip` (так и есть без ключа): пустая цена. `zero` или `out`: цена 0 |
| `price_default` | Подставить, если своя цена пустая, а число больше нуля |
| `price_multiplier` | Умножить. 1 ничего не меняет |
| `price_min`, `price_max` | Поджать цену к границам |

## Адрес, картинка и производитель

`pipeline:url` собирает адрес из `uri` ресурса и `site_url`. Уже абсолютный `uri` не склеивается. Непустой `url_prefix` в настройках прайса вставляется между сайтом и путём. У варианта в конец добавляется `?variant=` и id варианта (или `&variant=`, если вопрос в адресе уже есть).

`pipeline:image` берёт картинку варианта, если она есть, иначе `data.image`. Абсолютный URL возвращается как есть. Иначе путь отдаёт медиаисточник: `image_source_id` в настройках прайса, иначе системная `ms3yandexmarket_image_source`, иначе источник `1`. `image_prefix` дописывается к относительному пути. Этих полей в форме нет.

`pipeline:vendor` ищет так: `vendor_name` в настройках прайса, затем `msVendor` по `vendor_id` товара, затем ключ `vendor_fallback` в тех же настройках. Если ключа `vendor_fallback` нет, берётся системная `ms3yandexmarket_vendor_fallback`.

Известный префикс из таблицы подставляется. Строка без такого префикса возвращается как текст и может попасть в XML. Так бывает с токеном из списка редактора, который генератор не разбирает.

Редактор перед сохранением меняет первую точку на двоеточие: `data.price` становится `data:price`.

## Группы выпадающего списка

`/lists/sources` отдаёт группы для поля **Откуда брать текст**. Перед сохранением первая точка становится двоеточием.

| Группа | После сохранения | В XML тега предложения |
| --- | --- | --- |
| `data` | `data:price` | Колонка товара |
| `tv` | `tv:имя` | Дополнительное поле |
| `option` | `option:ключ` | Опция MiniShop3 |
| `setting` | `setting:ключ` | Системная настройка |
| `value` | `value:текст` | Текст как есть |
| `fenom` | `fenom:шаблон` | Шаблон pdoTools |

## Списки редактора, которые генератор не читает

`/lists/sources` отдаёт группы для выпадающего списка. Фильтры понимают `resource.поле`, `data.поле`, `tv.имя`, `option.ключ` с точкой. Подстановка текста тега эти группы не разбирает.

| Группа в списке | Что сохранится | Что попадёт в XML на дереве полей |
| --- | --- | --- |
| `resource` | `resource:pagetitle` | Текст токена, не заголовок товара. Для колонки ресурса пишите `field:pagetitle` |
| `gallery` | `gallery:image` | Текст токена. Картинку берите через `pipeline:image` |
| `variant` | `variant:sku` | Текст токена. Артикул варианта задаёт источник предложений `variant` |
| `remain` | `remain:count` | Текст токена. Остаток задаёт источник остатков |
