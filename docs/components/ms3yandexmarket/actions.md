# Действия

Состав файла и подстановка значений: [состав файла](/components/ms3yandexmarket/feeds), [источники](/components/ms3yandexmarket/sources).

## Права на действие

| Действие | Право |
| --- | --- |
| Список, карточка, диагностика, журнал, фрагмент XML, полный предпросмотр, чтение и скачивание файла | `ms3yandexmarket_view` |
| Создание и сохранение прайса, чтение и запись тегов, атрибутов и условий, категории | `ms3yandexmarket_manage` |
| **Сгенерировать** и запуск всех ожидающих прайсов | `ms3yandexmarket_generate` |
| Тип тега `19` | ещё `ms3yandexmarket_edit_raw_xml` |
| Непустой обработчик Fenom у тега или атрибута | ещё `ms3yandexmarket_edit_fenom` |

`GET /fields`, `GET /fields/{id}` и `GET /conditions` требуют `ms3yandexmarket_manage`. Установщик кладёт права своего XML и Fenom в политику. Без них сохранение отвечает 403. См. [настройки и права](/components/ms3yandexmarket/settings).

## Список прайсов

| Действие | Что происходит |
| --- | --- |
| **Поиск** | Список по названию. Пустая строка возвращает все прайсы |
| **Создать** | Карточка нового прайса. В базе строки ещё нет |
| Название в таблице | Открывает карточку |
| **Редактировать** | То же |
| **Удалить** | Спрашивает подтверждение. Удаляет прайс, его категории, запуски журнала и сообщения. Файл на диске остаётся |

## Шапка карточки

**Создать** на новом прайсе требует название. Пишет карточку и создаёт дерево тегов по площадке и назначению. После этого видны вкладки **Предложения** и **Генерация**.

**Сохранить** на существующем прайсе пишет название, описание, активность, источники предложений и остатков, режим, интервал, тип оффера, площадку, назначение, путь, URL и отмеченные категории. При `placement` ещё список управляемых полей. Теги дерева эта кнопка не пишет.

**Сохранить** и **Сохранить настройки** каждый раз шлют ключи отметки «нужно сгенерировать»: источник предложений, режим, интервал, площадка, категории. Сравнения со старым значением нет. Отметка ставится и если менялись только название, описание, активность, путь или URL.

Смена площадки или назначения стирает дерево тегов и заполняет его заново под новый профиль. Правки тегов, сделанные раньше, пропадают.

**Отмена** возвращает к списку и не пишет форму.

## Тег

Имя, источник и переключатель **Выводить в файл** лежат в форме, пока не нажато **Сохранить тег**. Кнопка пишет этот тег сразу и обновляет панель XML. Чужая `version` даёт ответ 409: тег не перезаписывается, откройте его снова.

Выключенный тег в списке бледнее и в файл не попадает.

Кнопок добавить тег, удалить тег и поменять порядок в дереве нет. Это делают маршруты `POST /fields/create`, `POST /fields/remove` и `POST /fields/reorder`. См. [маршруты](/components/ms3yandexmarket/api).

## Атрибут

**Добавить атрибут** сразу создаёт атрибут с именем `id` и пустым значением.

**Сохранить** у атрибута пишет имя и значение. **Удалить** убирает атрибут. Обе кнопки требуют актуальную `version`.

Имя `id` или `available` на самом узле `offer` в файл как отдельный атрибут не копируется: эти имена занимают атрибуты предложения из одноимённых вложенных тегов.

## Категории

Флажок раздела, флажок **Исключена** и **Своё название** меняют только форму. В базу они попадают по **Сохранить** в шапке. Снятие флажка раздела сбрасывает «исключена» в форме.

Предпросмотр категорий читает уже сохранённый набор. Пока шапка не сохранена, панель XML показывает старые разделы.

## Фильтры

Блок **Фильтры** есть на **Магазине** (`target` = `resource`) и на **Предложениях** (`target` = `offer`).

| Кнопка | Что происходит |
| --- | --- |
| **Добавить условие** | Сразу пишет строку: первая колонка списка, оператор `=`, пустое значение |
| **Сохранить** у строки | Пишет колонку, оператор и значение этой строки |
| **Удалить** у строки | Удаляет условие |

Подсказки берут опубликованные товары: не больше 100 разных строк, в списке 30. Для `is null` и `is not null` поле значения скрыто и при сохранении уходит пустым.

Пустое значение у оператора, которому оно нужно, выборку не сужает. Оба списка условий применяются к одним и тем же товарам. См. [категории и фильтры](/components/ms3yandexmarket/categories).

## Таблица предложений

Вкладка **Предложения** при первом открытии запрашивает порцию из 20 строк. **Поиск** сужает по строке и возвращает на первую страницу. **Назад** и **Дальше** листают порции, если строк больше 20.

Над таблицей счётчики: найдено, пропущено, просмотрено товаров.

**ID товара** и **ID варианта** задают фрагмент XML одного предложения. Без id товара эта панель пустая. Фрагмент читает сохранённые теги, не черновик формы тега.

## Генерация

**Сохранить настройки** пишет режим, интервал, площадку, путь и URL. Площадка здесь та же, что в шапке: её смена заново собирает дерево тегов.

| Кнопка | Право | Файл |
| --- | --- | --- |
| **Сгенерировать** | `generate` | Пишет. Повтор во время записи отвечает `generation_locked` |
| **Предпросмотр YML** | `view` | Сборка в памяти, файл не меняется |
| **Показать сгенерированный YML** | `view` | Текст уже записанного файла |
| **Скачать YML** | `view` | Тот же файл как загрузка |

Пока идёт **Сгенерировать**, журнал под кнопками обновляется каждые 1,5 секунды и показывает последние 80 строк. Опрос кончается на статусе `success`, `error` или `partial`.

Кнопки «сгенерировать все ожидающие» в менеджере нет. Тот же отбор делает планировщик, `cron.php` и маршрут `POST /generate/run-all`.

## Панели XML

Панель рядом с деревом обновляется примерно через 0,4 секунды после сохранения тега, атрибута или условия. Она не заменяет файл на диске.

Для Яндекса панель показывает фрагмент: магазин, категории или одно предложение. Для `google.rss20` панель категорий пишет комментарий, что элемента категорий нет. Панели магазина и предложения у Google показывают весь RSS, не кусок дерева тегов.

## Логи

**Поиск** и **Обновить** читают журнал. Непустой номер в поле фильтра оставляет запуски этого прайса. Пустое поле показывает все.

**Детали** открывает запуск: статус, выгружено, длительность, размер файла, прайс, старт, финиш, пропущено, ошибки, предупреждения и таблицу сообщений (уровень, сущность, поле, текст). Нет строк: замечаний не было. Потолок числа сообщений задаёт `ms3yandexmarket_log_entry_cap`.

**Назад** возвращает к списку журнала. Ссылка на прайс открывает его карточку.

## Диагностика

Раздел только читает среду. Кнопок записи нет. Группы: среда (PHP, версия компонента, размер порции), зависимости (MiniShop3, Fenom, Scheduler и его задача), варианты, остатки, файлы (путь и можно ли писать в каталог). Разбор строк: [журнал и диагностика](/components/ms3yandexmarket/logs).
