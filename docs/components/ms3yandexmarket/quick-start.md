# Первый прайс-лист

<!-- MEDIA: screenshot-admin | must | Первый прайс: список прайсов, карточка с вкладками «Магазин», «Категории», «Предложения», запуск «Генерация» | На тестовом стенде MiniShop3 открыть «Яндекс Маркет», пройти шаги 1–5 страницы на синтетическом каталоге без данных заказчиков -->

Прайс: один файл YML и один набор тегов. В менеджере прайсов может быть несколько.

1. Создайте прайс: **Название** и **Создать**. Без названия форма не сохранится.
2. Вкладка **Магазин**, блок **Поля магазина**: для тегов `name`, `company`, `url` укажите **Откуда брать текст** (например `value:Магазин`) и нажмите **Сохранить тег** у каждого.
3. Вкладка **Категории**: отметьте разделы для `<categories>`. Без отметок товары по разделу не фильтруются, блок категорий в XML пуст.
4. Вкладка **Предложения**: проверьте теги `name`, `price`, `url`. **Сохранить** в шапке их не пишет.
5. **Генерация**: запустите запись. Файл всегда называется `pricelist-{id}.xml` и лежит в каталоге `ms3yandexmarket_files_path`. После записи карточка получает этот путь и URL. Введённые вручную путь и URL генерация не использует. Предпросмотр файл на диске не заменяет.

Режим **Вручную** не обновляет файл при сохранении товара. Расписание: режим `scheduler`, см. [генерацию](/components/ms3yandexmarket/generation).
