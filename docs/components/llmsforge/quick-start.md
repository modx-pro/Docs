# Быстрый старт

## Требования

MODX Revolution 3, PHP 8.1+, расширения DOM, JSON и mbstring. На сайте должны работать Friendly URLs и перенаправление неизвестных путей в MODX. Если в корне уже есть файл `llms.txt` или ресурс с таким URI, он имеет приоритет перед маршрутом дополнения.

Для статистики посещений PHP нужен доступ на запись в `core/components/llmsforge/var/visits`.

## Установка

1. Загрузите и установите transport-пакет `llmsforge-1.0.0-pl.transport.zip` через менеджер пакетов MODX.
2. Откройте **Компоненты → LLMS Forge**. Для доступа нужно разрешение MODX `settings`.
3. Выберите контекст сайта и нажмите **Проверить**. Исправьте замечания диагностики.
4. Укажите название и краткое описание сайта.
5. Найдите нужные страницы, отметьте их и при необходимости задайте разделы. Поиск работает по названию и ID; список разделён на страницы по 25 строк.
6. Нажмите **Предпросмотр**, выберите **Опубликовать при сохранении** и сохраните настройки.
7. Откройте `https://ваш-домен/llms.txt` без авторизации и проверьте ответ.

```text
# Название сайта

> Краткое описание

## Pages

- [Страница](https://example.com/page): Описание страницы.
```

Предпросмотр использует текущие поля формы и сам по себе их не сохраняет. Контексты настраиваются отдельно. Пакет обновляется установкой новой версии поверх прежней; существующие настройки сохраняются.

## Веб-сервер

LLMS Forge обрабатывает маршруты через событие `OnPageNotFound`. Правила Friendly URLs должны передавать запросы `/llms.txt` и `/llms-txt/…` в MODX. После установки проверьте оба адреса: `/llms.txt` и ссылку на одну созданную карточку. При ответе 404 смотрите [решение проблем](troubleshooting.md).
