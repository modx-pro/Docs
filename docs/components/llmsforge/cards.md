# Карточки страниц

Отдельная карточка доступна по адресу `/llms-txt/slug`. Ссылка на неё добавляется в основной `/llms.txt` после сохранения настроек. Карточки подходят для товаров, категорий, статей и ключевых страниц.

## Карточка из ресурса MODX

В разделе **LLMS для отдельных страниц** нажмите **Добавить LLMS для страницы**, выберите источник **Получать из ресурса MODX** и найдите ресурс по названию или ID. Для новой карточки название и адрес `resource-ID` заполняются после выбора. Нажмите **Предпросмотр страницы**, затем сохраните настройки.

Кнопка **Создать карточки из выбранных** добавляет карточки для выбранных опубликованных страниц. При активном поиске используются только найденные страницы. Уже созданные карточки и исключённые ID пропускаются. Лимит — 200 карточек.

Содержимое ресурса преобразуется из HTML в Markdown без выполнения сниппетов. Автоматическая карточка не выдаётся, если ресурс или его родитель удалён, не опубликован, закрыт группой доступа или недоступен по срокам публикации.

## TV и miniShop3

В поле **TV для Markdown-карточек** перечислите имена TV через запятую. В поле **Поля miniShop3 для Markdown-карточек** можно указать `price,old_price,article,weight,vendor,made_in` или нужное подмножество.

Если для товара указано `price,article`, карточка может содержать:

```md
## Свойства

- price: 84158
- article: ART-000012
```

Значения берутся из `msProductData`, если miniShop3 установлен и поля заполнены. Они выводятся **в карточке товара**; основной `/llms.txt` содержит ссылки и краткие описания страниц.

## Ручная карточка

Выберите источник **Написать Markdown вручную**, укажите полный URL страницы и текст карточки. Ручной текст публикуется независимо от прав и состояния исходного ресурса. Не используйте этот режим для закрытой информации. Общий объём метаданных карточек ограничен 60 КБ, Markdown одной карточки — 50 КБ.
