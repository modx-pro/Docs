# Настройки и доступ

Настройки сохраняются отдельно для выбранного контекста MODX. Системные значения `llmsforge.*` используются как значения по умолчанию, а настройки контекста могут их переопределить.

| Поле | Назначение |
| --- | --- |
| Название и краткое описание | Заголовок и вводный текст `/llms.txt` |
| Выбранные ID и исключить ID | Состав и порядок ссылок; до 5000 выбранных ID |
| Разделы | Группировка ссылок в основном документе |
| Основной llms.txt | Автоматическая сборка или ручной Markdown |
| TV и поля miniShop3 | Дополнительные свойства автоматических карточек |
| Доступность | Включение публичных маршрутов после сохранения |

Экспорт исключает удалённые, неопубликованные, не участвующие в поиске и закрытые группами ресурсов страницы. Проверяются права `view`, даты публикации и снятия, а также все родительские ресурсы. Выбранный ID не гарантирует появление страницы в результате.

## Событие проверки ресурса

Интеграция может дополнительно исключить ресурс через `OnLLMSForgeResourceCheck`. Обработчик получает `resource` и `context`. Верните строку `exclude`, если страницу нельзя показывать:

```php
if ($resource->get('class_key') === 'CustomPrivateResource') {
    return 'exclude';
}
```

Базовые ограничения доступа действуют независимо от обработчика.

## Журнал AI-ботов

Журнал записывает запросы, дошедшие до MODX, и показывает время UTC, распознанный User-Agent, адрес, метод и статус. Он не сохраняет IP, параметры URL, cookies или полный User-Agent. Записи доступны за последние 30 дней; запись ограничена 5 МБ в сутки. Название бота по User-Agent может быть подделано, поэтому статистика не подтверждает реальное чтение или цитирование.
