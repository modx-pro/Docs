# Решение проблем

Панель не появилась или в журнале MODX растёт число ошибок пакета.

## Панель не появляется

1. `modx3profilertoolbar.enabled` и `modx3profilertoolbar.frontend_toolbar` включены.
2. Страница открыта в контексте `web`, не в менеджере.
3. Есть сессия контекста `mgr`.
4. Плагин `Modx3ProfilerToolbar` включён на событиях `OnMODXInit`, `OnHandleRequest`, `OnLoadWebDocument`, `OnWebPagePrerender`.
5. Запрос попал в `sampling_rate`. При значении ниже 100 часть запросов панель не получает.
6. В выводе ресурса есть `</body>`. Без этой строки пакет HTML не меняет и ошибку в консоль не пишет.
7. Браузер загрузил `toolbar.js` и модуль `petite-vue` 0.4.1 с `unpkg.com`. Блокировка `unpkg` оставляет JSON в странице и не строит панель. В странице ищите `window.modx3profilertoolbarToolbarData`.

## Журнал пишет pdoTools service not found

На профилируемом запросе без сервиса `pdotools` пакет пишет ошибку `[Modx3ProfilerToolbar] pdoTools service not found`. Сбор панели после записи продолжается. Текст ошибки не означает, что запрос оборвался.

## Сколько добавляет сбор

На запросе внутри `sampling_rate` в памяти считаются таймер, строка SQL и timings pdoTools, если сервис есть. Трейс в базу и на диск не пишется.

При включённом `enabled` пакет на `OnMODXInit` подменяет парсер и для запроса вне `sampling_rate`. Доли накладных расходов пакет не измеряет.

На рабочем сайте оставьте `frontend_toolbar` включённым, только если в менеджер входят те, кто должен видеть панель. Сессия `mgr` уже обязательна для вставки.

## Общий хостинг

Файлов с разбором запроса пакет не создаёт. При установке и обновлении уходит POST на `https://metrics.modx.pro/` с таймаутом 2 секунды. Неудача установку не прерывает. Состав тела описан в [обзоре](/components/modx3profilertoolbar/#ustanovka).

## Как выключить

Поставьте `modx3profilertoolbar.enabled` в «Нет». Плагин выходит до `start()` и до подмены парсера.

При выключенном ключе на запросе остаётся чтение этой настройки.

## Другие пакеты

Отдельного кода для miniShop3, Fenom и pdoTools-сниппетов нет. Совместная работа описана в [ограничениях](limitations). Шаблон менять не нужно. Панель добавляется перед `</body>` в уже собранный вывод ресурса.
