# Быстрый старт

## Требования

| Требование | Версия |
|------------|--------|
| MODX Revolution | 3.0.0 и новее |
| PHP | 8.1.0 и новее |

## Шаг 1. Установка

1. Откройте установщик пакетов.
2. Найдите **Modx3ProfilerToolbar**.
3. Нажмите **Установить**.

При установке и обновлении уходит обезличенный POST на `https://metrics.modx.pro/`. Состав описан в [обзоре](/components/modx3profilertoolbar/#ustanovka). Сбой отправки пакет не откатывает.

## Шаг 2. Настройки

Откройте системные настройки MODX и отфильтруйте пространство имён `modx3profilertoolbar`. Пакет свой пункт меню не создаёт.

Включите:

- `modx3profilertoolbar.enabled`
- `modx3profilertoolbar.frontend_toolbar`

Остальные ключи: [системные настройки](settings).

## Шаг 3. Проверка

1. Войдите в менеджер.
2. Откройте страницу сайта в контексте `web`.
3. В правом нижнем углу появляется панель.

Панель видна только при сессии контекста `mgr`. Данные относятся к этому запросу и уже вставлены в HTML. Если запрос не попал в `sampling_rate`, панели не будет. При включённом `enabled` пакет подменяет парсер и на таком запросе. См. [решение проблем](troubleshooting).
