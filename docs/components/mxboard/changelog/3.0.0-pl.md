# mxBoard 3.0.0-pl

Релиз убирает отдельное поле карточки `tor`, которое больше не показывалось в интерфейсе, дублировало типизированные поля задачи и комментарии, но продолжало присутствовать в таблице и контрактах API.

## Что изменилось

- Структурированная постановка хранится в `fields` согласно типу задачи.
- Свободный Markdown, уточнения и обсуждение хранятся в комментариях.
- Параметр `tor` удалён из MCP-инструментов `task_create` и `task_update`; `task_get` его больше не возвращает.
- ИИ-проверка полноты оценивает заголовок и поля выбранного типа без отдельного текста ToR.

## Миграция данных

При обновлении с 2.x установщик:

1. Находит все непустые значения `mxboard_task.tor`.
2. Создаёт для каждого обычный комментарий от автора карточки с исходным временем создания задачи и неизменённым текстом.
3. Проверяет, что для каждого исходного значения существует точная бинарная копия в комментариях.
4. Только после успешной проверки удаляет колонку `tor`.

Повторный запуск безопасен: комментарий с тем же текстом и автором не создаётся второй раз. Если таблица комментариев недоступна, вставка не выполнена или проверка не сошлась, upgrade завершается ошибкой, а исходная колонка остаётся на месте.

## Что поменять в интеграциях

- Удалите `tor` из запросов `task_create` и `task_update`.
- Перед созданием задачи вызывайте `task_schema` и заполняйте `fields` выбранного типа.
- Свободный текст добавляйте через `task_comment` или REST-эндпоинт комментариев.
