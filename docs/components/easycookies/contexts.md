# Контексты и языки

## Контексты

У языковых версий и поддоменов может быть свой баннер. Поле «Контексты» в карточке «Профиль» появляется, когда контекстов на сайте больше одного (менеджер не в счёт).

- **Контексты не отмечены** — общий профиль: показывается во всех контекстах, где нет своего профиля.
- **Контексты отмечены** — профиль показывается только в них и главнее общего.

Активным может быть один профиль на контекст. Включённый профиль выключает другие активные профили тех же контекстов: общий — другой общий, контекстный — профили с общими с ним контекстами. Общий и контекстный профили друг другу не мешают.

В списке профилей у активного общего профиля видно, в каких контекстах вместо него показывается свой: «кроме English».

Плагин и сниппеты берут профиль контекста текущей страницы. Настройка `easycookies.auto_inject_profile` и параметр `profile` у сниппетов задают профиль явно — тогда контекст не учитывается.

::: tip
Адрес политики конфиденциальности, заданный id ресурса, превращается в ссылку в контексте `web`. Для профиля другого контекста укажите адрес страницы текстом.
:::

## Языки

Готовые тексты баннера есть на 14 языках: русский, английский, украинский, белорусский, казахский, узбекский, таджикский, армянский, азербайджанский, немецкий, французский, испанский, итальянский, польский.

Языки добавляются списком «Добавить язык…». В нём две группы: языки с готовыми текстами и остальные языки, на которые переведён MODX. У языков второй группы и у языка, добавленного через «Другой язык по коду…», тексты начинаются с копии языка по умолчанию — их нужно перевести в окне «Тексты».

У простого баннера язык обычно один — язык сайта. Добавьте ещё, если сайт многоязычный: над текстом появятся вкладки языков.

| Поле | Описание |
| --- | --- |
| Язык по умолчанию | Показывается, если языка посетителя нет в профиле |
| Язык баннера | Откуда баннер берёт язык посетителя: язык страницы (`<html lang>`), язык браузера или всегда язык по умолчанию |

На страницу попадают тексты только тех языков, что есть в профиле. Для арабского, фарси, иврита и урду окна баннера разворачиваются справа налево.

::: tip
Язык страницы берётся из атрибута `lang` у `<html>`. В шаблоне MODX его обычно пишут так: `<html lang="[[++cultureKey]]">`.
:::
