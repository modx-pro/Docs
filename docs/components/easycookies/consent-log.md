# Журнал согласий

Законы вроде GDPR требуют не только спросить согласие, но и уметь его доказать. Баннер по требованиям с включённой настройкой «Вести журнал согласий» записывает каждый ответ посетителя: и первый, и каждое изменение выбора. У новых профилей настройка включена.

Простой баннер журнал не ведёт: «Понятно» ничего не разрешает сверх того, что уже работает.

Журнал — на вкладке **Журнал согласий** страницы компонента.

![Журнал согласий со сводкой](/components/easycookies/screenshots/log.png)

## Что записывается

| Поле | Описание |
| --- | --- |
| Дата | Когда посетитель ответил |
| ID согласия | Тот же, что хранится в cookie посетителя, — по нему находится вся история его выбора |
| Решение | «Принял все», «Только необходимые» или «Выборочно» |
| Разрешено и отклонено | Категории и разрешённые сервисы |
| Профиль, ревизия, язык | Каким баннером и на каком языке спросили |
| Страница | Путь без параметров запроса: в них бывают метки и адреса почты |
| IP | Укороченный: последний байт IPv4 и всё после /48 у IPv6 обнуляются. Можно не хранить вовсе — настройка `easycookies.log_ip` |
| Браузер | Строка User-Agent |

Запись согласия не ставит посетителю никаких cookie: приёмник `assets/components/easycookies/consent.php` работает без сессии.

Приёмник принимает только запросы со страниц сайта: скрипт баннера передаёт подпись страницы, которая действует неделю. С одного адреса принимается не больше 60 записей в час, а тот же ответ, отправленный повторно в течение минуты, второй раз не записывается.

## Сводка

Над таблицей — сводка за выбранный период:

- сколько ответов и какая доля приняла всё, отклонила или выбрала сама;
- график ответов по дням с разбивкой по решениям (на длинном периоде столбик объединяет несколько дней);
- сколько посетителей разрешили каждую категорию.

## Фильтры и таблица

Фильтры: поиск по ID согласия, странице или IP, решение, профиль и период «С» — «По». По умолчанию показаны последние 30 дней. Сводка, таблица и выгрузка считаются по одним и тем же фильтрам.

Таблица сортируется по дате, решению, профилю, странице, IP и ID согласия. Щелчок по ID копирует его.

Из списка профилей в журнал ведёт число в колонке «Согласия»: журнал откроется с фильтром по этому профилю.

## Выгрузка в CSV

«Выгрузить CSV» сохраняет всё, что подходит под фильтры, — до 50 000 строк за раз. Файл в UTF-8 с BOM, чтобы Excel открыл его без вопросов.

| Столбец | Содержимое |
| --- | --- |
| `date` | Дата и время `Y-m-d H:i:s` |
| `consent_id` | ID согласия |
| `decision` | `all`, `necessary` или `custom` |
| `accepted`, `rejected` | Категории через пробел |
| `services` | Разрешённые сервисы: `analytics:ym\|ga4 marketing:vk` |
| `profile` | Название профиля |
| `revision`, `mode`, `language` | Ревизия, вид баннера, язык |
| `page`, `ip`, `user_agent` | Страница, укороченный IP, браузер |

## Срок хранения

Записи старше `easycookies.log_days` дней (по умолчанию 365) удаляются сами — изредка, заодно с записью новых ответов. `0` — хранить всегда.

## Виджет рабочего стола

Виджет «Согласия на cookie» показывает ту же сводку за последние 30 дней и ссылку на журнал. Виджет видят пользователи с правом `settings`.

![Виджет «Согласия на cookie»](/components/easycookies/screenshots/widget.png)

::: tip
Если виджета на рабочем столе нет, добавьте его вручную в разделе управления панелями (Dashboards) или кнопкой «Добавить» на самом рабочем столе MODX 3.
:::
