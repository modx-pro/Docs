# Настройки компонента

Пространство имён в MODX: `easycookies`. Кнопка «Системные настройки» в шапке страницы компонента открывает их.

| Ключ | По умолчанию | Описание |
| --- | --- | --- |
| `easycookies.auto_inject` | `Да` | Плагин выводит баннер активного профиля на каждой HTML-странице. Выключите, чтобы вызывать сниппет `[[EasyCookies]]` из шаблона самостоятельно |
| `easycookies.auto_inject_profile` | — | Название или id профиля, который выводит плагин; пусто — активный профиль контекста |
| `easycookies.exclude_resources` | — | Id ресурсов через запятую, на которых плагин баннер не выводит, — например, страницы для мобильных приложений |
| `easycookies.log_days` | `365` | Сколько дней хранить журнал согласий; `0` — всегда |
| `easycookies.log_ip` | `Да` | Сохранять в журнале укороченный IP |
| `easycookies.migrate_paths` | — | Ещё каталоги с шаблонами `.tpl` и `.html` для «Найти на сайте», через запятую: от корня сайта или с `{core_path}`, `{base_path}`, `{assets_path}`. Каталог элементов pdoTools просматривается и так |

Настройки профиля — текст, вид, счётчики, cookie согласия — хранятся в самом профиле и меняются в [редакторе](/components/easycookies/profiles).
