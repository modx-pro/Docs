# Контроль загрузок

Если сайт упирается в лимит, контроль загрузок не даст загрузить файл, который в него не помещается. Менеджер увидит ошибку «Превышен лимит объёма сайта».

## Включение

Нужны обе настройки:

- [`modsizecontrol_control`](/components/modsizecontrol/settings) — `Да`;
- [`modsizecontrol_site_limit`](/components/modsizecontrol/settings) — лимит в мегабайтах больше нуля.

Без лимита контроль ничего не проверяет, даже если включён.

## Как считается

Проверку делает плагин modSizeControl на событии `OnFileManagerBeforeUpload`, то есть при загрузке через файловый менеджер MODX.

Текущий размер сайта — итог последнего сканирования плюс всё, что загружено через файловый менеджер после него. Если текущий размер вместе с загружаемым файлом больше лимита, файл не загружается. Загруженный файл сразу учитывается, так что следующий сравнивается уже с новым размером. Новое сканирование обнуляет счётчик загруженного.

Если сайт ещё ни разу не сканировали, размер берётся быстрым замером (`du` или обход из PHP) и кешируется на 12 часов.

::: warning
Контроль видит только загрузки через файловый менеджер MODX. Файлы, залитые по FTP или созданные компонентами, попадут в расчёт после следующего сканирования. Поэтому при включённом контроле стоит сканировать сайт по [cron](/components/modsizecontrol/scan#cron).
:::
