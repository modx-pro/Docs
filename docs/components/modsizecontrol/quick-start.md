# Быстрый старт

## Первое сканирование

Пока сайт не сканировали, виджет на рабочем столе пуст и предлагает кнопку «Сканировать». Её же показывает страница **Пакеты → Контроль размера сайта**.

Сканирование обходит все файлы сайта: корень, ядро, `assets`, менеджер, коннекторы и источники файлов. На сайте в несколько гигабайт это займёт пару минут. Прогресс виден и в виджете, и на странице. Страницу можно закрыть: сканирование продолжится, когда вы откроете её снова.

## Лимит

По умолчанию лимит не задан: виджет показывает размер сайта и свободное место на диске сервера. Чтобы видеть заполнение, впишите лимит в мегабайтах в системную настройку [`modsizecontrol_site_limit`](/components/modsizecontrol/settings), например `1024` — это 1 ГБ.

Кнопка «Системные настройки» на странице компонента открывает настройки modSizeControl.

![Виджет с лимитом](/components/modsizecontrol/screenshots/widget.png)

## Где искать место

Откройте страницу компонента кнопкой «Подробнее» в виджете. «Обзор» покажет, какая категория занимает больше всего, а название категории откроет её папки в проводнике. Дальше: [Страница компонента](/components/modsizecontrol/page).

То, что можно удалить без вреда для сайта, собрано в блоке [Очистка](/components/modsizecontrol/cleanup).

## Регулярная проверка

Цифры на странице и в виджете — на момент последнего сканирования. Чтобы они не устаревали и в «Истории» копился рост, поставьте сканирование в cron, например раз в сутки:

```bash
0 3 * * * php /var/www/site/core/components/modsizecontrol/cli/scan.php > /dev/null 2>&1
```

Подробнее: [Сканирование и cron](/components/modsizecontrol/scan).
