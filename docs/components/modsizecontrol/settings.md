# Настройки компонента

Пространство имён в MODX: `modsizecontrol`, раздел «Основные». Кнопка «Системные настройки» на странице компонента открывает именно его.

| Ключ | По умолчанию | Описание |
| --- | --- | --- |
| `modsizecontrol_site_limit` | `0` | Лимит размера сайта в мегабайтах, например `1024` — это 1 ГБ. `0` — без лимита: виджет сравнивает размер сайта с диском сервера |
| `modsizecontrol_file_system` | `1` | ID источников файлов через запятую. Источник внутри другого из списка считается один раз |
| `modsizecontrol_control` | `Нет` | [Контроль загрузок](/components/modsizecontrol/upload-control): файл, который не помещается в лимит, не загрузится |

## Источники файлов

Корень сайта сканируется всегда, поэтому источники внутри него ничего не добавляют к размеру. Настройка нужна, когда источник смотрит за пределы сайта, например на общий каталог загрузок: такой каталог сканируется отдельно и попадает в категорию «Медиа».
