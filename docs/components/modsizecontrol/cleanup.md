# Очистка

Блок «Очистка» внизу вкладки «Обзор» собирает то, что можно удалить без вреда для сайта. Размеры в нём считаются с диска при открытии страницы, а не берутся из сканирования.

Каждое действие спрашивает подтверждение и требует того же права, что и штатная кнопка MODX. Без права кнопка неактивна.

![Подтверждение удаления старых версий пакетов](/components/modsizecontrol/screenshots/dialog-cleanup.png)

| Строка | Что делает | Право |
| --- | --- | --- |
| Кеш MODX | То же, что «Очистить кэш» в меню MODX. MODX соберёт кеш заново при следующих открытиях страниц | `empty_cache` |
| Логи | Опустошает файлы в `core/cache/logs`. Сами файлы остаются, записи в них пропадают | `error_log_erase` |
| Старые версии пакетов | Удаляет версии пакетов ниже самой новой установленной | `packages` |

## Старые версии пакетов

После каждого обновления в `core/packages` остаются архив и распакованная папка предыдущей версии. На сайте, который обновляли несколько лет, это легко десятки мегабайт.

Под строкой перечислены версии, которые будут удалены, в окне подтверждения — их сигнатуры. Удаляются только версии ниже установленной: скачанная, но ещё не установленная новая версия не трогается. Сами компоненты не затрагиваются.

Удаляет версии тот же процессор MODX, что стоит за кнопкой «Удалить» в окне версий пакета.

::: tip
Цифры на вкладках — на момент сканирования. После очистки просканируйте сайт заново, чтобы увидеть результат.
:::
