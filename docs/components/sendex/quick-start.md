# Быстрый старт

Пошаговая настройка первой рассылки Sendex.

## Шаг 1. Установка

1. Установите пакет через **Extras → Installer** (см. [обзор](index#установка))
2. Очистите кэш MODX

## Шаг 2. Создание рассылки

1. Откройте **Компоненты → Sendex**
2. На вкладке **Подписки** нажмите **Создать**
3. Заполните обязательные поля:

| Поле | Описание |
| --- | --- |
| **Название** | Имя рассылки в менеджере |
| **Шаблон** | MODX-шаблон письма (см. шаг 3) |
| **Тема письма** | Тема исходящего письма |
| **Исходящий email** | Адрес отправителя |
| **Ответный email** | Reply-To |
| **Отправитель** | Имя отправителя |
| **Включено** | Активна ли рассылка |

Подробнее о полях и подписчиках: [Подписки](interface/subscriptions).

## Шаг 3. Шаблон письма

Создайте шаблон MODX для тела письма. При отправке Sendex передаёт в шаблон объекты `newsletter`, `subscriber`, а для авторизованных подписчиков — `user` и `profile`.

Пример ссылки для отписки в шаблоне:

::: code-group

```fenom
{set $args = [
  'sx_action' => 'unsubscribe',
  'newsletter_id' => $newsletter.id,
  'code' => $subscriber.code,
]}
<a href="{'site_start' | option | url : ['scheme' => 'full'] : $args}">Отписаться от рассылки</a>
```

```modx
<a href="[[~[[++site_start]]?scheme=`full`&sx_action=`unsubscribe`&newsletter_id=`[[+newsletter.id]]`&code=`[[+subscriber.code]]`]]">
  Отписаться от рассылки
</a>
```

:::

Страница по ссылке должна вызывать сниппет Sendex:

::: code-group

```fenom
{'!Sendex' | snippet : ['id' => 1]}
```

```modx
[[!Sendex? &id=`1`]]
```

:::

Полный список плейсхолдеров — в [документации сниппета](snippets/sendex#шаблон-письма).

::: tip Демо-шаблон из пакета
В transport входит шаблон **Sendex** (`template.sendex.tpl`) с таблицей всех плейсхолдеров `newsletter`, `subscriber`, `user`, `profile` и примером ссылки отписки. Используйте как основу для своего шаблона письма.
:::

## Шаг 4. Форма подписки на сайте

Разместите сниппет **некэшированным** — вывод зависит от авторизации пользователя:

::: code-group

```fenom
{'!Sendex' | snippet : ['id' => 1]}
```

```modx
[[!Sendex? &id=`1`]]
```

:::

Замените `1` на ID созданной рассылки.

- Авторизованный пользователь видит кнопку подписки или отписки
- Гость вводит email; при включённом подтверждении (`sendex_confirm_email`, по умолчанию **Да**) получает письмо со ссылкой активации

## Шаг 5. Тест подписки

1. Откройте страницу с формой
2. Подпишитесь тестовым email (или войдите под пользователем MODX)
3. В **Компоненты → Sendex → Подписки** откройте рассылку → вкладка **Подписчики** и проверьте запись

## Шаг 6. Отправка рассылки

1. В менеджере: **Подписки** → контекстное меню рассылки → **Отправить подписчикам** — формирует очередь и сразу отправляет
2. Или вручную: вкладка **Очередь писем** → выберите рассылку → сгенерируйте письма → отправьте
3. Для регулярной отправки настройте cron — см. [Очередь писем](interface/queue#cron)

## Чеклист после установки

- [ ] Рассылка создана и **включена**
- [ ] Шаблон письма с ссылкой отписки на странице с `[[!Sendex]]`
- [ ] Сниппет на странице подписки (некэшированный)
- [ ] Тест подписки гостя и авторизованного пользователя, запись в **Подписчики**
- [ ] Cron для `core/components/sendex/cron/send.php` (если очередь >100 писем)
- [ ] События `sxOn*` видны после обновления пакета (см. [События](integration/events))
