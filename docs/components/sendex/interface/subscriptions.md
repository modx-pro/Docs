# Подписки

В разделе **Подписки** вы создаёте рассылки, управляете подписчиками и запускаете отправку.

Откройте **Компоненты → Sendex** → вкладка **Подписки**.

## Создание рассылки

- Нажмите **Создать**, заполните форму и сохраните

![Создание рассылки](https://file.modx.pro/files/2/a/f/2af549ef2d714b69e4369fda479de69e.png)

### Поля рассылки

| Поле | Обязательное | Описание |
| --- | --- | --- |
| **Название** | да | Имя в менеджере |
| **Шаблон** | да | MODX-шаблон тела письма |
| **Тема письма** | да | Заголовок исходящего письма |
| **Исходящий email** | да | From |
| **Ответный email** | да | Reply-To |
| **Отправитель** | да | Имя отправителя |
| **Включено** | да | Активна ли рассылка |
| **Описание** | нет | Текст в форме подписки |
| **Изображение** | нет | URL картинки рассылки |

![Создание рассылки](https://file.modx.pro/files/a/3/0/a3059d34688e43b4c4c17dc0a750c930.png)

Неактивная рассылка скрыта на сайте, если сниппет вызван без `&showInactive=1`.

## Действия в сетке

| Действие | Описание |
| --- | --- |
| **Изменить** | Редактирование полей и подписчиков |
| **Включить / Выключить** | Переключение `active` |
| **Отправить подписчикам** | Формирует очередь и сразу отправляет письма всем подписчикам (см. ниже) |
| **Удалить** | Удаляет рассылку и связанные записи очереди (каскадно) |

Отправка пропускает неактивных и заблокированных пользователей MODX (`user_id > 0`).

**Отправить подписчикам** вызывает `addQueues()` и немедленный `flush()` — удобно для небольших рассылок. Для тысяч адресатов формируйте очередь отдельно и используйте cron — см. [Очередь писем](queue#отправка-из-менеджера-vs-cron).

## Подписчики

Откройте рассылку → вкладка **Подписчики**.

![Ручное добавление подписчиков](https://file.modx.pro/files/a/5/b/a5b5bc9a4020110a51853f073ad71e48.png)

![Подписчики](https://file.modx.pro/files/2/c/6/2c6b4a5878e3ba8cca8582ef0665a79e.png)

### Добавление одного пользователя

Выберите пользователя MODX в выпадающем списке. Добавляются только пользователи с email в профиле.

![Подписчики](https://file.modx.pro/files/3/f/b/3fb80280c1ca094329af7cac814a185a.png)

![Подписчики](https://file.modx.pro/files/e/f/7/ef782c213e39f644f76ab716ba187663.png)

### Добавление группы

На вкладке **Подписчики** выберите группу MODX. Добавляются только **активные** пользователи с `Profile.blocked = false`. События `sxOnSubscribe` для каждой строки **не вызываются** (массовая операция).

::: info
Для массовой подписки с записью каждой строки в лог используйте цикл `subscribe()` через [PHP API](../integration/api), а не групповую кнопку менеджера.
:::

### Удаление подписчика

Контекстное меню → **Удалить**. Вызывает `unSubscribe` с источником `mgr` и события отписки.

## Экспорт подписчиков

Кнопка **Экспорт** на вкладке подписчиков выгружает CSV через коннектор менеджера (не публичный URL). Доступна при наличии права `edit_document`.

Поля экспорта задаёт настройка [`sendex_export_fields`](../settings#настройки-из-пакета). Скрыть кнопку: [`sendex_hide_export_button`](../settings#настройки-из-пакета).

## Права доступа

| Действие | Право |
| --- | --- |
| Просмотр страницы Sendex | `view_sendex` или `view_document` |
| Создание рассылки | `new_document` |
| Изменение, подписчики, экспорт, отправка | `edit_document` |

::: info
Ключ `view_sendex` проверяется в коде, но transport **не создаёт** отдельную политику. По умолчанию достаточно `view_document`.
:::
