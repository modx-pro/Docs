# Сниппеты

MobileDetect поставляет один сниппет для условного вывода без Fenom.

| Сниппет | Назначение |
| --- | --- |
| [MobileDetect](mobiledetect) | Сравнение текущего типа устройства с параметром `&input` |

## Когда использовать сниппет

| Ситуация | Рекомендация |
| --- | --- |
| Шаблоны через pdoTools/Fenom | Fenom-модификатор `\| mobiledetect` или блоки `{mobile}` |
| Обычные MODX-шаблоны без Fenom | Сниппет `[[!MobileDetect]]` |
| Кэшированная страница, простая разметка | HTML-теги `<standard>` / `<mobile>` |

Подробнее: [Интеграция](../integration).
