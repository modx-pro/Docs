# ResVideoGallery

Адаптивная видеогалерея с Ajax-подгрузкой. У компонента две ветки для разных версий MODX:

- [ResVideoGallery для MODX 3](modx3) — версия 1.x, переписана заново для MODX Revolution 3.x (PHP 8.4 и новее, pdoTools). Видео с YouTube, Vimeo, RuTube, ВКонтакте, Dailymotion, Coub, Google Drive, TikTok, Instagram и Facebook привязываются к ресурсам, посетители добавляют видео по ссылке, авторы управляют своими видео в «Моих видео», администратор проверяет их перед публикацией.
- [ResVideoGallery для MODX 2](modx2) — версия для MODX Revolution 2.x: видео с YouTube, Vimeo, Dailymotion, RuTube, ВКонтакте и Coub, облако тегов, добавление видео с сайта.
