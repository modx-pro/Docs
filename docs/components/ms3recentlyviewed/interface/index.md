# Интерфейс админки

**Вход:** **ms3RecentlyViewed** (родитель `components`) и дочерний пункт **Настройки** — системные настройки пространства имён `ms3recentlyviewed`. Странице нужен `view`. `save_log` только на удаление, не на экспорт.

Контент вкладок при необходимости прокручивается внутри области вкладок.

## Разделы

- [Дашборд](dashboard) — KPI-карточки и топ товаров по просмотрам
- [История просмотров](history) — таблица с фильтрами, удаление записей, экспорт CSV
