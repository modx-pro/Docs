# Интерфейс админки

Пункт меню **«Просмотренные товары»** (ключ `ms3recentlyviewed`, родитель `components`). Дочерний пункт **«Настройки»** открывает системные настройки пространства имён `ms3recentlyviewed`. Странице нужен `view`. Пока ключа `save_log` нет в политике, удаление и экспорт CSV скрыты.

Длинные вкладки прокручиваются внутри своей области.

## Разделы

- [Дашборд](/components/ms3recentlyviewed/interface/dashboard) — KPI-карточки и топ товаров по просмотрам
- [История просмотров](/components/ms3recentlyviewed/interface/history) — таблица с фильтрами, удаление записей, экспорт CSV
