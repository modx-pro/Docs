# Дашборд

Вкладка **«Дашборд»** в меню **«Просмотренные товары»**.

## KPI-карточки

Подписи с экрана:

- **Всего просмотров** — число строк в `ms3recentlyviewed_items`
- **Уник. товары** — `COUNT(DISTINCT product_id)`
- **Уник. пользователи** — авторизованные по `user_id`, гости по `session_id`, если колонка есть
- **Ср. на пользователя** — всего просмотров, делённое на число уникальных пользователей

Под сеткой строка периодов. Это отдельные счётчики, не подсказка карточки.

- **за сегодня** — `DATE(viewed_at) = CURDATE()`
- **за неделю** — последние 7 суток (`INTERVAL 7 DAY`)
- **за месяц** — последние 30 суток (`INTERVAL 30 DAY`)

## Топ просматриваемых товаров (Топ-10)

Десять товаров с наибольшим числом строк в `ms3recentlyviewed_items`. В выборку попадают только ID, которые есть в `ms3_products`.

- Колонки: порядковый номер (#), ID, название, число просмотров
- Сортировка по всем колонкам, включая #
- Ранг обновляется при смене порядка
- Без разбивки на страницы
- Иконка обновления с подсказкой **«Обновить дашборд»** перезагружает данные

KPI, топ и история читают `ms3recentlyviewed_items`. Архив дописывает сводку в `ms3recentlyviewed_monthly` и не снимает детали. Старые строки `items` убирает TTL (`ttl_days`), не архив.
