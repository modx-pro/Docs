# Дашборд

Вкладка **«Дашборд»** в **Extras → ms3RecentlyViewed**.

## KPI-карточки

- **Всего просмотров** — записи в `ms3recentlyviewed_items`. Строка периодов под сеткой KPI (сегодня / неделя / месяц), не подсказка.
- **Уникальных товаров** — число уникальных товаров, которые просматривали
- **Уникальных пользователей** — число уникальных посетителей (`user_id` или `session_id`)
- **Среднее на пользователя** — среднее число просмотров на посетителя

## Топ просматриваемых товаров (Топ-10)

Десять самых просматриваемых товаров.

- Колонки: порядковый номер (#), ID, название, число просмотров
- Сортировка по всем колонкам, включая #
- Ранг обновляется при смене порядка
- Без разбивки на страницы
- Кнопка **«Обновить»** перезагружает данные

KPI, топ и история читают `ms3recentlyviewed_items`. Архив дописывает сводку в `ms3recentlyviewed_monthly` и не снимает детали. Старые строки `items` убирает TTL (`ttl_days`), не архив.
