# Права доступа

## Права

| Право | Действие |
|-------|----------|
| `view` | Просмотр дашборда и истории |
| `save_log` | Удаление и экспорт CSV |

Без **view** коннектор менеджера отвечает 403 `ms3rv_unauthorized`. Без `save_log` кнопки «Удалить выбранные» и «Экспорт CSV» скрыты (`canSaveLog`). `mgr/views/remove`, `mgr/views/removeMultiple` и `mgr/views/export` отвечают JSON `success: false`, не файлом.

Пакет не добавляет ключи в шаблон политики. `view` есть среди обычных прав MODX. `save_log` в поставке нет. Пока ключа нет в политике пользователя, удаление и экспорт остаются закрытыми. У пользователя с sudo MODX пропускает `hasPermission`, кнопки видны.

Чтобы открыть удаление и экспорт, добавьте право `save_log` в шаблон политики и выдайте его роли.
