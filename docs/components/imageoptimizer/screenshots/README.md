# Скриншоты админки ImageOptimizer

PNG лежат в этой папке. В markdown пути вида `/components/imageoptimizer/screenshots/имя.png`.

Снимки сделаны на MODX 3.2 + ImageOptimizer 1.0.4-beta1 (админка Vue 3 + PrimeVue).

| Файл | Что на снимке |
| --- | --- |
| `menu-imageoptimizer.png` | Подменю **Пакеты → ImageOptimizer** |
| `overview.png` | Вкладка **Обзор**: KPI очереди, Live, **Обработать очередь** / **Сбросить зависшие** |
| `queue.png` | Вкладка **Очередь**: toolbar, таблица, фильтр по статусу |
| `queue-rebuild.png` | Диалог **Пересобрать очередь**: source, path, dry-run |
| `settings.png` | Вкладка **Настройки → Общие** |
| `server.png` | Вкладка **Server**: энкодеры, PHP, cron-команда |
| `compatibility.png` | Вкладка **Compatibility**: VueTools, Thumb3x, MS3 |

Обновление скриншотов: открыть `manager/?a=index&namespace=imageoptimizer`, снять вкладки и диалог rebuild.
