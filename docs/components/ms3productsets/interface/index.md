# Интерфейс админки

Управление шаблонами: **Компоненты → Подборки товаров**. Нужен **VueTools**.

![Обзор](/components/ms3productsets/screenshots/page-overview.png)

## Разделы

- [Подборки товаров](templates) — таблица, форма, применение к категории
- [Сценарии (flows)](flows) — пошаговые действия менеджера
- [Руководство по админке](../admin) — полное описание полей и API
- [Права доступа](../permissions)

## Быстрые ссылки

| Действие | Где на экране |
|----------|---------------|
| Создать шаблон | Вкладка **Список подборок** → **Новая подборка** |
| Применить к категории | Вкладка **Применение** → **Применить** |
| Отвязать | Вкладка **Применение** → **Отвязать** |
| Настройки | **Системные настройки** → `ms3productsets` |
