# Права доступа

Право `view` открывает страницу админки `ms3ProductSets`.

## Права

| Право | Действие |
| --- | --- |
| `view` | Страница **Компоненты → Подборки товаров** и все mgr-действия коннектора (`get_templates`, `get_resources`, запись) |
| `save` | Запись через коннектор: `save_template`, `delete_template`, `apply_template`, `unbind_template` |

Это ядровые права MODX, не политика пакета. Нет сессии менеджера: JSON `unauthorized`. Сессия есть, но нет `view`, или запись без `save`: JSON `forbidden`. Страница CMP без `view` отклоняется MODX и строку `forbidden` не печатает. Без `save` чтение шаблонов, товаров и дерева остаётся доступным.

## Назначение

Права задаются в политиках MODX: **Управление → Права доступа**. Назначьте `view` и `save` ролям, которые правят подборки.
