# Права доступа

Доступ к странице админки `ms3ProductSets` в менеджере MODX контролируется правом `view`.

## Права

| Право | Действие |
| --- | --- |
| `view` | Страница **Компоненты → Подборки товаров** и все mgr-действия коннектора (`get_templates`, `get_resources`, запись) |
| `save` | Запись через коннектор: `save_template`, `delete_template`, `apply_template`, `unbind_template` |

Это ядровые права MODX, не политика пакета. Без `view` страница и API отвечают `forbidden`. Без `save` чтение шаблонов доступно, запись нет.

## Назначение

Права задаются в политиках MODX: **Управление → Права доступа**. Назначьте `view` и `save` ролям, которые правят подборки.
