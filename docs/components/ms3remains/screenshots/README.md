# Скриншоты ms3Remains

Положите PNG в эту папку. В документации пути вида `/components/ms3remains/screenshots/имя-файла.png`.

После добавления изображений раскомментируйте строки `![...](...)` в соответствующих markdown-файлах.

| Файл | Что снять | Где используется |
| --- | --- | --- |
| `settings.png` | Меню ms3Remains → **Настройки**: карточки Основные / Заказы / Витрина / Проекция | [settings.md](../settings.md), [quick-start.md](../quick-start.md) |
| `settings-warnings.png` | Те же настройки с видимыми предупреждениями (нет статусов списания, конфликт ms3Variants или inventory) | [settings.md](../settings.md) |
| `product-tab.png` | Вкладка **Остатки** на карточке товара: сетка, Итого, Сохранить | [stocks.md](../stocks.md), [quick-start.md](../quick-start.md) |
| `stocks-list.png` | Раздел **Остатки**: таблица, фильтры, Экспорт/Импорт CSV | [stocks.md](../stocks.md) |
| `remain-edit-dialog.png` | Диалог **Изменить остаток** | [stocks.md](../stocks.md) |
| `csv-import.png` | Диалог импорта CSV: вставка, проверка, Применить импорт | [external-sync.md](../external-sync.md) |
| `storefront-remains.png` | Карточка товара на витрине с выводом сниппета `ms3Remains` | [snippets/ms3Remains.md](../snippets/ms3Remains.md), [quick-start.md](../quick-start.md) |
