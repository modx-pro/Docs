# Решение проблем

## Редактор не появляется на сниппете / чанке

1. Плагин **Ace** включён
2. `which_element_editor = Ace`
3. Кэш менеджера очищен
4. В консоли браузера нет 404 на `assets/components/ace/`

## В ресурсе textarea или TinyMCE вместо Ace

Ожидаемо:

- `use_editor = Да` и richtext включён: Ace `#ta` не занимает. Своего RTE-инициализатора у пакета нет
- `use_editor = Да` и `which_editor` не `Ace`: у ресурса без richtext остаётся обычный textarea

Чтобы Ace стоял на content у всех ресурсов, поставьте `use_editor = Нет`. [Интеграция](integration#ресурсы-и-rte).

Проверьте **контекстные** значения `use_editor` / `which_editor`, не только глобальные.

## Fullscreen перекрыт панелями MODX 3

Обновите Ace до **1.9.11**: редактор уходит в `document.body`, z-index `12000`. Отступы считаются по `#modx-header` и `#modx-action-buttons`. Пока расчёт не выполнен, остаются `top: 60px` и `left: 70px`.

## Ctrl+S в fullscreen сохраняет старый текст

Исправлено в **1.9.10**: скрытое поле остаётся в форме, перед submit вызывается `getValue()`. С **1.9.11** у сниппета и плагина `<?php` в редакторе после сохранения остаётся, если MODX снял только обёртку. Undo не сбрасывается. После перезагрузки показывается текст из базы, уже без обёртки.

## Подсветка комментариев CSS ломается (`<!--` вместо `//`)

В **1.9.10** mixed-mode MODX включается только для HTML/Smarty/Twig mime. Обновите пакет или не задавайте HTML-mime для CSS-чанков.

## Tab-сниппеты не раскрываются

1. Настройка `ace.snippets` не пустая (после 1.9.10 набор по умолчанию пишется при пустом значении)
2. Курсор после имени сниппета, затем **Tab**
3. В определении сниппета отступы: настоящий Tab (**Alt+09**), не пробелы

## Черновик не предлагается

`ace.draft_restore = Да`. Баннер не показывается, если черновик пустой или совпадает с открытым текстом. После успешного сохранения черновик очищается. TTL: 7 дней. Данные только в браузере пользователя (localStorage).

## Ошибка установки / Zip / preserved

На **1.9.7+** PREEXISTING_MODE = REMOVE_PREEXISTING. Обновите Ace или удалите битый `.preserved.zip` и повторите установку.

## PHP worker ругается на `??`

Исправлено в **1.9.9** (ace-builds worker 1.37.5). Обновите пакет.

## Часто задаваемые вопросы

### Ace и TinyMCE одновременно?

Да. Другой RTE для richtext-ресурсов, Ace для элементов. При `use_editor = Да` Ace не занимает `#ta` у richtext-ресурса и у ресурса, чей `which_editor` не `Ace`.

### Нужен ли composer на сервере?

Нет на рабочем сайте. `composer` / `npm test` только для разработки пакета.
