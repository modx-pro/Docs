# Решение проблем

Типичные сбои Ace и что проверить.

## Редактор не появляется на сниппете / чанке

1. Плагин **Ace** включён
2. `which_element_editor = Ace`
3. Кэш менеджера очищен
4. В консоли браузера нет 404 на `assets/components/ace/`

## В ресурсе textarea или TinyMCE вместо Ace

Ожидаемо при другой связке RTE:

- `use_editor = Да` и `which_editor` ≠ Ace → Ace **не** занимает `#ta`
- richtext включён → работает выбранный RTE

Чтобы код в content шёл через Ace: `use_editor = Нет` или `which_editor = Ace`. [Интеграция](integration#ресурсы-и-rte).

Проверьте **контекстные** значения `use_editor` / `which_editor`, не только глобальные.

## Fullscreen перекрыт панелями MODX 3

Обновите Ace до **1.9.9+**: редактор уходит в `document.body` с корректным z-index. На 3.1+ insets оставляют шапку менеджера видимой.

## Ctrl+S в fullscreen сохраняет старый текст

Исправлено в **1.9.10**: скрытое поле остаётся в форме, перед submit вызывается `getValue()`. Обновите пакет.

## Подсветка комментариев CSS ломается (`<!--` вместо `//`)

В **1.9.10** mixed-mode MODX включается только для HTML/Smarty/Twig mime. Обновите пакет или не задавайте HTML-mime для CSS-чанков.

## Tab-сниппеты не раскрываются

1. Настройка `ace.snippets` не пустая (после 1.9.10 defaults пишутся при пустом значении)
2. Курсор после имени сниппета, затем **Tab**
3. В определении сниппета отступы: настоящий Tab (**Alt+09**), не пробелы

## Черновик не предлагается

`ace.draft_restore = Да`. Пустой черновик не показывается. После успешного save черновик очищается. TTL: 7 дней. Данные только в браузере пользователя (localStorage).

## Ошибка установки / Zip / preserved

На **1.9.7+** PREEXISTING_MODE = REMOVE_PREEXISTING. Обновите Ace или удалите битый `.preserved.zip` и повторите установку.

## PHP worker ругается на `??`

Исправлено в **1.9.9** (ace-builds worker 1.37.5). Обновите пакет.

## Часто задаваемые вопросы

### Ace и TinyMCE одновременно?

Да. TinyMCE (или другой RTE) для richtext-ресурсов, Ace для элементов. С 1.9.10 Ace не занимает `#ta`, если `which_editor` ≠ Ace.

### Нужен ли composer на сервере?

Нет для продакшена. `composer` / `npm test` только для разработки пакета.
