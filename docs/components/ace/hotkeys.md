# Горячие клавиши

Полный список команд Ace в менеджере: **Ctrl+Alt+H** в фокусе редактора. Emmet добавляет свои пункты в ту же таблицу.

Частые сочетания для работы с MODX:

## Ace и пакет

| Сочетание | Действие |
| --- | --- |
| **Ctrl+Alt+H** | Таблица горячих клавиш |
| **Ctrl+Shift+B** | Форматирование кода |
| **Alt+Z** | Вкл/выкл перенос строк (`word_wrap`) |
| **Ctrl+F11** | Полноэкранный режим (Windows/Linux) |
| **Cmd+F12** | Полноэкранный режим (Mac) |
| **Ctrl+Space** | Автодополнение MODX / PHP |
| **Tab** | Развернуть Tab-сниппет (`ace.snippets`) или отступ |
| **Alt+W** | Emmet: wrap with abbreviation |
| **Ctrl+S** / **Cmd+S** | Сохранение формы (в fullscreen с 1.9.10 синхронизируется корректно) |

## Набор Ace (базовый)

| Сочетание | Действие |
| --- | --- |
| Ctrl+F | Поиск |
| Ctrl+H | Замена |
| Ctrl+G | Перейти к строке |
| Ctrl+/ | Комментировать |
| Ctrl+D | Выделить следующее вхождение |
| Ctrl+Alt+↑ / ↓ | Мультикурсор |
| Ctrl+L | Выделить строку |

Точный список зависит от версии ace-builds в пакете и раскладки ОС. Ориентир: окно **Ctrl+Alt+H**.

## Fullscreen в MODX 3

В максимизированном режиме редактор переносится в `document.body` с высоким z-index, чтобы панели менеджера не перекрывали код. Отступы `.ace_maximized` оставляют видимыми верхнюю панель и дерево.
