# Вкладка вариантов в товаре

## Где вкладка

Вкладка **Варианты** — в карточке товара в админке, после встроенных вкладок MiniShop3 («Свойства товара», «Галерея», «Категории», «Связи», «Опции товара»).

- При создании товара вкладки нет: сохраните товар и откройте его снова.
- Нужен пакет VueTools. Без него вкладки нет, а в журнале ошибок MODX появляется запись `[ms3Variants] VueTools not found`.

## Список вариантов

| Колонка | Что показывает |
|---------|----------------|
| Активен | Флажок: снятый — вариант не выводится на сайте |
| Изображение | Миниатюра изображения варианта |
| Артикул | Артикул варианта; пусто — «-» |
| Опции | Значения опций варианта |
| Цена | Цена и старая цена; пустая старая цена не выводится |
| Остаток | Остаток варианта |
| — | Кнопки редактирования и удаления |

Варианты идут в порядке создания, поменять порядок на вкладке нельзя. Кнопка с круговой стрелкой рядом с «Создать вариант» обновляет список.

Под списком — «Всего вариантов», «Активных вариантов» и «Общий остаток». Общий остаток считается по всем вариантам, включая неактивные.

## Окно варианта

Кнопка **Создать вариант** открывает окно нового варианта, кнопка с карандашом в строке — окно существующего.

| Поле | Обязательное | Что важно знать |
|------|--------------|-----------------|
| Опции | при создании | Хотя бы одна опция. При редактировании можно удалить все опции — сервер это не запрещает, и у варианта на сайте не будет подписи опций |
| Артикул | нет | Не создаётся автоматически и не проверяется на уникальность |
| Цена | нет | По умолчанию 0 |
| Старая цена | нет | Цена до скидки |
| Остаток | нет | По умолчанию 0 |
| Вес | нет | В единицах веса MiniShop3. Если больше 0, заменяет вес позиции в корзине |
| Изображение | нет | Из галереи товара |
| Активен | — | Новый вариант всегда создаётся активным. Выключить можно здесь или флажком в списке — там изменение сохраняется сразу |

Ошибки сохранения показываются в окне под полем «Опции»:

| Сообщение | Когда |
|-----------|-------|
| «Укажите хотя бы одну опцию» | При создании варианта без опций |
| «Вариант с такими опциями уже существует» | Такой набор опций уже у другого активного варианта |
| «Вариант не найден» | Вариант удалён, например в другой вкладке браузера |
| «Ошибка» | Не удалось записать вариант в базу — подробности в журнале ошибок MODX |

::: warning Очистка цены или остатка не сохраняется
Если стереть цену или остаток у существующего варианта и сохранить, останется прежнее значение, а в журнал ошибок MODX запишется ошибка. Чтобы обнулить значение, введите `0`.
:::

## Опции варианта

1. Выберите ключ опции в выпадающем списке.
2. Введите значение — список подсказывает значения, уже заданные у товаров магазина, но можно ввести любое.
3. Нажмите «+» или Enter.

В списке ключей — опции из справочника опций MiniShop3 и ключи, уже заданные у любых товаров магазина, без учёта категории. Нового ключа на вкладке ввести нельзя: сначала создайте опцию в MiniShop3.

Вариант с таким же набором опций, как у другого активного варианта товара, не сохранится: «Вариант с такими опциями уже существует». С неактивным вариантом сочетание не сравнивается.

Значения опций при сохранении варианта добавляются в опции товара MiniShop3, а значения опций с ключами `color`, `size` и `tags` — ещё и в одноимённые поля данных товара. При изменении и удалении варианта старые значения из товара не убираются.

## Изображение варианта

Нажмите «Выбрать из галереи» и выберите изображение. Доступны только изображения из галереи этого товара: сначала загрузите их на вкладке **Галерея**. Если галерея пуста, окно выбора покажет «No images in gallery».

## Удаление варианта

Нажмите кнопку удаления в строке и подтвердите. Удаление необратимо.

Позиции корзин и заказов с этим вариантом остаются. В позициях заказов остаются опции и цена на момент покупки. Если покупатель изменит количество такой позиции в корзине, при включённом контроле остатков получит «Варианта нет в наличии».

Если удаление не прошло (например, вариант уже удалён в другой вкладке), сообщения об ошибке нет — обновите список кнопкой с круговой стрелкой и проверьте.

## Изменения на сайте

Неактивный вариант не выводится на сайте, и его нельзя добавить в корзину. Позиции, которые уже лежат в корзинах, остаются. Изменения вариантов не сбрасывают кэш страниц: если сниппет на странице товара вызван кэшируемым, очистите кэш сайта — см. [Сниппеты](../snippets).
