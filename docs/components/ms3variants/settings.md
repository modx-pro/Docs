# Системные настройки

Настройки находятся в разделе **Системные настройки**, пространство имён `ms3variants`.

| Ключ | По умолчанию | Что делает |
|------|--------------|------------|
| `ms3variants_check_stock` | Да | Запрещает продажу сверх остатка и включает списание остатков |
| `ms3variants_show_out_of_stock` | Да | Показывает закончившиеся варианты |
| `ms3variants_deduct_stock_status` | `2` | Статус заказа, в котором списываются остатки |
| `ms3variants_enabled` | Да | В текущей версии не действует |
| `ms3variants_default_active` | Да | В текущей версии не действует |
| `ms3variants_sku_pattern` | `{product_article}-{option_values}` | В текущей версии не действует |

## Остатки

### ms3variants_check_stock

Контроль остатков вариантов. По умолчанию — Да.

| | Да | Нет |
|---|---|---|
| Добавление в корзину и изменение количества сверх остатка | запрещено: MiniShop3 вернёт ошибку «Варианта нет в наличии», в том числе когда остаток больше нуля, но меньше запрошенного | разрешено |
| Списание остатков по статусу заказа | работает (см. [`ms3variants_deduct_stock_status`](#ms3variants_deduct_stock_status)) | **не работает** |
| Вариант с остатком 0 | не в наличии | в наличии: стандартные чанки покажут «В наличии: 0» |
| Скрытие закончившихся ([`ms3variants_show_out_of_stock`](#ms3variants_show_out_of_stock)) | скрывает варианты с остатком 0 | скрывает только неактивные варианты |

::: warning «Нет» отключает и списание
При значении Нет остатки вариантов не уменьшаются ни в каком статусе заказа, даже если задан `ms3variants_deduct_stock_status`. Списывать остатки и при этом разрешить продажу сверх остатка нельзя.
:::

### ms3variants_show_out_of_stock

Показывать ли варианты, которых нет в наличии. По умолчанию — Да.

- **Да** — показываются все активные варианты. Неактивные на сайте не выводятся при любом значении, кроме вызова сниппета с `activeOnly` = 0. Стандартные чанки отмечают закончившиеся «Нет в наличии». В каталоге кнопка добавления у них заблокирована, но только при включённом контроле остатков: при `ms3variants_check_stock` = Нет вариант с остатком 0 считается «в наличии». На странице товара — нет: покупатель выберет вариант, а сервер откажет при добавлении в корзину.
- **Нет** — закончившиеся и неактивные варианты скрыты на странице товара и в каталоге.

Настройка не действует на `available_options` и `options_json` сниппета `msProductVariants` и на админку: значения скрытых вариантов остаются в списке опций.

### ms3variants_deduct_stock_status

ID статуса заказа, при переходе в который остатки вариантов уменьшаются на количество из заказа. По умолчанию — `2`. Значение `0` отключает списание.

Статусы MiniShop3 после установки:

| ID | Статус |
|----|--------|
| 1 | Черновик |
| 2 | Новый |
| 3 | Оплачен |
| 4 | Отправлен |
| 5 | Отменен |

::: warning По умолчанию остатки списываются при оформлении заказа, до оплаты
Значение `2` — это статус «Новый», а не «Оплачен». Оформление заказа переводит его из «Черновик» в «Новый», и в этот момент остатки списываются. Чтобы списывать после оплаты, укажите `3`. ID статусов на вашем сайте — в таблице «Статусы заказа» на странице **MiniShop3 → Настройки**.
:::

Как работает списание:

- только при переходе ровно в этот статус. Если заказ перешёл, например, из «Новый» сразу в «Отправлен», а в настройке «Оплачен», остатки не спишутся;
- при отмене заказа остатки не возвращаются — верните их вручную на вкладке «Варианты» товара;
- если заказ снова перейдёт в этот статус, остатки спишутся ещё раз;
- остаток не уходит ниже нуля;
- меняются только остатки вариантов. Остаток товара в MiniShop3 и позиции заказа без варианта не затрагиваются. Складской учёт MiniShop3 (`ms3_inventory_enabled`) ведёт остаток товара отдельно;
- при [`ms3variants_check_stock`](#ms3variants_check_stock) = Нет списание не работает.

## Не действуют в текущей версии

Настройки есть в списке, но компонент их не читает: значение ни на что не влияет.

### ms3variants_enabled

Компонент работает при любом значении.

### ms3variants_default_active

Новый вариант всегда создаётся активным. Чтобы выключить вариант, снимите флажок «Активен» в окне варианта.

### ms3variants_sku_pattern

Артикул варианта автоматически не создаётся: если не заполнить поле «Артикул», вариант сохранится без артикула.
