# Скидка для группы покупателей

Результат: скидку видят и получают только авторизованные покупатели из выбранных групп, например оптовики.

## Шаги

1. Откройте **Компоненты → Скидки** и нажмите **Новая скидка**.
2. Заполните **Название**, например «Оптовая скидка 10%».
3. В поле **Применяется к** выберите область акции или оставьте «Все товары».
4. В поле **Скидка** введите размер, например `10`. В поле **Тип** оставьте «Процент».
5. Раскройте **Дополнительные условия**. В блоке «Условия применения» нажмите **Добавить условие**: тип «Группа пользователя», оператор `in`, значение — нужные группы из списка.
6. Нажмите **Сохранить** и очистите кэш MODX.

## Как это работает

Движок сравнивает группы текущего пользователя со списком из условия. Гости и покупатели из других групп правило не проходят: ни бейджа на витрине, ни скидки в корзине.

## Проверка

В панели **Проверить** выберите товар и пользователя из нужной группы. Затем повторите проверку с гостем: правило должно отклониться с причиной по условию группы.

## Если не работает

- Скидка видна всем: проверьте, что условие добавлено в блок «Условия применения», а не в «Исключения».
- Скидка не видна нужной группе: пользователь должен быть авторизован и состоять в группе. Проверьте членство в разделе «Пользователи» панели MODX.
- После смены групп у пользователя скидка не изменилась: очистите кэш MODX и пересчитайте корзину, изменив её состав.
