# Скидка на категорию в процентах

Результат: товары выбранных категорий продаются со скидкой в процентах. Бейдж виден в каталоге и на карточке товара, корзина пересчитывает цену автоматически.

## Шаги

1. Откройте **Компоненты → Скидки** и нажмите **Новая скидка**.
2. Заполните **Название**, например «Скидка 15% на посуду».
3. В поле **Применяется к** выберите «Категория». В поле **Выбрать** найдите по названию и отметьте нужные категории.
4. В поле **Тип** оставьте «Процент». В поле **Скидка** введите число, например `15`.
5. Задайте **Период**, если акция ограничена датами.
6. Нажмите **Сохранить** и очистите кэш MODX.

## Проверка

Кнопка **Проверить** внизу формы открывает панель тестирования. Выберите товар из категории: панель покажет базовую цену, цену со скидкой и применённое правило.

## Как это работает

Движок применяет процент к базовой цене каждой подходящей строки корзины. Учитываются и основная категория товара, и дополнительные связи товара с категориями. Флаги «Показывать в каталоге» и «Показывать на товаре» включены по умолчанию, поэтому бейдж появляется сразу после очистки кэша.

## Если не работает

- Нет бейджа в каталоге: вызовите `ms3discountsGetDiscount` в чанке строки `msProducts` с параметром `id` товара. Цены в строках пересчитывает плагин без дополнительных вызовов. См. [ms3discountsGetDiscount](../snippets/ms3discountsGetDiscount).
- В корзине цена прежняя: очистите кэш MODX и измените состав корзины для запуска пересчёта.
- Скидка не подошла части товаров категории: откройте вкладку «Трассировка» в панели **Проверить** (нужно право `ms3discounts_debug`) и посмотрите, какое условие отклонило товар.
