# Подарок к заказу

Результат: при выполнении условия в корзину добавляется подарочный товар отдельной строкой с ценой 0.

## Шаги

1. Откройте **Компоненты → Скидки** и нажмите **Новая скидка**.
2. Заполните **Название**, например «Подарок от 5000».
3. В поле **Тип** выберите «Подарок». Форма заменит поле значения на два поля.
4. В поле **Подарок** найдите по названию и выберите товар, который уйдёт в подарок. В поле **Количество** задайте число штук.
5. Раскройте **Дополнительные условия**. В блоке «Условия применения» нажмите **Добавить условие**: тип «Корзина», поле «Сумма», оператор `>=`, значение `5000`.
6. Нажмите **Сохранить** и очистите кэш MODX.

## Как это работает

Подарок появляется, только когда в корзине есть товары, подходящие под правило, и все условия выполнены. Подарочная строка получает цену 0 и отметку `ms3discounts_gift = true` в свойствах позиции. Если покупатель удаляет основные товары или сумма падает ниже порога, плагин удаляет подарок при следующем пересчёте.

Поле **Применяется к** у такого правила обычно оставляют в значении «Все товары»: тогда подарок даётся к любому составу корзины.

## Если не работает

- Подарок не добавился: проверьте условие по сумме в панели **Проверить**. По умолчанию сумма считается по всей корзине. Чтобы считать только позиции под правилом, смените в условии поле **Область** на «Подходящие товары».
- Подарок пропал после изменения корзины: это штатное поведение. Условие перестало выполняться, и плагин убрал подарочную строку.
- Подарочный товар не выбирается в поле **Подарок**: товар должен существовать в каталоге MiniShop3 и быть опубликован.
