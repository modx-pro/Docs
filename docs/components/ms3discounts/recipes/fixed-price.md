# Фиксированная цена на товар

Результат: выбранные товары продаются по точной цене независимо от базовой. Подходит для распродаж вида «всё по 990».

## Шаги

1. Откройте **Компоненты → Скидки** и нажмите **Новая скидка**.
2. Заполните **Название**, например «Всё по 990».
3. В поле **Применяется к** выберите «Товар» и отметьте товары в поле **Выбрать**. Для категории или производителя выберите соответствующий вариант.
4. В поле **Тип** выберите «Фиксированная цена». В поле **Скидка** введите итоговую цену, например `990`.
5. Нажмите **Сохранить** и очистите кэш MODX.

## Как это работает

Движок устанавливает цену единицы товара равной заданному значению. Если базовая цена товара ниже заданной, она не меняется: акция никогда не повышает цену.

Тип «Фиксированная сумма» работает иначе: вычитает из цены сумму в валюте на единицу товара. Выберите его, если выгода должна быть одинаковой для товаров с разной ценой.

## Если не работает

- Цена товара не изменилась: проверьте, что заданная цена ниже базовой цены товара.
- Скидку перекрыла другая акция: откройте вкладку «Трассировка» в панели **Проверить** и сравните политики и приоритеты правил. См. [Политики и приоритет](../index).
