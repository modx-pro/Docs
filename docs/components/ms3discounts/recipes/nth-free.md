# Каждый N-й товар бесплатно

Результат: покупатель получает каждый N-й товар из подходящих бесплатно или со скидкой. Классическая акция вида «1 + 1 = 3».

## Шаги

1. Откройте **Компоненты → Скидки** и нажмите **Новая скидка**.
2. Заполните **Название**, например «Каждый третий бесплатно».
3. В поле **Применяется к** выберите область акции: категорию, товары или производителя. Для акции на весь каталог оставьте «Все товары».
4. В поле **Тип** выберите «N-й товар». Форма заменит поле значения на два поля.
5. В поле **Каждый N-й** введите порог, например `3`. Минимальное значение: 2.
6. В поле **Скидка на N-й товар, %** оставьте `100` для бесплатного товара или введите процент, например `50`.
7. Нажмите **Сохранить** и очистите кэш MODX.

## Как это работает

Движок сортирует все подходящие единицы товара в корзине от дешёвых к дорогим и применяет скидку к каждой N-й штуке. При трёх одинаковых футболках и пороге 3 бесплатной будет одна. Если подходящих единиц меньше порога, скидка не применяется. Схема сортировки: [FAQ](../faq).

## Проверка

В панели **Проверить** выберите товар и задайте количество не меньше порога. Панель покажет сумму скидки на строку.

## Если не работает

- Скидка не появилась в корзине: проверьте, что подходящих единиц не меньше порога. Две штуки одного товара и две штуки разных товаров из одной категории считаются вместе.
- Скидка досталась не тому товару: так задумано. Дешёвые единицы идут первыми, поэтому выгода выпадает на самые дешёвые штуки.
- На карточке товара бейдж не показывает выгоду: скидка типа «N-й товар» считается по составу корзины, а не по единице товара. Проверяйте такую акцию в корзине.
