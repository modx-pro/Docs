# Скидка по расписанию

Результат: акция действует только в заданные дни недели и часы, например «счастливые часы» по будням с 12:00 до 15:00.

## Шаги

1. Откройте **Компоненты → Скидки** и нажмите **Новая скидка**.
2. Заполните **Название**, например «Счастливые часы».
3. В поле **Применяется к** выберите область акции или оставьте «Все товары».
4. В поле **Скидка** введите размер, например `10`. В поле **Тип** оставьте «Процент».
5. Раскройте **Дополнительные условия**. В полях **Время** задайте окно: «С» — `12:00`, «До» — `15:00`.
6. В поле **Дни недели** отметьте дни с понедельника по пятницу.
7. Нажмите **Сохранить** и очистите кэш MODX.

## Как это работает

Движок сверяет текущее время сервера с окном и днями недели. Пустые поля времени означают весь день, пустой список дней — все дни. Общий срок акции задаётся отдельно полем **Период**: вне этих дат правило отключено независимо от расписания.

## Проверка

Панель **Проверить** оценивает правило по текущему времени сервера. Если акция сейчас вне расписания, правило отклонится с причиной «Не в периоде действия».

## Если не работает

- Акция не началась вовремя: проверьте часовой пояс сервера. Расписание сверяется с серверным временем, а не с временем покупателя.
- Акция работает в лишние дни: проверьте, что в поле **Дни недели** отмечены только нужные дни. Пустой список снимает ограничение.
- Акция завершилась раньше срока: проверьте дату окончания в поле **Период**.
