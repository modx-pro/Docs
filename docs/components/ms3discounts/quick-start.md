# Быстрый старт

Установите пакет, создайте правило и проверьте скидку на карточке и в корзине.

```mermaid
flowchart LR
  A["1. Панель управления<br>Создание правила"] --> B["2. Витрина<br>Вывод бейджа скидки"]
  B --> C["3. Корзина<br>Автоматический пересчёт"]
```

## Шаг 1. Установите пакет

1. Установите MiniShop3 1.13.0 и новее, VueTools 1.2.0 и новее. Для стандартных Fenom-чанков установите pdoTools 3.0.0 и новее.
2. Установите ms3Discounts через менеджер пакетов. [Подключите репозиторий ModStore](https://modstore.pro/info/connection): transport зашифрован, без провайдера `modstore.pro` установка падает с `Package provider not found`.
3. Очистите кэш MODX.

После установки появляются:

- пункт меню **Компоненты → Скидки**
- плагин на событиях корзины MiniShop3
- сниппеты `ms3discounts`, `ms3discountsGetDiscount`, `ms3discountsBuyNow`
- политика доступа `ms3DiscountsManagerPolicy`

Для перехода в раздел требуется системное право `ms3discounts_view`.

## Шаг 2. Включите компонент

В системных настройках найдите ключи `ms3discounts_*` и оставьте `ms3discounts_enabled` включённым. Описание параметров: [Системные настройки](settings).

## Шаг 3. Создайте правило

<!-- ![Форма создания правила](/components/ms3discounts/screenshots/discount-drawer-main.png) -->

Откройте **Компоненты → Скидки**. Нажмите **Новая скидка**. Заполните название. В блоке «Применяется к» выберите товары, категории или производители. Укажите тип действия, значение и политику.

При необходимости задайте период (`date_start`, `date_end`), расписание (время и дни недели), контексты, приоритет и дополнительные условия в конструкторе правил. Поля формы: [Панель управления](manager). Сохраните форму.

Кнопка **Проверить** открывает превью расчёта цены выбранного товара.

## Шаг 4. Выведите скидку на карточке

<!-- ![Бейдж скидки на карточке товара](/components/ms3discounts/screenshots/storefront-badge.png) -->

В шаблоне товара вызовите сниппет некэшируемым.

::: code-group

```fenom
{'!ms3discountsGetDiscount' | snippet : ['id' => $_modx->resource.id]}
```

```modx
[[!ms3discountsGetDiscount? &id=`[[*id]]`]]
```

:::

Параметры и плейсхолдеры: [ms3discountsGetDiscount](snippets/ms3discountsGetDiscount).

## Шаг 5. Проверьте корзину

<!-- ![Скидка в корзине MiniShop3](/components/ms3discounts/screenshots/cart-discount.png) -->

Сниппет в чанк корзины не ставьте. Добавьте товар в корзину. Плагин автоматически пересчитает `price` и `cost` позиции. Базовая цена и сумма скидки сохраняются в `properties`.

После изменения правил скидок измените состав корзины или перейдите к оформлению заказа для запуска пересчёта. Как устроен механизм: [Интеграция](integration).
