# Быстрый старт

Установите пакет, создайте правило и проверьте скидку на карточке и в корзине.

## Шаг 1. Установите пакет

1. Установите MiniShop3, VueTools и pdoTools.
2. Установите ms3Discounts через менеджер пакетов.
3. Очистите кэш MODX.

После установки появляются:

- меню **Скидки**
- плагин на событиях корзины MiniShop3
- сниппеты `ms3discounts`, `ms3discountsGetDiscount`, `ms3discountsBuyNow`
- политика `ms3DiscountsManagerPolicy`

Без права `ms3discounts_view` меню не откроется.

## Шаг 2. Включите компонент

В системных настройках найдите ключи `ms3discounts_*` и оставьте `ms3discounts_enabled` включённым. Описание ключей: [Системные настройки](settings).

## Шаг 3. Создайте правило

Откройте **Компоненты → Скидки**. Нажмите **Новая скидка**. Заполните название, тип действия, значение и политику. Укажите товары, категории или производителей. При необходимости задайте период (`date_start`, `date_end`, время, дни недели, контексты) и флаг «только после активации». Сохраните.

Кнопка **Проверить** считает цену для выбранного товара и количества.

## Шаг 4. Выведите скидку на карточке

В шаблоне товара вызовите сниппет некэшируемым.

::: code-group

```fenom
{'!ms3discountsGetDiscount' | snippet : ['id' => $_modx->resource.id]}
```

```modx
[[!ms3discountsGetDiscount? &id=`[[*id]]`]]
```

:::

Параметры и плейсхолдеры: [ms3discountsGetDiscount](snippets/ms3discountsGetDiscount).

## Шаг 5. Проверьте корзину

Сниппет в чанк корзины не ставьте. Добавьте товар. Плагин перепишет `price` и `cost` позиции. Зачёркнутая цена и сумма скидки лежат в `properties`. Отдельного JS корзины нет.

После правки правила снова измените корзину или перейдите к оформлению. Как устроен пересчёт: [Интеграция](integration).
