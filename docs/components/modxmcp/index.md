# MODXMCP

**MODXMCP** — компонент для подключения внешних ИИ-агентов к **MODX Revolution 2.8.x** через **Model Context Protocol (MCP)**.

Он предоставляет агенту специализированный интерфейс для работы с ресурсами, шаблонами, чанками, сниппетами, TV-полями, системными настройками и другими сущностями MODX.

> [!WARNING]
> **MODXMCP не является готовым ИИ-агентом и сам по себе не добавляет искусственный интеллект в MODX.**
>
> После установки компонента в менеджере MODX не появляется чат для постановки задач. ИИ-агент и пользовательский интерфейс настраиваются отдельно.

Общая схема работы:

```text
Пользователь → ИИ-агент → MODXMCP → MODX
```

## Возможности

В версии **1.2.0** реализовано **192 операции**: 81 операция чтения и 111 изменяющих операций.

Поддерживается работа с:

- ресурсами и структурой сайта;
- шаблонами, чанками и сниппетами;
- плагинами;
- TV-полями;
- системными настройками;
- пользователями и группами;
- политиками доступа и шаблонами политик;
- группами ресурсов и их составом;
- источниками файлов;
- пакетами и дополнениями;
- настройками ClientConfig;
- MIGX;
- miniShop2;
- VersionX;
- VirtualPage.

MODXMCP также позволяет анализировать связи между элементами сайта с помощью графа зависимостей.

В версии 1.2.0 добавлена защита от записи по устаревшему состоянию сайта. Агент может получить текущую ревизию проекта, а перед изменением MODXMCP проверяет, что состояние не изменилось. Если данные уже были изменены другим агентом или процессом, операция отклоняется с ошибкой `STALE_STATE` вместо записи поверх более свежего состояния.

Часть потенциально опасных возможностей можно ограничивать или отключать настройками компонента.

## Установка

Транспортный пакет можно скачать из [релизов проекта на GitHub](https://github.com/rumata-estor/modx3-mcp/releases).

Для MODX Revolution 2.8.x используется пакет:

```text
modxmcp-1.2.0-pl.transport.zip
```

Установите пакет стандартным способом через менеджер пакетов MODX.

При первой установке компонент автоматически создаёт API-токен `modxmcp.api_token`, необходимый для доступа к MODXMCP.
