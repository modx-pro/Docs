# MODX MCP

**MODX MCP** — компонент для подключения внешних ИИ-агентов к **MODX Revolution 3.x** через **Model Context Protocol (MCP)**.

Он предоставляет агенту специализированный интерфейс для работы с ресурсами, шаблонами, чанками, сниппетами, TV-полями, системными настройками и другими сущностями MODX.

> [!WARNING]
> **MODX MCP не является готовым ИИ-агентом и сам по себе не добавляет искусственный интеллект в MODX.**
>
> После установки компонента в менеджере MODX не появляется чат для постановки задач. ИИ-агент и пользовательский интерфейс настраиваются отдельно.

Общая схема работы:

```text
Пользователь → ИИ-агент → MODX MCP → MODX
```

## Возможности

В текущей версии реализовано более **180 операций** для чтения, анализа и изменения данных MODX.

Поддерживается работа с:

- ресурсами и структурой сайта;
- шаблонами, чанками и сниппетами;
- плагинами;
- TV-полями;
- системными настройками;
- пользователями и группами;
- источниками файлов;
- пакетами и дополнениями;
- MIGX;
- miniShop2;
- VersionX;
- VirtualPage.

MODX MCP также позволяет анализировать связи между элементами сайта с помощью графа зависимостей.

Часть потенциально опасных возможностей можно ограничивать или отключать настройками компонента.

## Установка

Рекомендуемый способ — установить **MODX3MCP** как обычное дополнение через менеджер пакетов MODX из репозитория **modstore.pro**.

Также транспортный пакет можно скачать вручную из [релизов проекта на GitHub](https://github.com/rumata-estor/modx3-mcp/releases).

Для MODX Revolution 3.x используется пакет:

```text
modx3mcp-1.1.0-pl.transport.zip
```

> [!WARNING]
> Пакет `modxmcp-*.transport.zip` предназначен для MODX Revolution 2.8.x.

При первой установке компонент автоматически создаёт API-токен `modxmcp.api_token`, необходимый для доступа к MODX MCP.

## Совместимость

- MODX Revolution 3.2 и новее;
- PHP 8.1 и новее.

Для MODX Revolution 2.8.x выпускается отдельный транспортный пакет.
