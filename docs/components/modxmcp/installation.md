# Установка

Эта страница описывает установку **MODX MCP для MODX Revolution 3.x**.

## Требования

- MODX Revolution 3.2 или новее;
- PHP 8.1 или новее.

## Установка через Modstore

Рекомендуемый способ — установить MODX MCP как обычное дополнение через менеджер пакетов MODX.

1. Откройте **Пакеты → Установщик**.
2. Выберите репозиторий **modstore.pro**.
3. Найдите **MODX3MCP**.
4. Скачайте пакет.
5. Выполните установку.

Если репозиторий modstore.pro ещё не подключён к MODX, сначала добавьте его в список поставщиков пакетов.

После установки рекомендуется очистить кэш MODX.

## Установка транспортного пакета вручную

При необходимости пакет можно установить вручную.

Готовые транспортные пакеты находятся в релизах проекта:

[github.com/rumata-estor/modx3-mcp/releases](https://github.com/rumata-estor/modx3-mcp/releases)

Для MODX Revolution 3.x используется пакет:

```text
modx3mcp-1.1.0-pl.transport.zip
```

Загрузите архив через стандартный установщик пакетов MODX и выполните установку.

> [!WARNING]
> Для MODX 3 используйте пакет `modx3mcp-*.transport.zip`.
>
> Пакет `modxmcp-*.transport.zip` предназначен для MODX Revolution 2.8.x.

## Что создаётся при установке

MODX MCP создаёт необходимые системные настройки.

Также при первой установке автоматически генерируется API-токен:

```text
modxmcp.api_token
```

Токен можно посмотреть:

- в системных настройках MODX, выбрав пространство имён `modxmcp`;
- в интерфейсе компонента MODX MCP.

При обновлении существующий API-токен сохраняется и автоматически не заменяется.

> [!WARNING]
> API-токен является секретом доступа к MODX MCP. Не публикуйте его и не храните в открытых репозиториях.

## Проверка установки

После установки:

1. очистите кэш MODX;
2. откройте MODX MCP в менеджере;
3. убедитесь, что компонент открывается без ошибок;
4. проверьте наличие системных настроек пространства имён `modxmcp`;
5. убедитесь, что значение `modxmcp.api_token` создано.

На этом установка MODX-части завершена.

Настройка внешнего ИИ-агента и MCP-клиента выполняется отдельно.
