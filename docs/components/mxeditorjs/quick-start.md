# Быстрый старт

Как включить mxEditorJs в MODX 3.

## Требования

| Требование | Версия |
| --- | --- |
| MODX Revolution | 3.0.3+ |
| PHP | 8.2+ |

## Шаг 1: Установка

1. Установите пакет **mxEditorJs** через **Пакеты → Установщик** (transport-пакет или репозиторий).
2. Очистите кэш MODX.
3. В **Настройки → Системные настройки** проверьте ключи с префиксом `mxeditorjs`.

## Шаг 2: Выбор редактора

1. **Настройки → Системные настройки**
2. Найдите **which_editor** (или фильтр «editor»).
3. Выберите **mxEditorJs**.
4. Сохраните.

## Шаг 3: Включение компонента

1. Отфильтруйте настройки по пространству имён **mxeditorjs**.
2. **mxeditorjs.enabled** = **Да** (так по умолчанию).
3. При необходимости задайте **mxeditorjs.profile** (`default`, `minimal`, `blog`, `full`).

## Шаг 4: Проверка

1. Откройте любой ресурс в менеджере.
2. В поле контента должен быть блочный редактор Editor.js вместо TinyMCE/CKEditor.
3. Добавьте блок (заголовок, параграф, картинка или **галерея**), сохраните. Контент пишется в формате Editor.js и выходит HTML на фронте.

## Шаг 5: Template Variables (опционально)

1. Создайте или отредактируйте TV типа **Текст (многострочный)**.
2. Включите **Использовать визуальный редактор** (richtext).
3. При `which_editor` = **mxEditorJs** в этом TV тоже будет блочный редактор.
