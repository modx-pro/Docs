# Системные настройки

Откройте **Система → Системные настройки**, в фильтре пространства имён выберите **ms3optionscolor**.

После смены значений очистите кэш MODX. Если правили менеджер (RAL, ключ опции), перезагрузите страницу: конфигурация Vue читается при открытии.

Ключ в БД всегда с подчёркиванием: `ms3optionscolor_<имя>`. Пустой ключ читается как `ms3optionscolor.default_option_key`, затем `ms3optionscolor_product_option_keys`, затем `color`.

Транспорт ставит `'settings' => false`: новое значение по умолчанию в пакете не перезапишет уже сохранённые на сайте.

## Сводная таблица

| Ключ | Тип | По умолчанию | Кратко |
| --- | --- | --- | --- |
| `ms3optionscolor_default_option_key` | textfield | `color` | Какие опции товара считаются «цветом» |
| `ms3optionscolor_ral_enabled` | combo-boolean | Да | Вкладка и поиск RAL в менеджере |
| `ms3optionscolor_frontend_css` | combo-boolean | Да | Стили свотчей на сайте сами |
| `ms3optionscolor_variants_decorate` | combo-boolean | Да | Цвета у вариантов ms3variants в каталоге |

## `ms3optionscolor_default_option_key`

Какая опция участвует во вкладке **Swatches** и в чипах на «Свойства товара». Сниппет берёт тот же ключ, если не передали `&options`.

| Значение | Когда ставить |
| --- | --- |
| `color` | Один ключ опции «Цвет» (типичный магазин) |
| `color,material` | Свотчи и для цвета, и для материала |

Несколько ключей пишите через запятую. Пробелы после запятой пакет обрежет. Не оставляйте поле пустым.

Если ключ опции другой (например `obivka`), поставьте его сюда. Иначе вкладка Swatches будет пустой, хотя значения на «Свойства товара» есть.

## `ms3optionscolor_ral_enabled`

| Значение | Что происходит |
| --- | --- |
| Да | В CMP есть вкладка **RAL**, в диалоге цвета можно искать код RAL |
| Нет | Вкладка RAL скрыта, поиск RAL в форме недоступен. Уже сохранённые коды в словаре не удаляются |

Выключайте, если RAL магазину не нужен. HEX и паттерны от этой настройки не зависят.

## `ms3optionscolor_frontend_css`

| Значение | Что происходит |
| --- | --- |
| Да | Стили `css/web/main.css` подключаются на страницах сайта и при вызове сниппета |
| Нет | Стили не грузятся. Квадраты `[data-ms3oc-swatch]` часто без размера, особенно в корзине |

Оставляйте **Да**, если пользуетесь штатными чанками. Ставьте **Нет**, только когда сами подключаете CSS темы и не хотите второй файл пакета.

Ручное подключение:

::: code-group

```fenom
<link rel="stylesheet" href="{'assets_url' | option}components/ms3optionscolor/css/web/main.css">
```

```modx
<link rel="stylesheet" href="[[++assets_url]]components/ms3optionscolor/css/web/main.css">
```

:::

## `ms3optionscolor_variants_decorate`

Работает только вместе с [ms3variants](/components/ms3variants/) и вызовом листинга с `usePackages=ms3Variants`.

| Значение | Что происходит |
| --- | --- |
| Да | К каждому варианту в каталоге добавляются цвета из словаря (`variants[].swatches`) |
| Нет | Варианты как у ms3variants, без цветов из словаря |

На корзину, цену и выбор варианта настройка не влияет. Разметка: [ms3variants](ms3variants).

## Права доступа

Отдельных прав пакет не создаёт.

| Что делаете | Какое право нужно |
| --- | --- |
| Открыть раздел, править словарь и RAL | `msproduct_save` (как у сохранения товара miniShop3) |
| Вкладка Swatches на товаре | то же `msproduct_save` |

Без права сохранение в менеджере не пройдёт. Проверьте политику роли менеджера и очистите кэш.
