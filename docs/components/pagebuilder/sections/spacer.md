# Отступ

Пустая секция фиксированной высоты. Нужна, когда соседние блоки визуально слипаются и не хватает «воздуха».

<!-- ![Отступ](/components/pagebuilder/screenshots/sections/spacer.png) -->

## Зачем пустая секция

- Ритм страницы без пустых div в шаблоне
- Четыре высоты из коробки (`sm`–`xl`)
- Не ломает порядок секций при правках контента

## Где помогает

- Между hero и контентом: разделить первый экран и текст
- После плотной сетки карточек или галереи
- Перед футером: отделить последний CTA

## Примеры страниц

- [Hero](hero) → [Spacer](spacer) → [Карточки](cards)
- Плотная [Галерея](gallery) → [Spacer](spacer) → [CTA](cta)

## Выбор размера

Выберите **Размер** (`sm`, `md`, `lg`, `xl`). Других полей нет.

## Похожие секции

- Отступы в CSS темы, если нужен pixel-perfect на всём сайте
- [Текстовый блок](richtext) с коротким абзацем, если нужен текст между блоками

## Параметры блока

| Параметр | Значение |
| --- | --- |
| key | `spacer` |
| Слой | Free |
| Категория | вёрстка (`layout`) |
| Chunk | `pagebuilder_spacer` |
| Требования | — |

## Поля в редакторе

Заполните поля в инспекторе секции на ресурсе. Описание типов полей: [справочник типов](../fields/types).

### Размер (`size`)

Тип [select](../fields/select#vyvod-v-section-data). Обязательное. Выпадающий список с заранее заданными вариантами.

## Что видит посетитель

Элемент `pb-spacer` с модификатором размера.

## Данные секции {#vyvod-v-section-data}

Пример JSON после сохранения секции. Для media, video и map значения на выводе могут быть обогащены:

```json
{
  "size": "sm"
}
```

## Шаблон chunk

Fenom chunk `pagebuilder_spacer`:

```fenom
<div class="pb-spacer pb-spacer--{$size ?: 'md'}" aria-hidden="true"{if $id} id="pb-{$id|escape}"{/if}></div>
```

## JSON-определение

`core/components/pagebuilder/sections/spacer.json`
