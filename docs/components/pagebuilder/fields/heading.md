# Поле heading

Версия: **Free**.

<!-- ![heading](/components/pagebuilder/screenshots/fields/heading.jpg) -->

## Зачем этот тип

Делит длинную форму на блоки с заголовками.

## Когда использовать

- Подпись «Кнопка», «SEO», «Медиа» между полями
- Визуальный разделитель без [fieldset](fieldset) (Pro)
- Инструкция прямо в форме — через `label`

## Советы

`name` может быть техническим, например `_h`.

## Похожие типы

- [fieldset](fieldset) для legend и вложенных полей (Pro)
- [dependent](dependent) маркер для showWhen блоков (Pro)

## Настройка

```json
{
  "name": "_h",
  "type": "heading",
  "label": "Группа полей",
  "tab": "Контент",
  "width": 100
}
```

## Данные секции {#vyvod-v-section-data}

В данных секции не сохраняется.

## Пример в chunk

Не используется в chunk.

## Общие свойства

| Ключ | Роль | Панель |
| --- | --- | --- |
| `tab` | Группа в инспекторе | да |
| `width` | Ширина подписи в % строки (flex): 25, 33, 50, 66, 75, 100; в CMP только эти значения | да |
| `label` | Текст подзаголовка / маркера | да |

См. [обзор полей](overview#общие-свойства-поля).
