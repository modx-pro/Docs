# Поле heading

Слой: **Free**.

<!-- ![heading](/components/pagebuilder/screenshots/fields/heading.png) -->

## Зачем этот тип

Разбивает длинный инспектор на блоки. Ключ в данных секции не создаёт. Работают `tab` и `width` как у обычных полей.

## Когда использовать

- Подпись «Кнопка», «SEO», «Медиа» между полями
- Визуальный разделитель без [fieldset](fieldset) (Pro)
- Документация прямо в форме через label

## Советы

`name` может быть техническим, например `_h`. Вложенная группа с полями: [fieldset](fieldset) (Pro).

## Похожие типы

- [fieldset](fieldset) для legend и nested fields (Pro)
- [dependent](dependent) маркер для showWhen блоков (Pro)

## Настройка

```json
{
  "name": "_h",
  "type": "heading",
  "label": "Группа полей",
  "tab": "Контент",
  "width": 100
}
```

## Значение

Не попадает в данные секции.

## Данные секции {#vyvod-v-section-data}

В данных секции не сохраняется.

## Пример в chunk

Не используется в chunk.

## Общие свойства

Значение в данных секции **не сохраняется**.

| Ключ | Роль | CMP |
| --- | --- | --- |
| `tab` | Группа в инспекторе | да |
| `width` | Ширина подписи, 25–100 (%) | да |
| `label` | Текст подзаголовка / маркера | да |

См. [обзор полей](overview#общие-свойства-поля).
