# Поле dependent

Версия: **Pro** (`advanced-fields`).

<!-- ![dependent](/components/pagebuilder/screenshots/fields/dependent.jpg) -->

## Зачем этот тип

Само поле в инспекторе не показывается (модуль `fieldVisibility.ts`, функция `isFieldVisible` возвращает `false`). Оно помечает группу полей, которые видны по условию. Условие задаётся свойством `showWhen` у соседних полей.

## Когда использовать

- Комментарий в JSON, что ниже поля зависят от toggle
- Организация полей в панели управления для сложных веток
- Парность с yesno, toggle и скрытыми url

## Советы

Условие задаётся на видимых полях через `showWhen`. Декоративный заголовок без logic: [heading](heading).

## Похожие типы

- [heading](heading) видимый подзаголовок (Free)
- [toggle](toggle) частый триггер showWhen (Free)

## Настройка

```json
{
  "name": "_dep",
  "type": "dependent",
  "label": "Зависимые поля",
  "tab": "Контент",
  "width": 100
}
```

## Значение

Не сохраняется.

## Данные секции {#vyvod-v-section-data}

В данных секции не сохраняется.

## Пример в chunk

Не используется в chunk.

## Примечание

Сам тип в инспекторе не рисуется (`isFieldVisible` → `false`). Соседние поля управляют видимостью через `showWhen`.

## Общие свойства

Значение в данных секции **не сохраняется**.

| Ключ | Роль | Панель |
| --- | --- | --- |
| `tab` | Группа в инспекторе | да |
| `width` | 25, 33, 50, 66, 75, 100 | Ширина подписи в % строки (flex); в CMP только эти значения | да |
| `label` | Текст подзаголовка / маркера | да |

См. [обзор полей](overview#общие-свойства-поля).
