# Поле dependent

Версия: **Pro**.

<!-- ![dependent](/components/pagebuilder/screenshots/fields/dependent.png) -->

## Зачем этот тип

Сам тип скрыт в инспекторе (`fieldVisibility` false). Документирует группу условных полей. Соседи управляются `showWhen` на других полях.

## Когда использовать

- Комментарий в JSON, что ниже поля зависят от toggle
- Организация CMP для сложных веток
- Парность с yesno, toggle и скрытыми url

## Советы

Условие задаётся на видимых полях через `showWhen`. Декоративный заголовок без logic: [heading](heading).

## Похожие типы

- [heading](heading) видимый подзаголовок (Free)
- [toggle](toggle) частый триггер showWhen (Free)

## Настройка

```json
{
  "name": "_dep",
  "type": "dependent",
  "label": "Зависимые поля",
  "tab": "Контент",
  "width": 100
}
```

## Значение

Не сохраняется.

## Данные секции {#vyvod-v-section-data}

В данных секции не сохраняется.

## Пример в chunk

Не используется в chunk.

## Примечание

Сам тип в инспекторе не рисуется (`fieldVisibility` возвращает false). Соседние поля управляют видимостью через `showWhen`.

## Общие свойства

Значение в данных секции **не сохраняется**.

| Ключ | Роль | CMP |
| --- | --- | --- |
| `tab` | Группа в инспекторе | да |
| `width` | Ширина подписи, 25–100 (%) | да |
| `label` | Текст подзаголовка / маркера | да |

См. [обзор полей](overview#общие-свойства-поля).
