# Поле schedule

Версия: **Pro** (`advanced-fields`).

Текстовое поле. Плейсхолдер инспектора: `{"mon":["09:00-18:00"],"tue":["09:00-18:00"]}`. Схему редактор не проверяет. Сохраняется строка: этот JSON или обычный текст, например `Ежедневно 10:00-20:30`. JSON разбирайте в chunk или своём коде.

## Настройка

```json
{
  "name": "hours",
  "type": "schedule",
  "label": "Часы работы"
}
```

## Данные секции {#vyvod-v-section-data}

```json
{
  "hours": "{\"mon\":[\"09:00-18:00\"],\"tue\":[\"09:00-18:00\"]}"
}
```

## Похожие типы

- [textarea](textarea), если график это обычный текст
- [keyvalue](keyvalue) для пар без JSON-строки
