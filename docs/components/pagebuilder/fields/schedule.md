# Поле schedule

Версия: **Pro** (`advanced-fields`).

Многострочное поле. Сохраняется строка: JSON или обычный текст, например `Ежедневно 10:00-20:30`. Редактор схему не проверяет: JSON разбирайте в chunk или своём коде. Плейсхолдер инспектора показывает пример формата.

## Настройка

```json
{
  "name": "hours",
  "type": "schedule",
  "label": "Часы работы"
}
```

## Данные секции {#vyvod-v-section-data}

```json
{
  "hours": "{\"mon\":[\"09:00-18:00\"],\"tue\":[\"09:00-18:00\"]}"
}
```

## Похожие типы

- [textarea](textarea), если график это обычный текст
- [keyvalue](keyvalue) для пар без JSON-строки
