# Поле product

Версия: **Pro**, capability `minishop3`.

Строка с ID товара. Без miniShop3 тип в инспекторе нового поля не предлагается.

## Настройка

```json
{
  "name": "product_id",
  "type": "product",
  "label": "Товар"
}
```

## Данные секции {#vyvod-v-section-data}

```json
{
  "product_id": "42"
}
```
