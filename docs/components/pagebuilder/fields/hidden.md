# Поле hidden

Версия: **Free**.

<!-- ![hidden](/components/pagebuilder/screenshots/fields/hidden.jpg) -->

## Зачем этот тип

Значение сохраняется и попадает в чанк, но в форме редактора поля не видно. Значение по умолчанию задают в JSON или в панели управления.

## Когда использовать

- Служебный токен, ключ пресета, идентификатор счётчика
- Константа секции, которую меняет только разработчик
- Дублирование значения по умолчанию для форм на сайте

## Советы

Редактору нужен просмотр значения: [readonly](readonly). `active: false` скрывает любое поле; hidden — когда значение нужно только в данных.

## Похожие типы

- [readonly](readonly) для видимого, но не редактируемого
- [text](text) с `active: false`, если значение меняют в панели управления

## Настройка

```json
{
  "name": "token",
  "type": "hidden",
  "label": "Token",
  "tab": "Контент",
  "width": 100
}
```

## Значение

Строка в данных секции.

## Данные секции {#vyvod-v-section-data}

Ключ `token` в данных секции:

```json
{
  "token": "sku-001"
}
```

## Пример в chunk

::: code-group

```modx
<input type="hidden" name="token" value="[[+token]]">
```

```fenom
<input type="hidden" name="token" value="{$token|escape}">
```

:::

## Общие свойства

Для полей с `name`, которые сохраняются в данных секции:

| Ключ | Тип | Роль | Панель |
| --- | --- | --- | --- |
| `tab` | string | Подзаголовок группы в инспекторе | да |
| `width` | 25, 33, 50, 66, 75, 100 | Ширина поля в % строки (flex); в CMP только эти значения | да |
| `description` | string | Подсказка под подписью | да |
| `default` | any | Начальное значение новой секции | да |
| `active` | bool | `false`: скрыть поле в инспекторе | да |
| `required` | — | Для типа `hidden` publish-проверка обязательности не выполняется | — |

Подробнее: [обзор полей](overview#общие-свойства-поля).
