# Сетка товаров

Результат: на странице карточки с фото, ценой и кнопкой «В корзину». Товары читает msProducts внутри чанка, отдельный вызов сниппета в шаблоне не нужен. Нужны PageBuilder Pro и установленный miniShop3 (`requires: ["pro", "minishop3"]`).

## Что нужно заранее

1. Ресурс опубликован, в шаблоне стоит `[[!PageBuilder]]`.
2. miniShop3 установлен, в каталоге есть категория с товарами.
3. Тип `products_grid` виден в каталоге **Блоки**. Если его нет, проверьте `requires`.

## Шаги

1. Добавьте секцию `products_grid`.
2. В **Корень каталога** выберите категорию. Поле обязательное.
3. Задайте **Лимит** и сортировку: `menuindex`, `popular`, `new`, `price_asc`, `price_desc`. Неизвестное значение сортирует как `menuindex`.
4. **Сохранить** ресурса.

## Пример полей

**Корень каталога** `101` (пример, подставьте свою категорию). **Лимит** `6`. Пустой лимит в чанке становится 12. **Сортировка** `price_asc`. Для блока «часто берут» поставьте `popular`.

Пустая категория показывает лексикон `pagebuilder_fe_listing_empty_products` («В этой категории пока нет товаров.»). У секции `"cacheable": false`, HTML-кеш страницы листинг не замораживает.

Узкая полоса: секция `products_carousel`. Ручной список SKU: `curated_products`.

## Что проверить

На сайте карточки выбранной категории. Смена `sortby` на `price_asc` выводит товары по возрастанию цены. Пустая категория показывает текст лексикона, а не пустой блок без сообщения.

## Откат

Удалите секцию.
