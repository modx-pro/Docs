# Лендинг из Free-секций

Результат: на сайте четыре блока. Черновик на витрину не попадает. Публикует кнопка **Сохранить** ресурса MODX. Отдельной кнопки «Опубликовать» на вкладке **Секции** нет.

## Что нужно заранее

1. Ресурс опубликован в MODX. Снятый с публикации ресурс страницу не откроет.
2. В шаблоне стоит некэшированный `[[!PageBuilder]]`.

## Шаги

1. Откройте ресурс и вкладку **Секции**.
2. **Добавить секцию** и возьмите из каталога **Блоки**: `hero`, `richtext`, `faq`, `cta`.
3. Заполните поля в **Свойствах**.
4. Нажмите **Сохранить** у ресурса. Редактор валидирует поля и пишет `published_json`.
5. Откройте страницу на сайте.

## Пример полей

Hero. Title `Ремонт кухни под ваш метраж`, Description `Замер в день заявки, смета на следующий`. Button label `Оставить заявку`, Button URL `/contacts.html`. Alignment `left`.

Rich text. Короткий абзац о том, что входит в работу.

FAQ. Title `Частые вопросы`. Две строки: вопрос и ответ.

CTA. Title `Нужен замер`, Text `Напишите район и удобное время.` Кнопки те же, что у Hero.

Тот же порядок другими секциями Free:

| Задача | Секция |
| --- | --- |
| Цифры | `stats` |
| Отзыв | `testimonials` |
| Одно фото | `image` |
| Ролик | `video` |
| Зазор | `spacer` |
| Три карточки | `cards` |

С Pro в тот же порядок можно добавить `how_it_works`, `media_split`, `case_study`, `newsletter` или `quote`. Если типа нет в каталоге, проверьте `requires` и контекст ресурса.

Откат: удалите секцию в корзину страницы или снимите секции с публикации через `mgr/page/unpublish`, если кнопка есть в UI. Черновик при этом остаётся.
