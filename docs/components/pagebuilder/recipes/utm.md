# UTM и видимость

Результат: блок есть в HTML только если правило UTM выполнено. Значение берётся из query string, затем из `$_SESSION['utm']`. Реестр UTM требует PageBuilder Pro и capability `utm`. Уже опубликованные правила на сайте исполняет Free.

## Что нужно заранее

1. Включена `pagebuilder_inspector_visibility_enabled`. Пока настройка выключена, кнопки **Видимость** в инспекторе нет.
2. В шаблоне срабатывает плагин PageBuilder на `OnHandleRequest` в контексте `web`. Если нет, поставьте `[[!PageBuilderUtmSession]]` выше `[[!PageBuilder]]`.

## Шаги

1. В панели управления откройте вкладку **UTM** и добавьте параметр. Плейсхолдер в полях: <code v-pre>{{utm:key}}</code>. <!-- markdownlint-disable-line MD033 -->
2. На секции откройте **Видимость** и задайте правило `utm`. Сначала проверяется `$_GET[параметр]` и `$_GET['utm_' . параметр]`, затем `$_SESSION['utm']`.
3. Откройте страницу с меткой в адресе, затем без неё. Секция пропадает из HTML, когда правило не выполнено.
4. **Сохранить** ресурса.

Тот же диалог задаёт список контекстов MODX. В Pro при флаге `conditions` доступны ещё `settings.conditions` (гость, авторизованный, GET).

## Пример полей

Во вкладке **UTM** параметр `campaign`. В полях секции плейсхолдер <code v-pre>{{utm:campaign}}</code>. <!-- markdownlint-disable-line MD033 -->

На секции `cta` правило **Видимость**: `utm`, параметр `campaign`, допустимое значение `spring`. Откройте `?campaign=spring`. Секция в HTML. Откройте `?campaign=other`. Секции в HTML нет.

## Что проверить

С меткой блок есть в исходнике страницы. Без метки блока нет, а не `display: none`. Выключенная кнопка инспектора не стирает уже записанные правила.

## Откат

Очистите правило в диалоге и сохраните ресурс. Выключить кнопку инспектора можно настройкой, уже записанные правила при этом продолжают работать.
