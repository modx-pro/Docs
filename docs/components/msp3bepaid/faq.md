# FAQ

## Возврат не уходит

Пока попытка в `pending`, вкладка возврат не отправляет. Дождитесь webhook со статусом `successful`. Возврат идёт по UID транзакции на `https://gateway.bepaid.by/transactions/refunds`.

## Нельзя отменить ссылку на оплату

У bePaid нет запроса, который отменяет checkout token. Покупатель может не платить. Когда срок ссылки кончится, придёт уведомление `expired`, и попытка станет неуспешной.

## Покупатель вернулся на сайт, а заказ не оплачен

`return.php` только сверяет токен и перенаправляет браузер. Статус «оплачен» ставит webhook на `assets/components/msp3bepaid/webhook.php`. Проверьте, что в кабинете указан этот адрес и что запрос доходит по HTTPS без 301.
