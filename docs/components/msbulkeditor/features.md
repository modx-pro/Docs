# Возможности

Страница для менеджера: какие задачи закрывает панель и куда кликать дальше. Технические коды операций (`fieldType`) перечислены в конце.

![Схема: отбор → предпросмотр → применение → история](/components/msbulkeditor/screenshots/features-flow.png)

## Задачи, которые вы решаете здесь

1. Меняете цены, остатки и поля у десятков, сотен или тысяч товаров за одну операцию.
2. Работаете с отмеченными строками **или** со всей выборкой по фильтру (экспертный режим).
3. Смотрите таблицу «было / станет» **до** записи в базу.
4. Откатываете ошибочную операцию целиком или по отдельным товарам.
5. Сохраняете частую операцию как **пресет** и запускаете её снова с панели инструментов.
6. Выгружаете выборку в CSV/XLSX и загружаете правки цены, остатка и артикула.

Пошаговые инструкции со скриншотами: [Пошаговые сценарии](interface/flows).

## Операции по полям товаров

| Что меняете | Как в диалоге | Подробнее |
| --- | --- | --- |
| Цена | Установить, ± сумма, ± %, округление, перенос в старую цену | [Товар и цены](interface/product-and-prices) |
| Остаток | Те же режимы для склада | [Товар и цены](interface/product-and-prices) |
| TV-параметры | Задать, добавить, заменить, очистить | [TV](interface/tv-parameters) |
| Опции MiniShop3 | Одно значение или список тегов | [Опции](interface/options) |
| Категории | Доп. категории, снять все, сменить родителя | [Товар и цены](interface/product-and-prices) |
| Текст и артикул | Задать значение или найти и заменить | [Товар и цены](interface/product-and-prices), [Поля ресурса](interface/resource-fields) |
| SEO | Длинный заголовок, описание, пункт меню, alias | [Поля ресурса](interface/resource-fields) |
| Флаги | Опубликован, удалён, не показывать в меню и др. | [Поля ресурса](interface/resource-fields) |
| Производитель, шаблон, источник, тип контента | Выбор из справочника | [Быстрые действия](interface/quick-actions) |
| Даты и авторы | Дата публикации, createdby / editedby | [Поля ресурса](interface/resource-fields) |
| Связи товаров | Добавить или убрать link | [Поля ресурса](interface/resource-fields) |
| Варианты | Цена, остаток, sku, вес (нужен ms3Variants) | [Товар и цены](interface/product-and-prices) |
| Служебное | Кэш, URI, мягкое удаление, превью галереи | [Быстрые действия](interface/quick-actions) |

Если у части товаров нет нужного TV или опции, перед предпросмотром откроется [мастер привязки](interface/binding-wizard).

## Меню «Быстрые действия»

На вкладке **Товары** кнопка с молнией открывает готовые операции: сменить шаблон, родителя, производителя, даты, текст, очистить кэш, перегенерировать URI, мягко удалить и др. Тип операции выбирать не нужно.

→ [Быстрые действия](interface/quick-actions)

## Правка прямо в таблице

Клик по ячейке сохраняет одно поле через тот же безопасный путь (предпросмотр и запись): название, цена, остаток, публикация, артикул, вес, текстовые и image-TV, простые опции.

Списки-теги и TV типа list / checkbox / file в ячейке не правятся. Для них используйте массовую операцию.

→ [Редактирование в списке](interface/inline-editing)

## Колонки таблицы

Вы включаете нужные колонки (в том числе TV и опции), меняете порядок и ширину. Настройки можно сохранять на вашу учётку менеджера.

→ [Настройка колонок](interface/column-settings)

## Предпросмотр и применение

После **Предпросмотр** вы видите сводку и таблицу diff. Снимите галочки со строк, которые не нужно менять, затем нажмите **Применить**. Запись идёт пачками. Пока идёт прогресс, вторую массовую операцию запустить нельзя.

→ [Предпросмотр и применение](interface/preview-and-apply)

## История и откат

На вкладке **История** лежит журнал. У завершённой операции доступны полный откат и выборочный откат по товарам в панели **Изменения**.

→ [История](interface/history)

## Пресеты

Сохраните параметры операции под именем (например «Скидка −10 %»). Запускайте с вкладки **Пресеты** или из меню на панели инструментов вкладки **Товары**.

→ [Пресеты](interface/presets)

## Импорт и экспорт

| Сравнение | Экспорт | Импорт |
| --- | --- | --- |
| Форматы | CSV, XLSX | CSV, XLSX |
| Область | Отмеченные товары или вся выборка по фильтру | Та же логика отбора |
| Поля | id и колонки из настроек таблицы (в т.ч. TV и опции) | Цена, остаток, артикул |

→ [Импорт и экспорт](interface/import-export)

## Как отобрать товары

- дерево категорий слева (родитель и опция «Включая подкатегории»)
- поиск по названию и артикулу, фильтр публикации
- расширенные фильтры: шаблон, производитель, доп. категория, картинка, метки new / popular / favorite, удалённые, дубликаты URI
- экспертный режим: все товары по фильтру (лимит по умолчанию 5000)

→ [Сетка товаров](interface/products-grid)

## Права (кратко)

| Право | Что открывает |
| --- | --- |
| `msbulkeditor_view` | Панель, предпросмотр, чтение истории |
| `msbulkeditor_edit` | **Применить**, правка ячеек |
| `msbulkeditor_rollback` | Откат |
| `msbulkeditor_presets` | Вкладка и CRUD пресетов |
| `msbulkeditor_import_export` | Вкладка импорта и экспорта |

Подробнее: [Системные настройки](settings#права-доступа).

## Ограничения

- только товары MiniShop3 (`msProduct`)
- нет правки в ячейке для multi-value опций и TV list / checkbox / file
- тип опции в массовой форме (одно значение или теги) выбираете вручную

См. [FAQ](faq#ограничения).

## Справочник кодов fieldType

Для интеграторов и JSON-пресетов: `price`, `stock`, `boolean_toggle`, `category`, `option`, `tv`, `vendor`, `template`, `source`, `content_type`, `user`, `resource_group`, `text_set`, `dates`, `text_replace`, `seo`, `link`, `variant`, `gallery_regenerate`, `resource_utility`, `soft_delete`.
