# Сетка товаров

Вкладка **Товары** это основной экран. Здесь вы отбираете каталог и запускаете операции.

![Сетка товаров](/components/msbulkeditor/screenshots/products-grid.png)

---

## Что видно в таблице

| Колонка | Содержание |
| --- | --- |
| Превью | Миниатюра товара (всегда слева) |
| ID | Номер ресурса |
| Название | Можно править кликом по ячейке |
| Цена | То же |
| Остаток | Поле склада MiniShop3 |
| Публикация | Переключатель в ячейке |
| Варианты | Число вариантов, если установлен ms3Variants |

Состав колонок меняется в [настройке таблицы](column-settings). Можно добавить TV и опции.

Таблица листается по страницам (по умолчанию 25 строк). Сортировки по клику на заголовок нет.

### Важно про галочки

- Галочка в заголовке отмечает **только текущую страницу**.
- Счётчик **По фильтру** считает все товары по фильтру, не только страницу.
- Нужна вся выборка по фильтру? Включите **экспертный режим**.

---

## Дерево категорий

Слева дерево каталога MiniShop3. Узел **Все товары** сбрасывает фильтр по родителю. Клик по категории сужает список.

Внизу sidebar и в фильтрах есть переключатель **Включая подкатегории**.

![Дерево категорий](/components/msbulkeditor/screenshots/category-sidebar.png)

Дерево синхронизировано с полем **Категория** в панели фильтров.

---

## Поиск и фильтры

Основная строка: поиск, категория, статус публикации, кнопки **Применить** и **Сброс**.

Редкие условия спрятаны в **Ещё фильтры**. Кнопка подсвечивается, если там что-то включено.

![Панель фильтров](/components/msbulkeditor/screenshots/filters.png)

| Фильтр | Что делает |
| --- | --- |
| **Категория** | Родитель товара. С подкатегориями включает и потомков |
| **Доп. категория** | Товары, привязанные как дополнительные |
| **Шаблон** | Шаблон ресурса MODX |
| **Производитель** | Vendor MiniShop3 |
| **Изображение** | С фото в галерее / без |
| **Удалённые** | Показать мягко удалённые |
| **Дубликаты URI** | Товары с одинаковым непустым URI |
| **Метка** | new / popular / favorite: Да или Нет |
| **Поиск** | Подстрока в названии или артикуле |
| **Публикация** | Все / опубликованные / скрытые |

Фильтры сохраняются, пока вы ходите по вкладкам msBulkEditor.

## Как выбрать товары

| Действие | Результат |
| --- | --- |
| Галочка в строке | Один товар |
| Галочка в заголовке | Все строки **текущей страницы** |
| **Выбрано: N** | Сколько отмечено |
| Прицел в колонке `⋯` | Только один товар (см. экспертный режим) |

Без отмеченных строк и без экспертного режима неактивны **Запустить операцию**, **Быстрые действия** и меню **Пресеты**. Подсказка: выберите товары или включите экспертный режим.

---

## Счётчики над таблицей

| Показатель | Смысл |
| --- | --- |
| **По фильтру** | Сколько товаров подходит под текущие фильтры |
| **Выбрано** | Сколько отмечено галочками |

Рядом панель пишет область операции: «N выбранных строк» или «все N товаров по фильтрам».

---

## Экспертный режим

| Режим | На что действует операция |
| --- | --- |
| Выключен | Только отмеченные галочками |
| Включён | Все товары по текущим фильтрам |

Лимит по умолчанию: 5000 товаров (`msbulkeditor_expert_limit`). При превышении сузьте фильтр.

Администратор может запретить режим настройкой `msbulkeditor_expert_mode = Нет`.

![Экспертный режим](/components/msbulkeditor/screenshots/expert-mode.png)

### Прицел «только эта строка»

В экспертном режиме справа появляется колонка `⋯`:

1. Нажмите иконку прицела (**Выбрать только эту строку**).
2. В выборке останется один ID.
3. Экспертный режим не выключается. Дальше операция идёт по этой одной строке, пока вы не измените отбор.

## Панель инструментов

| Кнопка | Назначение |
| --- | --- |
| **Запустить операцию** | Любой тип операции → [предпросмотр](preview-and-apply) |
| **Быстрые действия** | Готовые частые операции → [быстрые действия](quick-actions) |
| **Настройка таблицы** | Колонки → [колонки](column-settings) |
| **Пресеты** | Сохранённые операции → [пресеты](presets) |

Ширину колонки меняете перетаскиванием границы заголовка (сохраняется на учётку, если администратор включил сохранение настроек).

## Правка одной ячейки

Клик по названию, цене, остатку, публикации, артикулу, весу, текстовому TV или простой опции. Подробнее: [редактирование в списке](inline-editing).

---

## Если список пуст или ошибка

| Ситуация | Что сделать |
| --- | --- |
| «Товары не найдены» | Смените фильтры или нажмите **Сброс** |
| Дерево категорий пусто | Проверьте каталог MiniShop3 |
| Ошибка загрузки списка | Перезагрузите. Смотрите лог MODX и FAQ |
| Нет выборки | Отметьте строки или включите экспертный режим |
| Превышен лимит эксперта | Сузьте фильтр |
