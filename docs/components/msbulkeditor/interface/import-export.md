# Импорт и экспорт

Вкладка для обмена с Excel без ручного набора в диалоге операций.

Нужно право **`msbulkeditor_import_export`**. Без него вкладка скрыта.

![Вкладка «Импорт и экспорт»](/components/msbulkeditor/screenshots/import-export-tab.png)

Область действия та же, что на **Товарах**: отмеченные строки или экспертный режим по фильтру. Сначала настройте отбор на вкладке **Товары**, затем перейдите сюда.

---

## Чем отличается экспорт от импорта

| Сравнение | Экспорт | Импорт |
| --- | --- | --- |
| Колонки | id, поля товара, TV, опции | Только **цена**, **остаток**, **артикул** |
| Зачем | Отчёт или правка в Excel | Вернуть правки цены / склада / артикула |
| TV и опции | Попадают в файл | Через вкладку импорта нельзя. Используйте массовую операцию |

---

## Экспорт

1. На **Товарах** отфильтруйте каталог и отметьте товары (или экспертный режим).
2. Откройте **Импорт и экспорт** → блок **Экспорт**.
3. Выберите формат: CSV или XLSX.
4. Укажите колонки через запятую. По умолчанию: `id,pagetitle,price,stock,published`.
5. Нажмите **Запустить экспорт**. Файл скачается в браузере.

![Форма экспорта](/components/msbulkeditor/screenshots/export-form.png)

### Какие колонки писать

| Ключ | Зачем |
| --- | --- |
| `id` | Нужен, если потом будете импортировать |
| `pagetitle` | Название |
| `price` | Цена |
| `stock` или `count` | Остаток |
| `published` | 0 или 1 |
| `article` | Артикул |
| `tv:имя` | TV-параметр |
| `option:ключ` | Опция товара (несколько значений через запятую) |

### Если XLSX не скачивается

Сообщение `msbulkeditor_export_xlsx_unavailable` значит, на сервере нет библиотеки OpenSpout из пакета. Экспортируйте CSV или попросите администратора проверить установку.

Разработчики могут добавить свои колонки через события экспорта: [События MODX](../events#расширение-экспорта-плагином).

## Импорт цены, остатка или артикула

Типичный путь:

1. Экспортируйте файл с колонкой `id` и нужным полем.
2. В Excel поправьте цены, остатки или артикулы. Не меняйте `id`.
3. На вкладке импорта нажмите **Выбрать файл**.
4. Укажите **целевое поле** (цена / остаток / артикул) и сопоставьте колонки ID и значения.
5. Нажмите **Предпросмотр импорта**, проверьте таблицу.
6. Нажмите **Применить импорт**.

Без маппинга предпросмотр недоступен. Без успешного предпросмотра кнопка применения неактивна.

![Маппинг колонок](/components/msbulkeditor/screenshots/import-mapping.png)

| Целевое поле в UI | Что обновится |
| --- | --- |
| Цена | Поле цены товара |
| Остаток | Склад (`count`). В файле подойдут заголовки count, stock, quantity, qty |
| Артикул | Поле article |

### Лимиты

| Параметр | По умолчанию |
| --- | --- |
| Строк в файле | 10 000 |
| Размер файла | 10 МБ |
| Форматы | `.csv`, `.xlsx` |

При обрезке по лимиту панель покажет предупреждение. Лимит строк задаёт `msbulkeditor_import_max_rows`.

---

## Импорт через JSON (расширенно)

Блок **Расширенно: JSON строк и маппинг** даёт те же три поля без файла:

```json
[
  {"id": 22, "price": 199},
  {"id": 23, "price": 249}
]
```

Маппинг:

```json
{"product_id": "id", "value": "price"}
```

Для TV и опций используйте [массовую операцию](preview-and-apply) на вкладке **Товары**.

---

## После импорта

Панель покажет итог: успешно / пропущено / ошибки.

**Очистить предпросмотр** сбрасывает результат на экране. Если очищать нечего, появится короткое сообщение.

Импорт пишет изменения тем же безопасным путём, что и обычная операция (предпросмотр → применение → запись в историю).
