# История и откат

Вкладка **История** хранит журнал массовых операций. Отсюда вы откатываете ошибочную акцию целиком или по отдельным товарам.

Нужно право **`msbulkeditor_rollback`**, чтобы нажимать откат. Смотреть журнал можно с правом `msbulkeditor_view`.

![Вкладка «История»](/components/msbulkeditor/screenshots/history-tab.png)

---

## Что в таблице

| Колонка | Содержание |
| --- | --- |
| Галочка | Только у статуса **Завершена** (для массового отката) |
| ID | Номер операции |
| Тип | Какая операция была (цена, TV, …) |
| Создано | Дата и время |
| Статус | В очереди, выполняется, завершена, ошибка, отменена |
| Обработано / Всего | Прогресс по товарам |

В строке две кнопки: **Откат** и **Изменения**.

Пустой журнал показывает «История пуста».

---

## Когда откат доступен

| Статус | Откат |
| --- | --- |
| В очереди / Выполняется | Нет |
| **Завершена** | Да: вся операция или выбранные товары |
| **Ошибка** | Только уже записанные позиции (откройте **Изменения**) |
| Отменена | Нет |

---

## Откатить всю операцию

1. Найдите операцию со статусом **Завершена**.
2. Нажмите **Откат**.
3. Подтвердите действие.
4. Панель вернёт прежние значения по всем позициям этой операции.

![Подтверждение отката](/components/msbulkeditor/screenshots/history-rollback-confirm.png)

---

## Откатить несколько операций сразу

1. Отметьте галочками завершённые операции.
2. Нажмите **Отменить выбранные**.
3. Подтвердите.

![Массовый откат](/components/msbulkeditor/screenshots/history-bulk-rollback-confirm.png)

---

## Откатить отдельные товары

1. В строке операции нажмите **Изменения**.
2. Под таблицей откроется панель со списком товаров и полей.
3. Отметьте нужные строки (активны только со статусом «применено»).
4. Нажмите **Откат выбранных**.

Клик по ID операции в панели копирует номер в буфер обмена.

![Панель «Изменения»](/components/msbulkeditor/screenshots/history-detail.png)

---

## Операция завершилась с ошибкой

1. Откройте **Историю**. Статус **Ошибка**.
2. Нажмите **Изменения**.
3. Откатите позиции, которые успели записаться.
4. Исправьте причину (права, данные, фильтр) и запустите операцию снова на оставшихся товарах.

---

## Как долго хранится журнал

Администратор может включить автоочистку через [Scheduler](/components/scheduler/) и настройку `msbulkeditor_scheduler_enabled`. Срок хранения задаёт `msbulkeditor_history_retention_days` (по умолчанию 90 дней).

Без очистки таблицы журнала растут. Подробнее: [Системные настройки](../settings#scheduler).

---

## На что обратить внимание

- Откат восстанавливает значения, которые панель сохранила в снимке операции (цена, поля, TV и т.д.).
- Служебные действия вроде очистки кэша или пересборки превью галереи откатывают метаданные по правилам операции. Файлы на диске могут не вернуться «как были».
