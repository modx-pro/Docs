# Редактирование в списке

Быстрая правка **одного товара** кликом по ячейке. Диалог массовой операции не нужен.

![Правка названия](/components/msbulkeditor/screenshots/inline-edit.png)

---

## Какие поля правятся в ячейке

| Колонка | Как править |
| --- | --- |
| Название | Клик → текст → Enter или клик мимо |
| Артикул | То же |
| Цена | Число ≥ 0 |
| Остаток | Число ≥ 0 |
| Вес | Число ≥ 0 |
| Публикация | Переключатель |
| TV (текст, email, url, textarea) | Клик → текст |
| TV image | Двойной клик → медиабраузер MODX |
| Опция с одним значением | Клик → текст |

TV типа list / checkbox / file и опции-теги в ячейке **не** правятся. Для них используйте массовую операцию.

---

## Как сохранить

1. Наведите на ячейку. Появится подсказка.
2. Кликните (для image TV дважды).
3. Измените значение.
4. Сохраните: Enter, клик мимо ячейки, переключатель публикации или выбор файла в медиабраузере.
5. При успехе увидите сообщение **Сохранено**.

При ошибке панель покажет текст ошибки и вернёт прежнее значение в таблице.

Нужно право **`msbulkeditor_edit`**.

---

## Что происходит «под капотом» (кратко)

Сохранение одной ячейки идёт тем же безопасным путём, что и массовая операция: проверка → запись → снимок в **Истории**. Откатить можно на вкладке истории (операция на один товар).

Пока идёт сохранение, в ячейке крутится индикатор загрузки.

---

## Ограничения

- Невалидное число для цены, остатка или веса не сохранится.
- Image TV работает только внутри менеджера MODX.
- Пока нет правки в ячейке для наборов тегов и сложных TV (list / checkbox / file).

Перед массовой правкой TV/опции без привязки откроется [мастер привязки](binding-wizard).
