# Настройка полей в списке

Управление колонками таблицы на вкладке **Товары**: что видно, в каком порядке и какой ширины.

![Диалог «Настройка таблицы»](/components/msbulkeditor/screenshots/column-manager.png)

---

## Как открыть

На вкладке **Товары** нажмите **Настройка таблицы** (иконка колонок на панели инструментов).

---

## Как устроен диалог

Два списка:

| Панель | Содержимое |
| --- | --- |
| **Доступные** | Поля, которые можно добавить |
| **Выбранные** | Колонки, которые уже в таблице |

Вы можете:

- искать поле по названию в «Доступных»
- добавлять и убирать выделенное поле кнопками
- перетаскивать поля между списками и менять порядок в «Выбранных» (ручка слева)
- двигать порядок кнопками **Выше** / **Ниже**
- задать **ширину** в пикселях (минимум 40) для каждой выбранной колонки

В самой таблице ширину меняете перетаскиванием правой границы заголовка (от 40 до 480 px).

### Кнопки внизу

| Кнопка | Действие |
| --- | --- |
| **Отмена** | Закрыть без сохранения |
| **Восстановить** | Вернуть снимок колонок из браузера (localStorage). Это не «заводские» колонки пакета |
| **Сохранить** | Записать набор и ширины для вашей учётки (если сохранение включено администратором) |

---

## Какие поля можно добавить

По умолчанию в таблице: ID, название, цена, остаток, публикация, число вариантов.

Дополнительно из каталога полей:

| Группа | Примеры |
| --- | --- |
| Ресурс | название, alias, публикация |
| MiniShop3 | цена, остаток, артикул, вес |
| Вычисляемые | ID, число вариантов |
| TV | дополнительные поля (когда задан шаблон в фильтре) |
| Опции | опции товара (когда задана категория) |

Колонка **Превью** всегда слева в таблице и в диалоге настройки **не** показывается.

Если каталог полей с сервера не загрузился, в «Доступных» останется короткий встроенный список. TV и опции появятся после успешной загрузки каталога с учётом фильтра по шаблону или категории.

---

## Сохранение на пользователя

Если в настройках `msbulkeditor_enable_save_setting_user = Да` (так по умолчанию), у каждого менеджера свой набор колонок.

Если **Нет**, все видят одинаковую таблицу. Сохранение UI отключено.

---

## Пустые состояния

| Сообщение | Что сделать |
| --- | --- |
| Нет доступных | Все поля уже в выбранных |
| Ничего по поиску | Уточните запрос |
| Нет выбранных | Добавьте хотя бы одну колонку перед сохранением |
