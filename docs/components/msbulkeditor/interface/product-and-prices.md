# Товар и цены

Массовые правки полей товара MiniShop3: цена, остаток, категории, производитель, варианты и несколько служебных действий.

Общий путь всегда один: отбор → **Запустить операцию** (или быстрое действие) → **Предпросмотр** → **Применить**.

![Диалог операции «Цена»](/components/msbulkeditor/screenshots/operation-price.png)

---

## Цена

**Запустить операцию** → тип **Цена**.

### Как изменить цену

| Режим в форме | Пример |
| --- | --- |
| **Установить значение** | Всем поставить 1990 |
| **Относительное +/-** | Было 1000, +100 → 1100 |
| **Проценты** | −10 % от текущей цены |

### Округление

| Вариант | Результат |
| --- | --- |
| Без округления | Как посчиталось |
| До целого | Математическое округление |
| Вниз / вверх | floor / ceil |
| До десятков / сотен | 1247 → 1250 или 1200 |

### Перенос между полями цены

![Перенос между полями цены](/components/msbulkeditor/screenshots/operation-price-transfer.png)

Режим **Перенос между полями** копирует значение из одного ценового поля в другое (например `price` → `old_price`). Можно очистить источник после копирования.

### Скидка с «старой ценой» на витрине

Включите флаг **Копировать текущую цену в old_price** перед изменением цены. Типичный сценарий акции: на витрине остаётся зачёркнутая старая цена.

### Товары с вариантами (ms3Variants)

| Область | Поведение |
| --- | --- |
| Только товар | Меняется основной товар |
| Товар и все варианты | Меняются и варианты |
| Пропустить с вариантами | Товары с вариантами не трогаются |

## Остаток

![Диалог «Остаток»](/components/msbulkeditor/screenshots/operation-stock.png)

Тип **Остаток**: те же режимы «установить», ± сумма, ± %. Округление по умолчанию до целого. Область вариантов работает так же, как у цены.

---

## Категории

| Режим | Действие |
| --- | --- |
| **Добавить категории** | Дописать дополнительные категории |
| **Удалить все доп. категории** | Снять все доп. привязки |
| **Сменить родителя** | Новый родительский ресурс |

## Варианты (ms3Variants)

![Операция «Вариант»](/components/msbulkeditor/screenshots/operation-variant.png)

Если установлен **ms3Variants**, тип **Вариант** меняет у вариантов цену, остаток, sku или вес выбранных товаров.

## Артикул и вес

![Текстовое поле](/components/msbulkeditor/screenshots/operation-text-set.png)

Операция **Текстовое поле**:

| Поле | Поведение |
| --- | --- |
| Артикул | Строка |
| Вес | Число ≥ 0 |

Режим «Оставить поле пустым» очищает артикул или ставит вес в 0.

## Метки new / popular / favorite

В MiniShop3 это флаги товара.

**Массово:** тип **Булево** → поле new / popular / favorite → Да / Нет / Инвертировать.

**Фильтр в таблице:** «Метка товара» + Да/Нет. См. [сетку](products-grid).

## Регенерация превью галереи

Пересобирает превью фото через MiniShop3. Товары без файлов в галерее пропускаются.

Откат из истории **не** вернёт файлы на диске как были. Для больших выборок уменьшите `msbulkeditor_chunk_size`.

Пункт есть в [быстрых действиях](quick-actions).

---

## Очистка кэша и URI

| Действие | Что происходит |
| --- | --- |
| Очистить кэш ресурса | Сброс кэша страницы товара |
| Перегенерировать URI | Пересчёт alias и URI |

Перед применением панель просит подтверждение. Товары с ручным URI (`uri_override`) при регенерации пропускаются.

Откат регенерации URI восстанавливает alias и URI из истории. Откат очистки кэша файлы кэша не возвращает.

![Подтверждение очистки кэша](/components/msbulkeditor/screenshots/confirm-clear-cache.png)

![Подтверждение регенерации URI](/components/msbulkeditor/screenshots/confirm-regenerate-uri.png)

## Мягкое удаление

Помечает товар удалённым (`deleted = 1`). Уже удалённые пропускаются. Перед записью — подтверждение. Откат из истории снимает пометку. Безвозвратного удаления из MODX здесь нет.

![Подтверждение мягкого удаления](/components/msbulkeditor/screenshots/confirm-soft-delete.png)

Пункт: [Быстрые действия](quick-actions) → **Мягкое удаление**.
