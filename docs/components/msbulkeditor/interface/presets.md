# Пресеты

Пресет — сохранённая настройка массовой операции под понятным именем. Пример: «Скидка −10 % с old_price». Вы один раз настроили параметры, сохранили и дальше запускаете их на новой выборке товаров.

Нужно право **`msbulkeditor_presets`**. Без него вкладка скрыта.

![Вкладка «Пресеты»](/components/msbulkeditor/screenshots/presets-tab.png)

![Форма пресета](/components/msbulkeditor/screenshots/presets-form.png)

---

## Когда это удобно

- одна и та же акция повторяется каждую неделю
- несколько менеджеров должны запускать одинаковую скидку без ручного набора полей
- вы уже проверили операцию через предпросмотр и хотите «зафиксировать» параметры

Пресет **не** хранит список товаров. При запуске берётся текущий отбор на вкладке **Товары** (галочки или экспертный режим).

---

## Вкладка «Пресеты»

| Элемент | Что делает |
| --- | --- |
| **Название** | Уникальное имя. Его вы увидите в списке и в меню на панели инструментов |
| Поле JSON | Техническое описание операции. Можно вставить готовый пример (см. ниже) |
| **Сохранить** | Создать или обновить пресет с этим именем |
| **Новый** | Очистить форму |
| **Редактировать** / **Загрузить** | Подставить выбранный пресет в форму |
| **Применить** | Открыть диалог операции на вкладке **Товары** с этими параметрами |
| **Удалить** | Запрос подтверждения, затем удаление |

![Подтверждение удаления](/components/msbulkeditor/screenshots/confirm-preset-delete.png)

Пустой список показывает подсказку «Пресетов пока нет».

### Как переименовать

1. Загрузите пресет в форму.
2. Измените только **Название**.
3. Нажмите **Сохранить**. Старое имя удалится после сохранения нового.

---

## Как создать пресет без ручного JSON

Практичный путь:

1. На вкладке **Товары** настройте операцию и сделайте **Предпросмотр**, чтобы убедиться в параметрах.
2. Откройте вкладку **Пресеты**.
3. Вставьте в форму JSON по образцу ниже (подставьте свои `mode`, `value` и флаги).
4. Задайте имя и нажмите **Сохранить**.

Кнопки «Скопировать JSON» в диалоге операции нет. Берите пример со страницы или текст из списка пресетов.

### Пример: скидка 10 %

```json
{
  "fieldType": "price",
  "parameters": {
    "field": "price",
    "mode": "percent",
    "sign": "-",
    "value": 10,
    "rounding": "integer",
    "transferToOldPrice": true,
    "variantScope": "product_only"
  }
}
```

`fieldType` — код типа операции. В обычном диалоге вы выбираете русское название (**Цена**, **Остаток**, …). Полный список кодов: [Возможности](../features#справочник-кодов-fieldtype).

Невалидный JSON при сохранении покажет сообщение об ошибке. Исправьте синтаксис и сохраните снова.

::: tip
Пресет с TV или опцией при запуске может открыть [мастер привязки](binding-wizard), если у части товаров поле не привязано.
:::

## Запуск с панели инструментов

На вкладке **Товары** откройте меню **Пресеты**:

![Меню пресетов на панели](/components/msbulkeditor/screenshots/preset-menu.png)

1. Отметьте товары или включите экспертный режим (иначе меню неактивно).
2. Выберите имя пресета.
3. Проверьте параметры в диалоге → **Предпросмотр** → **Применить**.

| Состояние меню | Что видно |
| --- | --- |
| Идёт загрузка | «Загрузка…» |
| Список пуст | «Нет пресетов» |
| Есть пресеты | Список имён |

---

## Сценарий на практике

1. Один раз прогоните скидку через предпросмотр на тестовой выборке.
2. Сохраните пресет «Скидка −10 % + old_price».
3. В день акции отфильтруйте нужную категорию, отметьте товары (или экспертный режим).
4. Запустите пресет из меню или с вкладки **Применить**.
5. При ошибке откатите операцию в [Истории](history).

---

## Где хранятся пресеты

Пресеты общие для всей установки MODX (не «только мои»). Создавать и удалять может любой менеджер с правом `msbulkeditor_presets`.
