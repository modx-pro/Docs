# Поля ресурса

Массовые операции над полями товара как ресурса MODX: флаги, SEO, текст, даты, группы доступа, связи. Цену, остаток, TV и опции смотрите на отдельных страницах.

Открыть: **Запустить операцию** → нужный тип в списке.

![Булево переключение](/components/msbulkeditor/screenshots/operation-boolean.png)

---

## Булево переключение

Включение, выключение или инверсия флагов.

### Какие поля

| Поле | Смысл |
| --- | --- |
| Публикация | Показывать на сайте |
| Скрыть из меню | Не показывать в меню |
| Удалён | Мягкое удаление (корзина) |
| searchable, cacheable, richtext, uri_override, show_in_tree | Служебные флаги MODX |
| new, popular, favorite | Метки MiniShop3 |

### Какое значение поставить

| В форме | Эффект |
| --- | --- |
| **Инвертировать** | Да станет Нет и наоборот |
| **Да** | Включить |
| **Нет** | Выключить |

Метки new / popular / favorite также описаны в [товар и цены](product-and-prices#метки-new--popular--favorite).

## SEO

![Операция SEO](/components/msbulkeditor/screenshots/operation-seo.png)

Записывает одно SEO-поле сразу всем товарам выборки.

| Поле | Назначение |
| --- | --- |
| longtitle | Длинный заголовок |
| description | Meta description |
| menutitle | Пункт меню |
| alias | Часть URL |

Нужна замена куска текста внутри поля? Используйте **Замена текста**, не SEO.

---

## Замена текста

![Замена текста](/components/msbulkeditor/screenshots/operation-text-replace.png)

Поиск и замена в одном текстовом поле за операцию.

Доступные поля: название, longtitle, description, introtext, content, alias, uri, menutitle.

Укажите поле, что искать и на что заменить.

---

## Даты

![Операция «Даты»](/components/msbulkeditor/screenshots/operation-dates.png)

| Поле | Смысл |
| --- | --- |
| createdon, editedon, publishedon | Системные даты |
| pub_date, unpub_date | Отложенная публикация / снятие |

| Режим | Что делает |
| --- | --- |
| Установить | Дата в формате `YYYY-MM-DD` или с временем |
| Очистить | Убрать значение |
| Сдвиг на N дней | Сдвинуть вперёд или назад (отрицательное число) |

Тот же тип доступен в [быстрых действиях](quick-actions) → **Изменить даты**.

## Группа ресурсов

![Группа ресурсов](/components/msbulkeditor/screenshots/operation-resource-group.png)

Назначает товарам группу доступа MODX. В форме выбираете одну группу из списка.

Пункт также есть в быстрых действиях: **Назначить группу ресурсов**.

---

## Связи товаров

![Связь товаров](/components/msbulkeditor/screenshots/operation-link.png)

Работа со связанными товарами MiniShop3.

| Режим | Действие |
| --- | --- |
| Добавить | Создать связь «этот товар → целевой» |
| Удалить | Убрать связь |

Укажите тип связи MiniShop3 и ID целевого товара. В предпросмотре видно, где связь уже есть или отсутствует.
