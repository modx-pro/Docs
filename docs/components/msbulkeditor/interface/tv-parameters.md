# TV-параметры

Массовая работа с дополнительными полями (TV) у товаров.

![Диалог операции «TV-параметр»](/components/msbulkeditor/screenshots/operation-tv.png)

---

## Как открыть

1. Отметьте товары или включите экспертный режим.
2. **Запустить операцию** → тип **TV-параметр**.

---

## Режимы

| Режим | Что делает |
| --- | --- |
| **Установить** | Записать новое значение |
| **Добавить к значению** | Дописать текст к текущему |
| **Заменить текст** | Найти и заменить подстроку |
| **Удалить** | Очистить TV |

Укажите **имя TV** (техническое имя, не подпись в менеджере). Для установки и добавления заполните значение. Для замены: что искать и на что заменить.

---

## Как выглядит поле ввода

Форма подстраивается под тип TV:

| Тип TV в MODX | Что вы видите |
| --- | --- |
| text, textarea, email, url | Текстовое поле |
| list / dropdown | Выпадающий список вариантов |
| image | Путь и кнопка **Обзор** (медиабраузер) |
| file, checkbox, date и др. | Базовый ввод текстом |

---

## Правка в ячейке таблицы

| Тип TV | В таблице |
| --- | --- |
| text, textarea, email, url | Клик → правка |
| image | Двойной клик → медиабраузер |
| list, checkbox, file | Только массовая операция |

Подробнее: [редактирование в списке](inline-editing).

---

## Привязка к шаблонам

Перед предпросмотром панель проверяет, привязан ли TV к шаблонам товаров. Если нет, откроется [мастер привязки](binding-wizard).

При разных шаблонах в выборке можно ограничить операцию основным шаблоном (флажок в мастере).

---

## Пример: заменить год в TV `subtitle`

1. Включите экспертный режим и отфильтруйте категорию.
2. **TV-параметр** → **Заменить текст**.
3. Имя: `subtitle`, искать `2024`, заменить на `2025`.
4. **Предпросмотр** → **Применить**.

![Предпросмотр TV](/components/msbulkeditor/screenshots/tv-preview.png)
