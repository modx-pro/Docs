# Предпросмотр и применение

Перед записью в базу вы всегда смотрите **предпросмотр**: сводку и таблицу «было / станет». Только после этого нажимаете **Применить**.

![Блок предпросмотра под таблицей](/components/msbulkeditor/screenshots/preview-block.png)

---

## Пошагово

1. Отберите товары на вкладке **Товары**.
2. Откройте **Запустить операцию**, быстрое действие или пресет.
3. Заполните форму. Пустые обязательные поля панель подсветит до запроса.
4. Нажмите **Предпросмотр**.
5. Под таблицей товаров появится блок предпросмотра.
6. Снимите галочки со строк, которые менять не нужно.
7. Нажмите **Применить**.
8. Дождитесь панели прогресса («обработано X из Y»).

Нужно право `msbulkeditor_edit`.

---

## Что показывает сводка

| Метрика | Смысл |
| --- | --- |
| Будет изменено | Товары, у которых значение реально изменится |
| Без изменений | Уже совпадает с целевым |
| Пропущено | Операция не затронет строку по правилам области |

В детальной таблице по умолчанию до 100 строк (`msbulkeditor_preview_detail_limit`). Администратор может поднять лимит в настройках.

В таблице вы видите ID товара, поле, старое значение, новое значение и статус строки.

---

## Как исключить товары из записи

После предпросмотра у строк с реальным изменением есть активный чекбокс. Снимите галочку — товар не попадёт в **Применить**.

- сводка «Будет изменено» пересчитается
- у строк «без изменений», «пропущено» и с ошибкой чекбокс неактивен
- **Отмена** в блоке предпросмотра сбрасывает результат и скрывает блок

![Чекбоксы исключения](/components/msbulkeditor/screenshots/preview-exclude.png)

## Кнопки

| Кнопка | Когда доступна |
| --- | --- |
| **Предпросмотр** | Форма операции заполнена корректно |
| **Применить** | После предпросмотра, если «Будет изменено» больше 0 |
| **Отмена** | Пока виден блок предпросмотра |

Если «Будет изменено» = 0, панель сообщит `msbulkeditor_apply_no_changes`. Проверьте параметры и выборку: возможно, значения уже такие, как вы задали.

Слишком много товаров в экспертном режиме? Сообщение `msbulkeditor_expert_limit_exceeded`. Сузьте фильтр или попросите администратора поднять `msbulkeditor_expert_limit`. См. [сетку](products-grid#экспертный-режим).

## Как идёт запись

Изменения пишутся **пачками** (по умолчанию по 50 товаров, настройка `msbulkeditor_chunk_size`). Так операция не упирается в лимит времени PHP на одном огромном запросе.

Пока идёт применение:

- под таблицей видна панель прогресса
- вторую массовую операцию запустить нельзя
- кнопки «Отменить прямо сейчас» нет. Дождитесь конца или после завершения откатите в [Истории](history)

![Панель прогресса](/components/msbulkeditor/screenshots/progress-panel.png)

| Итог | Что делать |
| --- | --- |
| Завершена | Проверьте таблицу и вкладку **История** |
| Ошибка | Откройте **История**. Часть товаров могла уже измениться. Откатите применённые позиции |
| Отменена | Редкий статус с сервера. Дальше смотрите **Историю** |

После успешного завершения строки таблицы обновляются без перезагрузки всей страницы менеджера.

::: tip
Повторный клик по **Применить** с тем же запросом не создаст дубль: панель защищает от двойного нажатия.
:::

## Особый случай: операция по TV

Если тип операции — TV, форма подстраивается под тип поля в MODX:

| Тип TV в MODX | Что вы видите в диалоге |
| --- | --- |
| Список / dropdown | Выпадающий список вариантов |
| Checkbox | Переключатель |
| Image / file | Путь и кнопка **Обзор** (медиабраузер MODX) |
| Остальные | Текстовое поле |

Имя TV выбирайте из списка каталога. Подробнее: [TV-параметры](tv-parameters).
