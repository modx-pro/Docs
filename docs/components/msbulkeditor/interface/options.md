# Опции MiniShop3

Массовое изменение опций товара MiniShop3 (цвет, размер, теги и любые ключи из настроек MS3).

![Диалог операции «Опция»](/components/msbulkeditor/screenshots/operation-option.png)

---

## Как открыть

1. Отметьте товары или включите экспертный режим.
2. **Запустить операцию** → тип **Опция**.

---

## Одно значение или теги

В форме сначала выберите тип значения:

| В форме | Когда брать |
| --- | --- |
| **Одно значение** | Опция хранит одну строку (текст, select) |
| **Теги (несколько значений)** | Опция хранит набор тегов (цвета, метки) |

Тип опции панель не угадывает. Выбирайте вручную под то, как опция заведена в MiniShop3.

---

## Одно значение

| Режим | Действие |
| --- | --- |
| **Установить значение** | Записать новую строку |
| **Заменить значение** | Найти подстроку и заменить |
| **Удалить значение** | Очистить опцию |

Укажите **ключ** опции. Для установки и замены заполните значение (или «найти / заменить»).

В режиме замены можно взять текущее значение из товаров на странице таблицы (picker «Текущее значение в выборке»).

---

## Теги (несколько значений)

![Опция: теги](/components/msbulkeditor/screenshots/operation-option-multi.png)

| Режим | Действие |
| --- | --- |
| **Добавить теги** | Добавить теги без дубликатов |
| **Заменить тег** | Точное совпадение: старый тег → новый |
| **Удалить тег** | Убрать тег из набора |

Предпросмотр показывает список тегов «было / станет».

---

## На что обратить внимание

- Сложные виджеты MS3 (дата, textarea) в массовой форме идут как обычный текст.
- Если опция не привязана к категории части товаров, откроется [мастер привязки](binding-wizard).
- В ячейке таблицы правятся только опции с **одним** значением. Наборы тегов меняйте массовой операцией.

---

## Пример: добавить тег `sale`

1. Отберите товары.
2. **Опция** → тип **Теги**.
3. Ключ: `tags`, режим **Добавить теги**, значение `sale`.
4. **Предпросмотр**. Строки, где `sale` уже есть, попадут в «без изменений» / «пропущено».
5. **Применить**.

![Предпросмотр опции](/components/msbulkeditor/screenshots/option-preview.png)

---

## Опции в таблице товаров

Добавьте колонку опции через [настройку колонок](column-settings). Несколько значений показываются через запятую. Одно значение можно править кликом. См. [редактирование в списке](inline-editing).
