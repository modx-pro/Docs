# FAQ

Ключи `msbulkeditor_*` в интерфейсе и логе. До процессора коннектор может вернуть обычный английский текст: `config.core.php not found.`, `Invalid action.`, `Processor failed.`.

## Общие

### С какими товарами работает панель?

С товарами **MiniShop3** (`msProduct`) в менеджере **MODX 3**. Обычные ресурсы MODX (не товары магазина) панель не меняет.

## Установка и доступ

### Не открывается панель / предупреждение про VueTools

1. Установите **[VueTools](https://modstore.pro/)** (`modxpro-vue-core`) через ModStore.
2. Очистите кэш MODX.
3. Жёстко обновите страницу менеджера (Cmd+Shift+R или Ctrl+Shift+R).

### Вкладки «Пресеты» или «Импорт» не видны

Нужны права `msbulkeditor_presets` и `msbulkeditor_import_export`. Без права вкладка скрыта. Прямая ссылка вернёт на **Товары**.

### Сообщение про отказ в доступе

Запросите у администратора нужное право (`view`, `edit`, `rollback` и т.д.). Таблица: [Настройки](settings#права-доступа).

### Сессия или токен недействительны

Обновите страницу менеджера. Если сессия истекла, войдите снова.

## Операции

### «Нет изменений» при применении

В предпросмотре 0 строк к изменению. Проверьте параметры и выборку: значения уже могут совпадать с целевыми.

### Превышен лимит экспертного режима

Сузьте фильтры или попросите администратора поднять `msbulkeditor_expert_limit` (с учётом памяти и лимита времени PHP).

### Не вижу экспертный режим

Администратор выключил `msbulkeditor_expert_mode`. Включите в системных настройках области `msbulkeditor`.

### Клик по опции заменяет набор тегов

Клик по колонке опции записывает одну строку и заменяет прежний набор. TV типов list / checkbox / file в ячейке не открываются. Отдельный тег добавляйте массовой операцией. См. [Редактирование в списке](interface/inline-editing).

### Открылся мастер привязки

У части товаров нет нужного TV или опции на шаблоне / категории. Пройдите мастер или сузьте выборку. → [Мастер привязки](interface/binding-wizard)

## Импорт и экспорт

### XLSX не экспортируется

На сервере недоступен OpenSpout из пакета. Экспортируйте CSV или проверьте установку пакета.

### Ошибка маппинга импорта

Укажите колонку ID и хотя бы одно поле значения (цена, остаток или артикул). Без колонки ID текущий фильтр не используется.

### Ошибка файла импорта

Проверьте формат (CSV/XLSX), размер и лимит `msbulkeditor_import_max_rows`.

### Почему импорт не пишет TV и опции?

Вкладка импорта обновляет только цену, остаток и артикул. TV и опции меняйте массовой операцией на вкладке **Товары**.

## История

### Нет кнопки «Откат»

Нужно право `msbulkeditor_rollback`. Откат доступен для завершённых операций. У операции с ошибкой откатываются только уже записанные позиции. См. [История](interface/history).

### История не очищается

Журнал чистится и без Scheduler: плагин `msbulkeditor_bootstrap` запускает очистку не чаще раза в сутки, когда открывают страницу менеджера. Если Scheduler установлен, пакет включает задачу и повторяет это при каждом обновлении. См. [Настройки](settings#scheduler).

## Краткая шпаргалка по сообщениям

| Сообщение | Действие |
| --- | --- |
| `msbulkeditor_vuetools_required` | Установите VueTools |
| `msbulkeditor_products_load_failed` | Лог MODX, MiniShop3, фильтры |
| `msbulkeditor_binding_*` | [Мастер привязки](interface/binding-wizard) |
| `msbulkeditor_apply_no_changes` | Нет строк к изменению в предпросмотре |
| `msbulkeditor_expert_limit_exceeded` | Сузьте фильтр |
| `msbulkeditor_expert_mode_disabled` | Включите `msbulkeditor_expert_mode` |
| `msbulkeditor_auth_method_not_allowed` | Запись только методом POST |
| `msbulkeditor_import_file_too_large` | Файл больше 10 МБ |
| `msbulkeditor_processor_failed` | Смотрите лог MODX |

## Ограничения

- только товары MiniShop3 (`msProduct`)
- клик по колонке опции записывает одну строку и заменяет набор тегов
- TV list / checkbox / file в ячейке не правятся
- тип опции в массовой форме (одно значение или теги) выбираете вручную
