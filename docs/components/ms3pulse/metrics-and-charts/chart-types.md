# Типы графиков

ms3Pulse строит диаграммы на **Apache ECharts 6**. Доступно 15 типов.

## Список

| Тип | Описание |
|-----|----------|
| Линейный | Плавная линия по времени. |
| Ступенчатая линия | Линия с дискретными шагами. |
| С областью | Линия с заливкой под кривой. |
| Область с накоплением | Площадной график с суммой серий. |
| Столбчатый | Вертикальные столбцы. |
| Горизонтальные столбцы | Рейтинги и топы. |
| Столбцы с накоплением | Несколько серий в одном столбце. |
| Точечный | Точки по осям X/Y. |
| Круговая | Доли в целом. |
| Роза (Nightingale) | Круговая с секторами по площади. |
| Кольцевая | Круговая с вырезом в центре. |
| Воронка | Убывающие блоки. |
| Радар | Радарная диаграмма. |
| Спидометр | Индикатор-стрелка. |
| Дерево (treemap) | Прямоугольники по величине. |

![Первые четыре графика на «Динамике»: area, bar, line и кастомная область](/components/ms3pulse/screenshots/chart-types-examples.png)

## Рекомендации

- **По времени** (выручка, заказы, средний чек) — линия, область, столбцы, точечный.
- **Топ товаров и статусы** — горизонтальные столбцы, круговая, кольцевая, воронка, дерево.

Не каждая пара «тип × источник» даёт наглядный результат. Ориентир: [рекомендуемые сочетания](../interface/builder#рекомендуемые-сочетания).

::: details Ключи ECharts (для разработчиков)
`line`, `lineStep`, `area`, `stackedArea`, `bar`, `barHorizontal`, `stackedBar`, `scatter`, `pie`, `rose`, `donut`, `funnel`, `radar`, `gauge`, `treemap`.
:::
