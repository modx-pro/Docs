# Источники данных для графиков

Графики строятся по одному из пяти источников. Все учитывают период, статусы и группировку (для временных рядов).

## Список

| Источник | Описание |
|----------|----------|
| **Выручка по дням** | Сумма заказов по дню, неделе или месяцу (зависит от группировки). |
| **Заказы по дням** | Количество заказов по интервалам времени. |
| **Средний чек по дням** | Выручка ÷ количество заказов за каждый интервал. |
| **Топ товаров** | Товары по убыванию выручки: название, выручка, количество. |
| **Заказы по статусам** | Количество заказов в каждом статусе с цветом статуса из MS3. |

## Фильтры

- **Период** — «От» и «До».
- **Статусы** — пусто = все статусы.
- **Группировка** — день / неделя / месяц для источников «по дням».

## Лимит точек в конструкторе

В форме «Добавить график» поле **«Кол-во данных»**: 5, 10, 20, 50, 100.

- Для выручки, заказов и среднего чека — последние N точек по времени.
- Для топа товаров и статусов — первые N записей.

Это снижает перегрузку графика при длинном периоде или большом каталоге.
