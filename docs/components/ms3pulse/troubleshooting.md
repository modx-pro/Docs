# Решение проблем

## Графики не отображаются

1. Установлен **[VueTools](/components/vuetools/) 1.1.1+**.
2. У пользователя есть **ms3pulse_view**.
3. Консоль браузера (F12): нет 404 на JS/CSS, нет ошибок при вызове `assets/components/ms3pulse/connector.php`.
4. Коннектор возвращает JSON, а не HTML страницы входа. Вы авторизованы в manager.

## Пустые метрики и графики

1. За выбранный период есть заказы MiniShop3.
2. Фильтр статусов не исключает все заказы.
3. Расширьте период или снимите фильтр статусов.
4. Нажмите **«Обновить»** после смены фильтров.

## Ошибка экспорта CSV

1. Консоль и ответ сервера на запрос ExportCsv.
2. Период и статусы заданы, данные за период есть.
3. Права **ms3pulse_view** и рабочая сессия manager.

## Пропали кастомные графики или таблицы

Layout хранится в **localStorage** браузера. Пропадает при смене браузера, инкогнито или очистке данных сайта. Восстановить нельзя — добавьте заново.

## Отчёт не приходит на email

1. **ms3pulse_scheduled_export_enabled** = Да, email указан.
2. Задача Scheduler с **SendScheduledReport** выполняется по расписанию.
3. Настройки почты MODX (`mail_*`) работают.
4. Проверьте «Спам» и логи сервера.

## Пресеты и фильтры не реагируют

1. Полная перезагрузка страницы (Ctrl+Shift+R).
2. Консоль на ошибки JavaScript.
3. Отключите блокировщики скриптов.
4. **Управление → Очистить кэш** в MODX.

## Платный пакет: Package provider not found

Подключите провайдер [modstore.pro](https://modstore.pro/extras/) в **Extras → Installer** перед установкой ms3Pulse.
