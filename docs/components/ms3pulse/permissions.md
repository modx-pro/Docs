# Права доступа

Доступ к ms3Pulse через права MODX и политику **ms3PulseUserPolicy**.

## Права

| Право | Описание |
|-------|----------|
| `ms3pulse_view` | Дашборд и конструктор графиков. Без права пункт **Компоненты → ms3Pulse** скрыт. |
| `ms3pulse_save` | Зарезервировано. В текущей версии UI и API его не проверяют. |

## Назначение

1. **Управление → Права доступа**.
2. Выберите роль или пользователя.
3. В политике **ms3PulseUserPolicy** включите **ms3pulse_view**.
4. Сохраните.

![Политика ms3Pulse](/components/ms3pulse/screenshots/permissions-policy.png)

Пункт **ms3Pulse → Настройки** ведёт в системные настройки MODX. Доступ к ним определяется правами на **system/settings**, не ms3pulse.
