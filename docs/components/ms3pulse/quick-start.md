# Быстрый старт

Пошаговое руководство по установке и первому запуску ms3Pulse.

## Требования

| Требование | Версия |
|------------|--------|
| MODX Revolution | 3.0.0+ |
| PHP | 8.1+ |
| MiniShop3 | установлен и настроен |
| VueTools | 1.1.1+ |

## Шаг 1: Установка

1. [Подключите репозиторий ModStore](https://modstore.pro/info/connection), если пакет платный.
2. Перейдите в **Extras → Installer**.
3. Найдите **ms3Pulse**, нажмите **Download**, затем **Install**.
4. **Управление → Очистить кэш**.

## Шаг 2: Первый запуск

1. Откройте **Компоненты → ms3Pulse**.
2. На дашборде четыре вкладки: **Обзор**, **Динамика**, **Товары**, **Топы / Флопы**.

![Главный экран дашборда — вкладка «Обзор»](/components/ms3pulse/screenshots/dashboard-overview.png)

## Шаг 3: Период и фильтры

1. Раскройте панель **«Фильтры»**.
2. Задайте **«От»** и **«До»** или нажмите пресет (**7**, **30**, **90**, **180**, **365** дней).
3. При необходимости выберите **статусы заказов**. Пусто = все статусы.
4. Нажмите **«Обновить»**.

![Панель фильтров](/components/ms3pulse/screenshots/filters-panel.png)

## Шаг 4: Вкладки дашборда

- **Обзор** — шесть метрик, сравнение с предыдущим периодом, мини-график выручки.
- **Динамика** — фиксированные графики выручки, заказов и среднего чека плюс кастомные (область, столбцы, точки, линия).
- **Товары** — топ товаров, заказы по статусам плюс кастомные (круг, кольцо, горизонтальные столбцы, воронка, treemap).
- **Топы / Флопы** — до шести типов таблиц на одной вкладке, сортировка, экспорт CSV.

![Вкладка «Динамика» — area, bar, scatter, line](/components/ms3pulse/screenshots/tab-dynamics.png)

![Вкладка «Товары» — pie, donut, barHorizontal, funnel, treemap](/components/ms3pulse/screenshots/tab-products.png)

## Шаг 5: Свой график (опционально)

1. **ms3Pulse → Конструктор** или кнопка **«В конструктор»** на вкладках «Динамика» / «Товары».
2. Раскройте **«Добавить график»**.
3. Выберите тип, источник данных, размер и вкладку.
4. Нажмите **«Добавить»**.

Кастомные графики хранятся в **localStorage** браузера.

![Конструктор — форма «Добавить график»](/components/ms3pulse/screenshots/builder-form.png)

## Шаг 6: Экспорт

- **CSV** — кнопка у каждой таблицы на вкладке «Топы / Флопы».
- **PNG** — меню карточки графика (три точки) → **«Экспорт изображения (PNG)»**.
