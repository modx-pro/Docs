# Экспорт данных и графиков

ms3Pulse выгружает таблицы в CSV и графики в PNG.

## CSV таблиц

На вкладке **«Топы / Флопы»** у каждой таблицы есть кнопка **CSV**.

1. Настройте период и статусы в фильтрах.
2. Нажмите CSV у нужной таблицы.
3. Браузер скачает файл UTF-8 с BOM.

Поддерживаемые типы: топ/флоп товаров, заказы по статусам, выручка по дням, заказы по доставке, заказы по оплате.

![Кнопка экспорта CSV](/components/ms3pulse/screenshots/export-csv-button.png)

## PNG графиков

1. На вкладке «Обзор», «Динамика» или «Товары» откройте меню карточки (три точки).
2. Выберите **«Экспорт изображения (PNG)»**.
3. Браузер сохранит снимок графика с белым фоном.

![Меню графика — экспорт PNG](/components/ms3pulse/screenshots/export-chart-menu.png)

::: info
Экспорт данных графика в CSV из меню карточки в текущей версии не выведен. CSV доступен только для таблиц на вкладке «Топы / Флопы».
:::
