# FAQ

## Что означает «Оплата» на вкладке «Обзор»?

Это **выручка минус сумма доставки** за период. Не сумма по способам оплаты. Таблица «Заказы по оплате» на вкладке «Топы / Флопы» как раз группирует по способам оплаты MS3.

## Какие статусы включать в выручку?

Зависит от вашей логики учёта. Часто в аналитику берут оплаченные и выполненные статусы. Пустой фильтр статусов = все заказы за период. Экспериментируйте с мультивыбором и смотрите карточку «Выручка».

## Почему пропали мои графики и таблицы?

Кастомные графики и layout таблиц хранятся в **localStorage** браузера. Они не синхронизируются между пользователями и устройствами. Очистка данных сайта или другой браузер = пустой layout.

## Есть ли демо-данные без заказов?

Нет. При отсутствии заказов за период показываются пустые состояния. Для скриншотов и тестов нужны заказы MiniShop3 или импорт тестовых данных.

## Работает ли тур по интерфейсу?

В текущей версии кнопка тура отключена. Разделы описаны в [Сценариях (flows)](interface/flows) и [Быстром старте](quick-start).

## Как вызвать отчёт по cron?

```text
https://ваш-сайт/assets/components/ms3pulse/connector.php?action=Dashboard/SendScheduledReport&token=ВАШ_ТОКЕН
```

Включите `ms3pulse_scheduled_export_enabled` и задайте token в настройках. Подробнее: [Отчёты по расписанию](scheduled-reports).

## Письмо с отчётом не приходит

Проверьте настройки почты MODX, email получателя, выполнение задачи Scheduler и папку «Спам». Отчёт содержит CSV «выручка по дням» за N последних дней.

## Нужен ли Scheduler?

Только для отчётов по расписанию. Дашборд, графики и ручной CSV работают без Scheduler.

## Ошибка Package provider not found при установке

Подключите провайдер [modstore.pro](https://modstore.pro/extras/) в Installer. Пакет распространяется через ModStore.

## Что даёт право ms3pulse_save?

Зарезервировано для будущих операций записи. Сейчас UI проверяет только **ms3pulse_view**.

## Экспорт данных графика в CSV

В меню карточки графика доступен только **PNG**. CSV — у таблиц на вкладке «Топы / Флопы».

## VueTools: какая версия?

**1.1.1+**. Без VueTools дашборд не загрузится. Установите до или вместе с ms3Pulse.

Если проблема осталась: [Решение проблем](troubleshooting).
