# Топы и флопы (конструктор таблиц)

Вкладка **«Топы / Флопы»** — настраиваемые таблицы по заказам и товарам.

## 6 типов таблиц

| Тип | Колонки |
|-----|---------|
| Топ товаров | №, Товар, Выручка, Кол-во |
| Флоп товаров | Те же (товары с наименьшей выручкой) |
| Заказы по статусам | Статус, Заказов, Выручка |
| Выручка по дням | Дата, Выручка, Заказов |
| Заказы по доставке | Доставка, Заказов, Выручка |
| Заказы по оплате | Способ оплаты, Заказов, Выручка |

![Топ и флоп товаров — две карточки рядом](/components/ms3pulse/screenshots/topflops-tables.png)

## Форма «Добавить таблицу»

Панель по умолчанию **свёрнута**.

| Поле | Описание |
|------|----------|
| **Тип** | Один из шести типов. |
| **Название** | Заголовок блока таблицы. |
| **Ширина** | 50% или 100% строки. |
| **Лимит строк** | 5, 10, 50, 100. |

![Форма «Добавить таблицу»](/components/ms3pulse/screenshots/topflops-add-table.png)

## Возможности

- **Сортировка** — клик по заголовку колонки.
- **Итоговая строка** — суммы по выручке и количеству где применимо.
- **Экспорт CSV** — кнопка у каждой таблицы. UTF-8 с BOM для Excel.
- **Хранение** — конфигурация в localStorage.

## Экспорт

Имя файла формируется автоматически, например `ms3pulse-top-2026-02-11.csv`. Учитываются текущие фильтры: период и статусы.
