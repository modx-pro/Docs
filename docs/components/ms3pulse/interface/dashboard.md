# Интерфейс дашборда

Главная страница ms3Pulse: фильтры, метрики, графики и таблицы.

## Шапка

- Название **ms3Pulse**.
- Переключение вкладок дашборда.

![Шапка дашборда](/components/ms3pulse/screenshots/dashboard-header.png)

## Панель фильтров

По умолчанию **свёрнута**. Раскрывается по клику на **«Фильтры»**.

| Элемент | Описание |
|---------|----------|
| **Период** | Поля «От» и «До» (DatePicker, ДД.ММ.ГГГГ). |
| **Статусы** | Мультивыбор статусов MiniShop3. Пусто = все. Цвета из настроек MS3. |
| **Группировка** | День / неделя / месяц — агрегация точек на временных графиках. |
| **Пресеты** | 7, 30, 90, 180, 365 дней. «До» = сегодня, «От» = сегодня − N. |
| **Обновить** | Перезагрузка данных с сервера. |

![Панель фильтров](/components/ms3pulse/screenshots/filters-panel.png)

Подробнее: [Фильтры и период](../metrics-and-charts/filters).

## Вкладки

| Вкладка | Содержимое |
|---------|------------|
| **Обзор** | Шесть карточек метрик, % к предыдущему периоду, мини-график выручки. |
| **Динамика** | Три фиксированных графика (выручка, заказы, средний чек) + кастомные. Кнопка «В конструктор». |
| **Товары** | Топ товаров, заказы по статусам + кастомные. Кнопка «В конструктор». |
| **Топы / Флопы** | Конструктор таблиц, сортировка, CSV. |

![Карточки метрик — Обзор](/components/ms3pulse/screenshots/metrics-cards.png)

## Пустые состояния

Нет данных за период — сообщение с предложением изменить фильтры. Нет кастомных графиков — подсказка добавить через конструктор.

## Карточки графиков

- **Tooltip** при наведении.
- **Меню** (три точки): ширина (100%, 75%, 50%, 25%), экспорт PNG, удаление (кастомные).
- **Перетаскивание** — порядок графиков на вкладке.
- **Редактирование** — описание кастомного графика на дашборде.
