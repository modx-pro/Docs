# Интерфейс ms3Pulse

Обзор разделов. Пошаговые сценарии: [Сценарии (flows)](flows).

## Точки входа

| Раздел | Доступ | Описание |
|--------|--------|----------|
| **Дашборд** | Компоненты → ms3Pulse | Метрики, фильтры, вкладки с графиками и таблицами. |
| **Конструктор** | ms3Pulse → Конструктор | Кастомные графики для «Динамика» и «Товары». |
| **Настройки** | ms3Pulse → Настройки | Системные настройки namespace `ms3pulse`. |

## Документация

- [Дашборд](dashboard) — фильтры, вкладки, карточки графиков.
- [Конструктор графиков](builder) — форма, превью, localStorage.
- [Топы и флопы](topflops) — таблицы, сортировка, CSV.
- [Настройки в меню](settings) — быстрый переход к системным настройкам.
