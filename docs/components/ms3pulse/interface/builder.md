# Конструктор графиков (билдер)

Добавление своих графиков на вкладки **«Динамика»** и **«Товары»**.

## Доступ

- **Компоненты → ms3Pulse → Конструктор**
- Кнопка **«В конструктор»** на вкладках «Динамика» и «Товары»

![Страница конструктора](/components/ms3pulse/screenshots/builder-page.png)

## Форма «Добавить график»

Панель по умолчанию **свёрнута**.

| Поле | Описание |
|------|----------|
| **Тип** | 15 типов: линия, ступенчатая, область, столбцы, горизонтальные столбцы, точечный, круговая, роза, кольцевая, воронка, радар, спидометр, дерево и др. |
| **Источник данных** | Выручка по дням, заказы по дням, средний чек по дням, топ товаров, заказы по статусам. |
| **Размер** | 100%, 75%, 50%, 25% ширины сетки. |
| **Вкладка** | Динамика или Товары. |
| **Кол-во данных** | 5, 10, 20, 50, 100. Для временных источников — последние N точек. Для топа и статусов — первые N записей. |
| **Заголовок** | Необязательно. |
| **Описание** | Необязательно. |

После **«Добавить»** график появится на выбранной вкладке. Активная вкладка запоминается в localStorage.

![Форма «Добавить график»](/components/ms3pulse/screenshots/builder-form.png)

## Превью типов

На странице конструктора сетка превью всех 15 типов — можно оценить вид до добавления.

## Хранение

Кастомные графики, порядок и размеры хранятся в **localStorage** браузера. При смене браузера или очистке данных сайта список нужно собрать заново.

## Рекомендуемые сочетания

| Источник | Подходящие типы |
|----------|-----------------|
| Выручка / заказы / средний чек по времени | Линия, область, столбцы, точечный, радар, спидометр |
| Топ товаров | Горизонтальные столбцы, круговая, кольцевая, воронка, дерево |
| Заказы по статусам | Круговая, кольцевая, воронка, радар, дерево |

Подробнее: [Типы графиков](../metrics-and-charts/chart-types), [Источники данных](../metrics-and-charts/data-sources).
