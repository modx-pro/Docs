# ManagerButtons

Группы кнопок на главной панели управления MODX3. Кнопка открывает раздел менеджера или внешнюю ссылку. Набор можно назначить для группы пользователей или оставить только администраторам.

Интерфейс работает через [VueTools](/components/vuetools/). Внешний вид берётся из настройки `vuetools.theme`.

## Требования

| | |
| --- | --- |
| MODX | 3.0+ |
| PHP | 8.1+ |
| VueTools | 1.2.0+ |

VueTools ставится первым. Без него пакет не установится: зависимость указана в транспорте.

## Установка

1. **Приложения → Установщик**. Установите VueTools, если его ещё нет.
2. Загрузите `ManagerButtons-1.2.1-pl.transport.zip` и установите пакет.
3. Очистите папку cache.

В меню **Пакеты** появится пункт **ManagerButtons**. На дашборд Default добавляется виджет с тем же именем.

Пункт меню виден администраторам и пользователям с правом `managerbuttons`. Право записывается в политику Administrator при установке.

## Группы

Группа — это набор кнопок в сетке из четырёх колонок.

![Список групп](./img/groups.png)

У группы два поля: **название** и **группы пользователей**.

Администраторы (группа `Administrator` и пользователи с `sudo`) видят все наборы. Если группы пользователей не выбраны, набор видят только администраторы.

Порядок групп меняется перетаскиванием строк. Пока в поиске что-то введено, порядок не меняется. Несколько групп можно удалить сразу, отметив строки.

## Кнопки

В строке группы кнопка с сеткой открывает список кнопок. Внизу окна — тот же вид, что на панели управления.

![Кнопки группы и предпросмотр](./img/buttons.png)

У кнопки:

- **Название**
- **Ссылка** — действие менеджера (`?a=resource/create`), путь на сайте или адрес `https://`
- **Колонки** — ширина от 1 до 4. Закрашенные клетки показывают, сколько места займёт кнопка
- **Описание** — короткая строка под названием. Можно не заполнять
- **Фон** — свой цвет. Пустое поле берёт цвет из общих настроек
- **Иконка** — Font Awesome 5 из менеджера MODX. В базе хранится короткое имя, например `plus`

![Форма кнопки](./img/button.png)

Ссылки `?a=...` открываются в менеджере без полной перезагрузки. Адреса `http` и `https` открываются в новой вкладке.

Кнопки в одной строке сетки одной высоты. Текст прижат к верху, поэтому короткое название не «висит» посередине рядом с кнопкой, у которой есть описание.

## Общие настройки

Кнопка **Общие настройки** задаёт фон и цвет текста для всех кнопок.

![Общие настройки](./img/settings.png)

Если фон не задан, кнопки синие `#234368`, текст белый. Свой фон кнопки важнее общего. Те же значения лежат в системных настройках `managerbuttons.background` и `managerbuttons.color`.

## Панель управления

Виджет **ManagerButtons** показывает наборы, доступные текущему пользователю. У каждой группы свой заголовок и своя сетка.

![Набор на панели управления](./img/dashboard.png)

Чтобы виджет показывал одну группу, в его свойствах укажите `group_id` — числовой id группы. Пустое значение выводит все доступные наборы.

## Экспорт и импорт

**Экспорт** скачивает JSON группы: название, кнопки и имена групп пользователей.

**Импорт** всегда создаёт новую группу. Так набор переносится на другой сайт или копируется на этом. **Дублировать** в таблице делает то же самое без файла.

Группы пользователей ищутся по имени. Если на сайте нет группы с таким именем, это ограничение не переносится. Администраторы набор всё равно видят.

```json
{
  "package": "ManagerButtons",
  "format": 1,
  "version": "1.2.1-pl",
  "group": {
    "name": "Контент",
    "usergroups": ["Editor"],
    "buttons": [
      {
        "name": "Создать ресурс",
        "url": "?a=resource/create",
        "icon": "plus",
        "description": "Новая страница в дереве",
        "background": "",
        "cols": 2,
        "rank": 0
      }
    ]
  }
}
```
