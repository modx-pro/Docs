# Готовые сценарии

Решения для задач, которые встречаются почти на каждом сайте. Код можно брать целиком: большинство примеров настраивается атрибутами в разметке формы и не требует правки скрипта под каждую новую форму.

## На странице

- [Индикатор отправки](/components/fetchit/examples/scenarios/loading) — спиннер или «Отправляем…» на кнопке
- [Благодарность вместо формы](/components/fetchit/examples/scenarios/thank-you) — блок «Спасибо» на месте отправленной формы
- [Переход на другую страницу](/components/fetchit/examples/scenarios/redirect) — редирект после успеха
- [Маска телефона](/components/fetchit/examples/scenarios/phone-mask) — ввод номера по шаблону
- [Загрузка файлов](/components/fetchit/examples/scenarios/files) — проверка размера и типа до отправки
- [Несколько форм на странице](/components/fetchit/examples/scenarios/multiple-forms) — разное поведение для разных форм

## Аналитика и интеграции

- [Цели в Метрике и Google Analytics](/components/fetchit/examples/scenarios/analytics) — Яндекс Метрика, GA4, Google Tag Manager, VK Реклама
- [Заявка в Telegram](/components/fetchit/examples/scenarios/telegram) — хук FormIt, который присылает заявки в чат

Модальные окна, уведомления и клиентская проверка полей — в соседних разделах: [модальные окна](/components/fetchit/examples/modals/), [всплывающие сообщения](/components/fetchit/examples/notifications/), [валидация](/components/fetchit/examples/validation/).
