# Шаблоны

Шаблон и есть всё письмо. PostCraft отправляет HTML чанка как есть, без общей шапки и подвала сайта.

## Чанки

Шаблоны хранятся в чанках с именем `PostCraft.Имя`. После установки есть два:

| Чанк | Что внутри |
|---|---|
| `PostCraft.Blank` | приветствие, текст, ссылки на веб-версию и отписку |
| `PostCraft.Promo` | то же с кнопкой |

Обновление пакета не перезаписывает эти чанки, но для своих писем удобнее создать копию: «Создать копию» и имя вида `Offer`. PostCraft сохранит чанк как `PostCraft.Offer`. В имени допустимы латиница, цифры, точка, `_` и `-`.

## Редактор

Редактор зависит от системной настройки `which_editor`:

| `which_editor` | Редактор |
|---|---|
| CKEditor | CKEditor |
| TinyMCE RTE | TinyMCE |
| пусто | поле HTML |

Превью показывает письмо в трёх ширинах: телефон, планшет, десктоп. «Обновить превью» перерисовывает его после правок, «Сохранить шаблон» записывает чанк.

## Плейсхолдеры

| Плейсхолдер | Значение |
|---|---|
| `{{ mirror }}` | адрес веб-версии письма |
| `{{ unsubscribe }}` | адрес страницы отписки |

PostCraft подставляет их отдельно для каждого получателя. При включённом трекинге кликов остальные ссылки письма идут через редирект `t.php`.

## Советы по вёрстке

- Пишите стили в атрибуте `style`. Почтовые программы часто вырезают `<style>`.
- Ширина письма до 600–640 px.
- Картинки указывайте полными адресами с `https://`.
