# Страница в админке

«Приложения → PostCraft» (в MODX 3 «Пакеты → PostCraft») открывает страницу с вкладками:

| Вкладка | Что на ней |
|---|---|
| [Рассылка](campaign) | новое письмо: шаблон, получатели, окно отправки |
| Списки | сохранённые списки адресов |
| [Шаблоны](templates) | HTML писем и превью |
| [Страница отписки](unsubscribe) | тексты страниц отписки для каждого сайта и языка |
| [Статистика](stats) | рассылки, их статус, открытия, клики, отписки, управление очередью |
| Blacklist | адреса, которым письма не уходят |

Шестерёнка справа от вкладок открывает ящики отправителя.

## Списки

Список хранит адреса под названием. Адреса пишутся столбиком или через запятую. При сохранении PostCraft убирает повторы и сообщает, сколько адресов уже есть в других списках и сколько стоят в blacklist.

На вкладке «Рассылка» список выбирается в поле «Сохранённый список», кнопка «Подставить» добавляет его адреса к полю «Адреса».

## Blacklist

Адреса из blacklist пропускаются во всех рассылках. Сюда попадают:

- отписавшиеся по ссылке `{{ unsubscribe }}`;
- адреса с hard bounce, если настроен [разбор возвратов](../settings#bounces);
- адреса, добавленные вручную.

Поле добавления принимает несколько адресов за раз: столбиком, через запятую, точку с запятой или пробел. Уже записанные адреса сохраняют прежнюю причину. Строки, не похожие на email, PostCraft покажет отдельно.

Кнопка «Убрать» возвращает адрес в рассылки. Получатель может сделать то же сам через публичную форму `/unsubscribe`.

## Ящики отправителя

Каждый ящик задаёт адрес и имя в поле «От кого».

| Поле | Значение |
|---|---|
| Способ отправки | Local: `mail()` сервера сайта. SMTP: внешний сервер |
| SMTP host, порт, шифрование | для SMTP. Порт по умолчанию 587, для SSL 465 |
| Логин и пароль SMTP | логин по умолчанию равен email. Пароль в форме не показывается, пустое поле оставляет прежний |
| Проверять SSL-сертификат | снимите галочку, если сертификат сервера выдан на другое имя. Так бывает на общем хостинге |
| Показывать в «От кого» | скрывает ящик из списка, не удаляя его |

Последний ящик удалить нельзя.
