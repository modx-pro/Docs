# Статистика

Таблица показывает все рассылки: тему, статус, план отправки, сколько писем отправлено и ждёт в очереди, сколько человек открыли письмо и кликнули, отписки и blacklist.

## Управление рассылкой

Меню строки рассылки:

| Действие | Когда доступно |
|---|---|
| Изменить | запланирована или на паузе |
| Пауза | запланирована или идёт отправка |
| Продолжить | на паузе |
| Отменить рассылку | до завершения. Отменить отмену нельзя |

Подробнее о правке: [Рассылка](campaign#editing-a-campaign).

## Детали рассылки

Клик по строке открывает детали под таблицей:

- **По каким ссылкам кликали**: адрес ссылки, число кликов, уникальные клики. Ссылки без кликов не показываются.
- **Кто по чему кликал**: адрес получателя, ссылка, число кликов, последний клик.
- **Причины отписки**: тексты из формы с полем `reason`.
- **Blacklist, отписки, bounce**: адреса этой рассылки, которые попали в blacklist или были пропущены.

## Что считается открытием

Открытие фиксирует картинка-пиксель в письме. PostCraft не считает:

- запросы ботов и сканеров ссылок;
- прокси почтовых сервисов, которые загружают картинки заранее;
- открытия в первые секунды после отправки, их делают антивирусы и почтовые сервисы, которые заранее загружают картинки.

Поэтому открытий в PostCraft меньше, чем показывают сервисы без фильтра, зато это люди.

Клики PostCraft считает через редирект. Для этого включите «Отслеживать клики по ссылкам» при постановке рассылки.

## Выгрузка в Excel

«Выгрузить в Excel» в деталях выгружает одну рассылку, «Выгрузить всю статистику в Excel» над таблицей выгружает все. Файл XLSX собирается без сторонних библиотек, нужен только PHP-модуль `zip`.

Файл одной рассылки содержит листы: сводка, получатели со статусом, первым открытием и первым кликом, ссылки с кликами, кто по чему кликал, причины отписки и blacklist. В общей выгрузке листы рассылок, причин отписки, кликов и blacklist.
