# Страница отписки

Ссылка `{{ unsubscribe }}` ведёт получателя на страницу подтверждения. Кнопка «Отписаться» добавляет адрес в blacklist, и следующие рассылки его пропускают.

## Сайт и язык

Сверху вкладки выбираются сайт и язык. У каждой пары свои тексты. Языки берутся из контекстов MODX: `cultureKey` задаёт язык, `site_url` адрес. Язык, чей `site_url` совпадает с корнем сайта, открывается без префикса, остальные с префиксом: `/en/unsubscribe/{токен}`.

Готовые тексты есть для английского, русского, испанского, португальского, французского и арабского. Для арабского страница выводится справа налево.

## Состояния страницы

| Поле | Когда показывается |
|---|---|
| Подтверждение | переход из письма. Здесь должна быть кнопка отписки |
| Публичная форма | `/unsubscribe` без токена: поле email и кнопки «Подписаться» и «Отписаться» |
| После отписки | адрес отписан |
| После подписки | адрес убран из blacklist через публичную форму |
| Ссылка недействительна | токен не найден |

Каждое поле хранит HTML и CSS целиком, без служебной рамки PostCraft.

## Плейсхолдеры

| Плейсхолдер | Значение |
|---|---|
| `{{ unsubscribe }}` | в подтверждении: кнопка отписки. В публичной форме: поле email и кнопки |
| `{{ email }}` | адрес получателя |
| `{{ home }}` | адрес сайта |

Свою кнопку можно сверстать ссылкой: `<a class="btn" href="{{ unsubscribe }}">Отписаться</a>`. PostCraft сохранит класс и разметку.

## Причина отписки

Чтобы спросить причину, поставьте в подтверждение свою форму:

```html
<form action="{{ unsubscribe }}" method="post">
  <textarea name="reason" placeholder="Почему вы отписываетесь?"></textarea>
  <button type="submit">Отписаться</button>
</form>
```

Разметка останется вашей. Текст из `reason` появится в статистике рассылки, в блоке «Причины отписки».

## Отписка в один клик

Каждое письмо получает заголовки `List-Unsubscribe` и `List-Unsubscribe-Post`. По ним Gmail, Яндекс Почта и другие почтовые программы показывают свою кнопку «Отписаться», и она работает без перехода на сайт.
