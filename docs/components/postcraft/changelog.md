# История версий

## 1.0.0-pl1

Первый выпуск.

- MODX Revolution 2.8 и 3.x, PHP 7.2 и выше. Один пакет для обеих версий.
- Шаблоны писем в чанках, редактор HTML или визуальный, превью для телефона и компьютера на вкладках «Шаблоны», «Рассылка» и «Страница отписки».
- Получатели из списка, сохранённых списков и заявок FormIt. Повторы отбрасываются, можно пропустить тех, кто уже получал шаблон.
- Окно отправки: дата и часы в поясе `postcraft_timezone`. Без статистики по адресу — равномерно по окну, со открытиями — в его обычный час.
- Лимиты скорости на ящик и в системных настройках (час / день / пачка), прогрев, раскладка длинного списка на несколько дней, оценка плана на вкладке «Рассылка», автопауза по SMTP-лимиту, серии ошибок и % bounce.
- Пауза, продолжение, отмена и правка запланированной рассылки.
- Прехедер, Reply-To, ящик отправителя на рассылку. PHP mail или SMTP, проверку SSL можно отключить для отдельного ящика.
- Трекинг открытий и кликов с фильтром ботов и предзагрузки.
- Страницы отписки для каждого сайта и языка, форма с причиной, заголовки `List-Unsubscribe`. Языки из Localizator или контекстов MODX, тексты на русском и английском, для остальных языков английский черновик.
- Выгрузка статистики в Excel.
- Blacklist с массовым добавлением, разбор возвратов по IMAP.
- Несколько доменов: ссылки по домену отправителя, edge на MODX и без него, подпись запросов HMAC.
