# PostCraft

PostCraft отправляет email-рассылки прямо из админки MODX. Вы собираете письмо из чанка, берёте получателей из списка, FormIt, пользователей MODX или заказчиков miniShop, выбираете день и часы отправки. Cron разносит письма по этому окну, а статистика показывает открытия, клики, отписки и возвраты.

Сторонние сервисы рассылок не нужны: письма уходят через почту сервера или ваш SMTP. Языки страниц отписки PostCraft берёт из Localizator, а без него из контекстов MODX, как в Babel.

## Возможности

- Шаблон письма хранится в чанке `PostCraft.*`. Редактор HTML или визуальный (CKEditor, TinyMCE RTE), превью для телефона и компьютера на вкладках «Шаблоны», «Рассылка» и «Страница отписки».
- Получатели: список адресов, сохранённые списки, FormIt, активные пользователи MODX и заказчики miniShop2 / MiniShop3. Выбор сохранённого списка сразу заполняет поле «Адреса». Повторы между источниками отбрасываются, адреса из blacklist пропускаются всегда.
- Окно отправки: дата и часы «с» и «до» в часовом поясе сайта. Первая отправка без статистики — равномерно по окну; дальше — по открытиям адреса.
- Лимиты скорости на ящик (час / день / пачка), прогрев, растягивание длинного списка на несколько дней и автопауза при риске бана IP.
- Пауза, продолжение, отмена и правка запланированной рассылки: тема, прехедер, окно, адреса, текст.
- Прехедер, адрес для ответов и ящик отправителя на каждую рассылку. Ящик работает через PHP mail или SMTP.
- «Не отправлять повторно» с окном в днях (по умолчанию 30): пропущенные адреса перечисляются, остальные встают в очередь.
- «Фиксированная рассылка»: после успешной отправки адреса на N дней (по умолчанию 7) во временном blacklist — любой шаблон им не уйдёт, потом запись снимается сама.
- Трекинг открытий и кликов. Боты, прокси почтовых сервисов и мгновенные автозагрузки в статистику не попадают.
- Страница отписки для каждого сайта и языка, своя форма с причиной отписки. Заголовок `List-Unsubscribe` для кнопки «Отписаться» в Gmail и Яндекс Почте.
- Статистика по рассылке и по адресу (поиск и клик по email). Выгрузка в Excel без сторонних библиотек.
- Разбор недоставленных писем по IMAP: hard bounce попадает в blacklist.
- Несколько доменов из одной админки: ссылки в письме ведут на сайт, с домена которого оно отправлено.

## Требования

| | |
|---|---|
| MODX | 2.8 или 3.x |
| PHP | 7.2 и выше, расширения `pdo_mysql`, `mbstring`, `zip` (выгрузка в Excel) |
| Cron | задача раз в минуту |
| Возвраты | расширение `imap`, отдельный ящик |

Пакет один для MODX 2.8 и MODX 3.
