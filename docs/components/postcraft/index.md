# PostCraft

PostCraft отправляет email-рассылки прямо из админки MODX. Вы собираете письмо из чанка, вставляете адреса или берёте их из заявок FormIt, выбираете день и часы отправки. Cron разносит письма по этому окну, а статистика показывает открытия, клики, отписки и возвраты.

Сторонние сервисы рассылок не нужны: письма уходят через почту сервера или ваш SMTP. Babel тоже не нужен, языки страниц отписки PostCraft берёт из контекстов MODX.

## Возможности

- Шаблон письма хранится в чанке `PostCraft.*`. Редактор HTML или визуальный (CKEditor, TinyMCE RTE), превью для телефона, планшета и компьютера.
- Получатели: список адресов, сохранённые списки, уникальные email из заявок FormIt. Повторы отбрасываются, адреса из blacklist пропускаются всегда.
- Окно отправки: дата и часы «с» и «до» в часовом поясе сайта. Внутри окна письмо уходит каждому адресу в то время, когда он обычно открывает почту.
- Пауза, продолжение, отмена и правка запланированной рассылки: тема, прехедер, окно, адреса, текст.
- Прехедер, адрес для ответов и ящик отправителя на каждую рассылку. Ящик работает через PHP mail или SMTP.
- Опция «не отправлять повторно тем, кому этот шаблон уже уходил».
- Трекинг открытий и кликов. Боты, прокси почтовых сервисов и мгновенные автозагрузки в статистику не попадают.
- Страница отписки для каждого сайта и языка, своя форма с причиной отписки. Заголовок `List-Unsubscribe` для кнопки «Отписаться» в Gmail и Яндекс Почте.
- Выгрузка статистики в Excel без сторонних библиотек.
- Разбор недоставленных писем по IMAP: hard bounce попадает в blacklist.
- Несколько доменов из одной админки: ссылки в письме ведут на сайт, с домена которого оно отправлено.

## Требования

| | |
|---|---|
| MODX | 2.8 или 3.x |
| PHP | 7.2 и выше, расширения `pdo_mysql`, `mbstring`, `zip` (выгрузка в Excel) |
| Cron | задача раз в минуту |
| Возвраты | расширение `imap`, отдельный ящик |

Пакет один для MODX 2.8 и MODX 3.
