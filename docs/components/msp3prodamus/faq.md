# FAQ

## error: signature incorrect

Секрет webhook не совпал с секретом страницы, с которой создали ссылку. `demo_mode=1` ключ HMAC не переключает.

Если боевой режим страницы выключен на стороне Prodamus, подпись считают другим ключом (суффикс `demo`). Такой webhook не должен проходить как боевой.

## Оплата прошла, заказ не сменился

Проверьте `order_num` = `external_id` попытки. Переход на `urlSuccess` сам по себе заказ не оплачивает.

Повторную отправку можно нажать в кабинете: **Список платежей → URL-оповещения**.

## urlNotification не принимается

Задайте `msp3prodamus_sys`. Без кода интеграции Prodamus игнорирует URL из запроса.

## 301 на `*.test`

Тело POST пропадает. Нужен HTTPS без редиректа. На webhook не ставьте Basic Auth.
