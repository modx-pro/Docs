# FAQ

## error: signature incorrect

`webhook.php` сверяет подпись с секретом из properties способа, иначе с **`msp3prodamus_secret_key`**. Секрет должен совпадать с секретом страницы, с которой создали ссылку. `demo_mode=1` ключ HMAC не переключает.

Если боевой режим страницы выключен на стороне Prodamus, подпись считают другим ключом (суффикс `demo`). Такой webhook не должен проходить как боевой.

## Оплата прошла, заказ не сменился

Проверьте, что Prodamus вернул в `order_num` тот же идентификатор, что пакет отправил как `order_id` при создании ссылки. Это `external_id` попытки вида `{orderId}-{hex}`. Пустой `order_num` и число кабинета в `order_id` попытку не найдут. Переход на `urlSuccess` сам по себе заказ не оплачивает.

Повторную отправку можно нажать в кабинете: **Список платежей → URL-оповещения**.

## urlNotification не принимается

Задайте `msp3prodamus_sys`. Без кода интеграции Prodamus игнорирует URL из запроса.

## 301 на `*.test`

Тело POST пропадает. Нужен HTTPS без редиректа. На webhook не ставьте Basic Auth.
