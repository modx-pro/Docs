# Админка и модерация

## Открытие

**Extras → msReviews**. Нужен **VueTools ≥ 1.1.2-pl** ([документация VueTools](/components/vuetools/)). Без VueTools вместо интерфейса — подсказка об установке.

Права: [Права доступа](permissions). Настройки — **Система → Настройки**, namespace **`msreviews`**.

<!-- ![Дашборд CMP](/components/msreviews/screenshots/dashboard.png) -->

## Вкладка на карточке товара

С **1.2.5** на **resource/update** любого неудалённого документа (кроме папок) появляется вкладка **«Отзывы»** при праве **`review_view`**. Настройка `msreviews_product_class_key` вкладку не ограничивает.

Сводка только для чтения: средний рейтинг, число опубликованных, pending отзывов и вопросов. Кнопка **«Открыть модерацию»** ведёт в **Extras → msReviews** с `?product_id=`.

<!-- ![Вкладка на ресурсе](/components/msreviews/screenshots/resource-product-tab.png) -->

При `mode=new` вкладка не добавляется.

## Дашборд

С правом **`review_analytics`**:

- счётчики: опубликовано, pending, verified, вопросы pending, очередь писем
- с **1.2.4** плитка и сегмент doughnut **`published_questions`**: клик открывает вопросы со `status=published`
- фильтр по датам и области каталога
- клик по карточке открывает **Отзывы** или **Операции** с фильтром.

## Отзывы

### Фильтры

Товар или любой ресурс, статус, дата, рейтинг от/до, чекбоксы: verified, с фото, с ответом, «рекомендую».

Поиск в фильтре идёт через `mgr/catalog/search` с `type=resource` (любой неудалённый `site_content`). `limit` 1–100, по умолчанию 50. При вводе `q` список подсказок заменяется целиком. Числовой `q` поднимает точный id в начало.

URL с `?product_id=` или `?msr_product_id=` предзаполняет фильтр.

### Массовые действия

При **`review_moderate`**: выбор строк, целевой статус, причина в журнале, подтверждение перед применением.

### Добавление и правка вручную

С **1.1.0** при праве **`review_moderate`**:

- кнопка **«Добавить отзыв»** над таблицей
- **«Редактировать отзыв»** в действиях строки (иконка карандаша).

В диалоге задайте ресурс (любой неудалённый `site_content`, не только `msProduct`). Поля: рейтинг 1–5, заголовок, текст, имя и email автора, статус, чекбокс **Verified purchase**. **Ответ магазина** доступен при праве **`review_reply`**.

Ограничения диалога:

- фото к отзыву здесь не загружают (только вкладка **Медиа** или витрина)
- **`order_id`** не редактируют: у ручных отзывов он остаётся пустым
- при смене **ресурса** при редактировании пересчитываются агрегаты старого и нового `product_id`.

### Таблица

Колонки: id, товар/ресурс, рейтинг, verified, рекомендация, медиа, текст, автор, email, дата, действия, закреп, статус. С **1.2.1** колонки «Ответ магазина» нет: ответ в форме редактирования и в развёртке строки.

- **Превью** (иконка «глаз»): полный текст, structured-поля, журнал модерации, spam signals.
- **Редактировать** (карандаш): тот же диалог, что и «Добавить отзыв», в том числе ответ магазина.
- **Закреп** — только для published. На витрине такие отзывы выводятся первыми.

### Ответ магазина

В диалоге **«Редактировать отзыв»** при праве **`review_reply`**. Пустой текст снимает ответ. Альтернатива: action `mgr/review/set-reply`.

## Вопросы

Право `question_moderate`: фильтры, смена статуса, закреп.

Кнопка «Добавить вопрос» открывает форму: ресурс (любой неудалённый `site_content`), текст, автор, email, статус, флаг уведомления и вкладка ответа. Редактирование: кнопка в строке таблицы. После сохранения ответа статус берётся из поля формы.

С **1.2.4** ответ задаётся только в форме создания или редактирования. Колонка «Ответ» и быстрый диалог из списка убраны. Поиск ресурса в форме доступен при праве `question_moderate` (`mgr/catalog/*`).

API: `mgr/question/create`, `mgr/question/update`, `mgr/question/get`. См. [AJAX API](api).

## Медиа

Право **`review_view`**: список вложений. Удаление при **`review_moderate`**.

Файлы: `assets/components/msreviews/upload/`.

## Операции

- **Очередь приглашений** — статусы писем (`mgr/request_queue/list`), выгрузка CSV (`mgr/export/request_queue`), **Обработать очередь** (`queue_process`).
- **Экспорт** отзывов и вопросов в CSV.
- **Импорт отзывов** из CSV (мастер из трёх шагов, **`review_import`**).
- **Импорт вопросов** из CSV (с **1.2.4**, **`review_import`**): колонки `product_id`, `text`, `status`, `author_email` или `author_name`; опционально `answer_text`, `notify`, `pinned`.
- Подсказка cron: `action=request/process` + **`msreviews_cron_key`**.
