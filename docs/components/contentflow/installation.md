# Установка и обновление

## Установка пакета

1. Откройте в MODX раздел **Пакеты → Установщик**.
2. Загрузите транспортный пакет ContentFlow или выберите его у поставщика
   Modstore.
3. Нажмите **Установить**.
4. После завершения установки очистите кэш MODX.
5. Откройте **Приложения → ContentFlow**.

При установке создаются таблицы компонента, системные настройки, разрешения,
пункт меню и событие `OnContentFlowResourcePublished`.

> [!WARNING]
> Установка не добавляет задание в crontab. Команду cron нужно настроить вручную
> после проверки компонента.

## Обновление

Для обновления установите транспортный пакет с более новой версией поверх
существующей. Удалять предыдущую версию перед обновлением не нужно.

Перед обновлением рекомендуется сделать резервную копию базы данных и файлов
сайта. Это особенно важно, если в новой версии меняется схема таблиц.

После обновления:

1. очистите кэш MODX;
2. откройте ContentFlow и проверьте глобальные настройки;
3. выполните worker один раз вручную;
4. проверьте журнал компонента.

```bash
/usr/bin/php /absolute/path/to/modx/core/components/contentflow/cli/worker.php --once
```

## Переустановка

Не используйте удаление пакета как способ обновления. При полном удалении могут
быть удалены настройки, принадлежащие установленному пакету. Если требуется
чистая переустановка, заранее сохраните:

- глобальные настройки;
- настройки контекстов;
- параметры моделей и агентов;
- пользовательские промпты;
- конфигурацию задач.

Ресурсы MODX и созданные изображения не следует считать резервной копией
конфигурации ContentFlow.

## Проверка установки

После установки должны открываться:

- главная страница ContentFlow;
- список задач;
- раздел администрирования;
- вкладки моделей, агентов, глобальных настроек и контекстов.

Если интерфейс открывается, но таблицы не загружаются, очистите кэш MODX и
проверьте журнал `core/cache/logs/error.log`.
