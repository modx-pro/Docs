# Требования

## Сервер

| Требование | Значение |
|---|---|
| MODX Revolution | 3.0.0 или новее |
| PHP | 8.1 или новее |
| PHP cURL | обязателен для запросов к API |
| База данных | MySQL или MariaDB, таблицы ContentFlow используют InnoDB |
| Доступ к CLI | требуется для worker и автоматических запусков |
| Cron | требуется для работы по расписанию |

PHP CLI, который запускается из cron, должен использовать ту же конфигурацию и
иметь доступ к файлам MODX. На хостингах с несколькими версиями PHP указывайте
полный путь к нужному исполняемому файлу.

## Доступ к API

Для запуска текстового pipeline необходимы:

- настроенная текстовая модель для четырёх текстовых агентов;
- модель Embeddings;
- текстовая модель для пограничной проверки дублей.

Модель изображений требуется только для задач, в которых включено главное или
дополнительное изображение.

В поставку входят модули:

- OpenAI GPT;
- OpenAI Images;
- OpenAI Embeddings;
- Recraft Images.

API-ключи, доступ к моделям и средства на балансе соответствующих сервисов
владелец сайта предоставляет самостоятельно.

Для оплаты зарубежных подписок можно использовать сервис
[«Плати по миру»](https://platipomiru.com/?code=DXD89B17). Это реферальная
ссылка: разработчик ContentFlow может получить вознаграждение за регистрацию или
заказ пользователя.

## Сеть и прокси

Если сервер находится в России, исходящие запросы к OpenAI и Recraft необходимо
направлять через HTTP-прокси. Адрес можно задать один раз в глобальных настройках
ContentFlow, а затем выбрать режим **Глобальный прокси** в каждой модели.

Прокси должен поддерживать HTTPS-запросы через метод `CONNECT` и находиться в
регионе, из которого доступны API выбранных поставщиков. SOCKS-прокси встроенными
модулями не поддерживается.

## Запись файлов

Пользователь, от имени которого работает PHP CLI, должен иметь право:

- читать `core/config/config.inc.php` и `core/vendor/autoload.php`;
- читать файлы компонента;
- создавать каталоги и изображения внутри пути, указанного в настройках
  контекста;
- работать с каталогом кэша MODX.

## Время сервера

Расписание рассчитывается по часовому поясу PHP на сервере. Перед включением
автоматических задач проверьте время в MODX и вывод команды:

```bash
php -r 'echo date_default_timezone_get(), " ", date("c"), PHP_EOL;'
```

ContentFlow не создаёт пропущенные запуски задним числом. Если cron не работал
несколько дней, после восстановления будет обработано только актуальное
расписание.
