# Быстрый старт

Ниже приведена минимальная последовательность настройки для первой ручной
задачи без изображений.

## 1. Настройте модели

Откройте **ContentFlow → Администрирование → Модели**.

1. Настройте **OpenAI GPT** и проверьте соединение.
2. Настройте **OpenAI Embeddings** и проверьте соединение.
3. Включите обе модели.

Если сервер находится в России, сначала заполните глобальный HTTP-прокси и
выберите режим **Глобальный прокси** в настройках каждой модели. Для отдельных
подключений вместо этого можно указать собственный HTTP-прокси.

## 2. Настройте агентов

Откройте вкладку **Агенты** и назначьте текстовую модель агентам:

- Копирайтер;
- Технический редактор;
- Ревьюер.

Контент-менеджер также требует текстовую модель, но в первой ручной задаче он не
участвует. Publisher может остаться без графической модели, пока изображения
отключены.

Сохраните каждого агента. Промпты по умолчанию уже заполнены; для первого запуска
их менять не требуется.

## 3. Настройте проверку дублей

На вкладке **Глобальные настройки** выберите:

- модель OpenAI Embeddings и её версию;
- текстовую модель для LLM-проверки дублей и её версию.

Для первого теста можно оставить пороги и размер пакета индексации по умолчанию.

## 4. Настройте контекст

Откройте **Настройки контекстов** и выберите рабочий контекст.

1. Укажите корневой раздел блога.
2. Проверьте назначение `pagetitle`, `description`, `introtext` и `content`.
3. Укажите поле alias и поле главного изображения.
4. Проверьте базовый путь изображений.
5. Включите контекст и сохраните форму.

## 5. Включите ContentFlow

Вернитесь в **Глобальные настройки**, включите ContentFlow и сохраните форму.

## 6. Создайте ручную задачу

На странице **Задачи** нажмите **Создать задачу**.

Укажите:

- название;
- настроенный контекст;
- тип **Ручная**;
- темы в формате `ID категории | Тема`;
- язык;
- шаблон и автора ресурса;
- режим создания черновика;
- главное изображение — **Нет**;
- дополнительные изображения — `0`.

Пример:

```text
12 | Как настроить резервное копирование сайта
15 | Что проверить, если домен не открывается
```

Сохраните задачу и откройте её карту контента.

## 7. Создайте запуск

В меню **Действия** выберите **Запустить сейчас**, затем выполните worker:

```bash
/usr/bin/php /absolute/path/to/modx/core/components/contentflow/cli/worker.php --once
```

Повторяйте команду, пока очередь не опустеет, либо запустите worker без `--once`:

```bash
/usr/bin/php /absolute/path/to/modx/core/components/contentflow/cli/worker.php
```

Результат проверяйте во вкладках **Карта контента**, **Запуски** и **Журнал**.

## 8. Подключите cron

После успешного ручного теста добавьте команду `cron.php` с запуском каждую
минуту. Подробная настройка приведена на странице [Cron и worker](cron).
