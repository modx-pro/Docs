# Ссылки, офферы и вставки

Эти параметры настраиваются отдельно для каждой задачи. В максимальном режиме
их применяет Технический редактор, в умеренном — Копирайтер получает те же
технические требования, а Технический редактор проверяет их при возврате
Ревьюера.

## Рекламные ссылки

Для каждой ссылки указываются:

- цель в формате `[[~ID]]` либо полный HTTP/HTTPS URL;
- описание назначения ссылки.

Анкор и подходящее место выбирает модель. Внешняя рекламная ссылка должна иметь
`rel="nofollow"`.

Лимит задаёт верхнюю границу на одну статью. Используйте положительное значение,
если ссылки должны передаваться в работу.

## Офферы

Оффер содержит имя чанка и описание. Описание помогает выбрать релевантный
оффер и место в статье.

Готовый тег строится по настройке контекста:

```text
[[$OfferChunk]]
```

или:

```text
{include 'OfferChunk'}
```

Оффер не обязан появляться в каждой статье: модель использует его только при
соответствии теме и в пределах лимита.

## Рекламные вставки

Для рекламной вставки задаётся только имя чанка. Если раздел включён, список не
пуст и установлен положительный лимит, вставки обязательны.

ContentFlow передаёт точный готовый тег. Формы `[[!ChunkName]]`,
`[[!$ChunkName]]` и `[[ChunkName]]` для стандартного MODX-синтаксиса запрещены.

## Внутренняя перелинковка

ContentFlow подбирает до 100 наиболее близких статей и передаёт их агенту. В
кандидаты не попадают категории.

Доступны области:

- **Категории задачи** — категории, выбранные автоматической задачей, либо
  категории тем ручной задачи;
- **Все разделы блога** — вся область из настроек контекста.

Для всей области блога можно исключить категории. Исключение родителя исключает
его поддерево. В режиме категорий задачи отдельный список исключений
перелинковки не применяется, но учитываются исключения самой автоматической
задачи.

По умолчанию используются только опубликованные ресурсы. Настройка
**Учитывать неопубликованные ресурсы** добавляет завершённые черновики
ContentFlow. До публикации такие ссылки могут вести на недоступную посетителю
страницу.

Агент сам решает, нужна ли ссылка по смыслу. Установленный максимум не означает,
что статья обязательно получит это количество ссылок. Ссылки оформляются через
MODX-тег:

```html
<a href="[[~123]]">естественный анкор</a>
```

## Обычные внешние ссылки

Веб-поиск и рекламные ссылки — разные механизмы. ContentFlow не добавляет
найденные в веб-поиске URL в статью автоматически. Разрешение или запрет обычных
редакционных внешних ссылок следует явно указать в инструкции Копирайтеру и
проверять Ревьюером.
