# Модели

Модель хранит подключение к поставщику API. В ней настраиваются ключ, сеть и
тайм-ауты. Конкретную версию и параметры генерации выбирает агент или задача.

## Общий порядок настройки

1. Откройте **ContentFlow → Администрирование → Модели**.
2. Выберите строку модели и откройте её настройки.
3. Сначала включите модель.
4. Заполните обязательные параметры подключения.
5. Выберите режим прокси.
6. Нажмите **Проверить подключение**.
7. Сохраните форму.

Проверка подключения не генерирует статью или изображение. Для OpenAI она
запрашивает список доступных моделей, для Recraft — сведения текущего
пользователя.

## Режимы прокси

- **Без прокси** — прямое подключение;
- **Глобальный прокси** — адрес из глобальных настроек ContentFlow;
- **Собственный HTTP-прокси** — отдельный адрес для текущей модели.

При выборе глобального режима глобальный адрес должен быть заполнен. Поддержка
SOCKS в поставляемых модулях не предусмотрена.

::: warning
На сервере, расположенном в России, подключения к OpenAI и Recraft следует
направлять через HTTP-прокси. После сохранения обязательно проверьте соединение
отдельно для каждой включённой модели.
:::

## OpenAI GPT

Текстовая модель для Контент-менеджера, Копирайтера, Технического редактора,
Ревьюера и LLM-проверки дублей.

Параметры подключения:

- API key;
- Organization ID — необязательно;
- Project ID — необязательно;
- тайм-аут подключения;
- тайм-аут запроса;
- режим прокси.

После проверки ContentFlow показывает доступные версии с идентификаторами,
начинающимися с `gpt-`. Пользовательский идентификатор также можно указать
вручную.

### Веб-поиск

Веб-поиск относится не к подключению модели, а к профилю конкретного агента:

- **Выключен** — инструмент не передаётся модели;
- **По необходимости** — модель сама решает, нужен ли поиск;
- **Обязателен** — каждый запрос должен использовать веб-поиск.

Максимум вызовов задаётся отдельно для профиля. В один лимит входят поиск,
открытие страницы и поиск текста внутри страницы. Поэтому четыре вызова — это
не обязательно четыре поисковых запроса.

В журнале отображаются:

- `web_search_calls` — завершённые вызовы;
- `web_search_attempts` — все попытки;
- `web_search_sources` — количество уникальных источников в ответе поставщика;
- `web_search_limit` — действующий лимит.

## OpenAI Embeddings

Используется для смыслового поиска кандидатов на дубли. Подключение совпадает с
OpenAI GPT, но в список версий попадают модели `text-embedding-*`.

ContentFlow запрашивает у моделей семейства `text-embedding-3` векторы размером
512 измерений. Вектор хранится в базе как восстанавливаемый бинарный кэш.

Старую Embeddings-модель без поддержки параметра `dimensions` использовать для
этого индекса нельзя.

## OpenAI Images

Графическая модель для Publisher. Поддерживаются идентификаторы `gpt-image-*` и
`dall-e-*`.

Набор параметров зависит от версии:

- DALL-E 2: размер;
- DALL-E 3: размер, качество и стиль;
- GPT Image: размер и качество;
- GPT Image 2: в том числе размеры 16:9, например `1536x864`, `2048x1152`,
  `2560x1440` и `3840x2160`.

Чем выше размер и качество, тем больше время обработки и стоимость генерации.

## Recraft Images

Для подключения указывается API token, тайм-ауты и режим прокси.

Доступны варианты Recraft V2, V3, V4 и V4.1, включая совместимые raster,
vector, pro и utility-версии.

Параметры генерации зависят от выбранной версии:

- соотношение сторон;
- именованный стиль для V2 и V3;
- предпочтительные HEX-цвета;
- цвет фона;
- негативный промпт для V2 и V3;
- запрет текста для V3.

Соотношение сторон по умолчанию — `16:9`. Цвета указываются в HEX-формате.

## Хранение ключей

Ключи сохраняются в конфигурации модели и не попадают в операционный журнал.
Доступ к настройкам моделей следует выдавать только доверенным пользователям
MODX.
