# Карта контента

Карта контента объединяет темы и связанные с ними статьи. Отдельная таблица
статей в интерфейсе не требуется: до выполнения тема показывается без материала,
после выполнения — со статьёй и ресурсом MODX.

## Добавление тем

Темы можно добавлять в ручную и автоматическую задачу. Используется формат:

```text
12 | Как выбрать виртуальный сервер
25 | Настройка резервного копирования
```

Точная копия существующей темы в том же контексте будет пропущена. После
добавления тема проходит обычную смысловую проверку.

## Принятие

Состояния принятия:

- **Ожидает** — пользователь ещё не принял решение;
- **Принята** — тема может попасть в запуск после успешного dedup;
- **Отклонена** — тема не пишется, но сохраняется как отрицательная память для
  Content Manager и проверки дублей.

Отклонённую тему можно удалить окончательно, если она не защищена активной
обработкой или созданным ресурсом. После удаления она перестаёт участвовать в
dedup.

## Состояния dedup

- **Не проверена**;
- **Уникальна**;
- **Есть совпадение**;
- **Ожидает проверки**;
- **Требует уточнения**;
- **Оставлена вручную**.

Для совпадения можно открыть список кандидатов, увидеть процент, источник и
причину решения. Если LLM предложил более узкую тему, пользователь может
применить её; новая формулировка будет проверена заново.

Принудительное разрешение не удаляет диагностику совпадения, но позволяет теме
продолжить обработку.

## Состояния обработки

- **В очереди** — тема доступна для запуска;
- **Требует решения** — необходимо принять решение по dedup или теме;
- **В работе**;
- **Ожидает Publisher**;
- **Завершена**;
- **Завершена с ошибками**;
- **Ошибка**.

Ошибка до создания ресурса позволяет заново обработать тему в следующем
запуске. Если ресурс уже создан, текстовый pipeline автоматически не начинается
сначала.

## Повтор Publisher

Если текст и ресурс готовы, но произошла ошибка изображений или финализации,
доступно действие **Повторить Publisher**. Оно:

- использует исходный snapshot статьи;
- не создаёт новый запуск задачи;
- не вызывает Копирайтера, Технического редактора и Ревьюера повторно;
- сохраняет уже созданные изображения и продолжает незавершённую работу.

Если результат устраивает без исправления Publisher, статью можно отметить
завершённой вручную.

## Состояние ресурса MODX

Под ID ресурса показывается актуальное состояние:

- опубликован;
- не опубликован;
- удалён;
- ресурс не создан.

Если ресурс удалён в MODX, тему можно явно вернуть в очередь для полного
повторного создания. Пока пользователь не выполнит это действие, ContentFlow не
начинает статью заново автоматически.

## Массовые действия

Список действий зависит от выбранных строк. Например:

- ожидающие темы можно принять или отклонить;
- неиспользуемые темы можно удалить;
- статьи с ошибкой Publisher можно поставить на повтор;
- подходящие результаты можно отметить завершёнными.

Недоступное для всего выделения действие не показывается либо пропускает
защищённые строки с итоговым счётчиком.
