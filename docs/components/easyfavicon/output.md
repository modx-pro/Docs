# Вывод на сайте

## Автовставка

Плагин **EasyFavicon** на событии `OnWebPagePrerender` вставляет разметку активного профиля перед `</head>` на каждой странице сайта. Добавлять что-то в шаблоны не нужно.

Какой профиль выводить, задаёт настройка `easyfavicon.auto_inject_profile` (имя или id); пустая — активный. Выключается автовставка настройкой `easyfavicon.auto_inject`.

## Сниппет EasyFavicon

Если место вывода нужно выбрать самому, выключите `easyfavicon.auto_inject` и вызовите сниппет в `<head>` шаблона:

::: code-group

```modx
[[EasyFavicon]]
```

```fenom
{'EasyFavicon' | snippet}
```

:::

| Параметр | По умолчанию | Описание |
| --- | --- | --- |
| `profile` | активный | Имя или id профиля |
| `tpl` | `tpl.EasyFavicon` | Чанк-обёртка с плейсхолдером `[[+html]]` |

Сниппет подставляет в разметку `base_url`, поэтому пути к файлам верны и на сайте в подкаталоге.

::: warning
Не оставляйте включёнными и автовставку, и сниппет: разметка попадёт на страницу дважды.
:::
