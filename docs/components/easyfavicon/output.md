# Вывод на сайте

## Автовставка

Плагин **EasyFavicon** на событии `OnWebPagePrerender` вставляет разметку активного профиля контекста страницы перед `</head>` на каждой странице сайта. Добавлять что-то в шаблоны не нужно.

Какой профиль выводить, задаёт настройка `easyfavicon.auto_inject_profile` (имя или id); пустая — активный профиль контекста. Выключается автовставка настройкой `easyfavicon.auto_inject`.

Если в ответе нет `</head>`, плагин ничего не вставляет и пишет предупреждение в журнал ошибок — для таких страниц выведите разметку сниппетом.

## Сниппет EasyFavicon

Если место вывода нужно выбрать самому, выключите `easyfavicon.auto_inject` и вызовите сниппет в `<head>` шаблона:

::: code-group

```modx
[[EasyFavicon]]
```

```fenom
{'EasyFavicon' | snippet}
```

:::

| Параметр | По умолчанию | Описание |
| --- | --- | --- |
| `profile` | активный профиль контекста | Имя или id профиля |
| `tpl` | `tpl.EasyFavicon` | Чанк-обёртка с плейсхолдером `[[+html]]` |

Например, вывести конкретный профиль:

::: code-group

```modx
[[EasyFavicon? &profile=`Новогодняя`]]
```

```fenom
{'EasyFavicon' | snippet : ['profile' => 'Новогодняя']}
```

:::

И плагин, и сниппет подставляют в пути `base_url` и метку сборки `?v=…`, поэтому ссылки верны и на сайте в подкаталоге, а после смены профиля браузер не держит старую иконку из кеша.

::: tip
Если сниппет уже вывел ту же разметку, плагин её не повторит. Но если сниппет и `easyfavicon.auto_inject_profile` указывают на разные профили, на странице окажутся оба набора — поэтому при ручном выводе автовставку лучше выключить.
:::
