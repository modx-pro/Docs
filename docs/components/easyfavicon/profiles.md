# Профили

Профиль — это картинка, каталог для файлов и результат последней сборки: набор файлов и разметка.

## Список

В строке профиля видна сама фавиконка из последней сборки, у несобранного — исходная картинка. Переключатель в столбце «Активный» включает и выключает профиль, справа — кнопки «Собрать фавиконку», «Просмотр» (только у собранных), «Изменить» и «Удалить». Столбец «Контексты» появляется, когда контекстов на сайте больше одного.

Поиск над таблицей ищет по названию, описанию и пути к картинке. Escape очищает его.

Щелчок по заголовку «Профиль», «Исходник», «Каталог» или «Обновлён» сортирует список по этому столбцу, повторный — в обратную сторону. По дате сначала идут свежие сборки. Сортирует сервер, поэтому порядок общий для всех страниц списка.

Правый клик по строке открывает меню с теми же действиями, как контекстное меню таблиц MODX.

![Меню строки по правому клику](/components/easyfavicon/screenshots/context-menu.png)

## Активный профиль

Активный профиль — один на контекст. Его разметку плагин вставляет на страницы, а его файлы лежат в каталоге сайта. Чтобы сменить активный профиль, включите переключатель в строке другого: прежний профиль тех же контекстов выключится сам. Выключенный переключатель убирает фавиконку из контекстов профиля. Про профили для разных контекстов — [Контексты](/components/easyfavicon/contexts).

![Столбец «Активный» в списке профилей](/components/easyfavicon/screenshots/active.png)

EasyFavicon хранит архив каждой сборки в `core/packages/easyfavicon/`. При переключении профиль выкладывает свои файлы заново, поэтому можно держать, например, основную и новогоднюю фавиконку и менять их одним кликом. Ссылки в разметке получают метку сборки `?v=…`, так что браузер не покажет старую иконку из кеша.

::: tip
Если архив профиля сохранить не удалось (каталог недоступен для записи), переключение поменяет только разметку, а файлы на сайте останутся от последней сборки. EasyFavicon предупредит об этом — соберите профиль заново.
:::

Два профиля с одним каталогом делят его файлы. Сборка неактивного профиля в тот же каталог сохраняет архив, но на сайт набор не выкладывает, пока профиль не станет активным.

## Результат

Кнопка «Просмотр» показывает результат сборки:

- превью фавиконки в браузерах и на мобильных;
- разметку, которую вставляет плагин;
- список файлов набора;
- версию сборщика RealFaviconGenerator.

![Результат сборки: превью, разметка и файлы](/components/easyfavicon/screenshots/dialog-result.png)

Превью хранится на стороне сервиса, и через несколько часов после сборки картинка может пропасть — на сам набор это не влияет.

Разметку можно скопировать кнопкой «Скопировать», но нужно это, только если автовставка выключена.

## Изменение и удаление

«Изменить» открывает название, каталог файлов, описание, исходное изображение, контексты (если их на сайте больше одного) и галочку «Активный профиль». После смены картинки или каталога соберите профиль заново.

![Окно изменения профиля](/components/easyfavicon/screenshots/dialog-edit.png)

«Удалить» спрашивает подтверждение. Вместе с профилем удаляются его сохранённый архив и миниатюра, а файлы в каталоге сайта остаются на месте — они могут быть уже подключены.

## Манифест

RealFaviconGenerator кладёт в набор `site.webmanifest` с заглушками вместо имени приложения и без `start_url`. После распаковки EasyFavicon дописывает манифест данными сайта:

| Поле | Откуда |
| --- | --- |
| `name` | `easyfavicon.manifest_name`, иначе `site_name` |
| `short_name` | `easyfavicon.manifest_short_name`, иначе `site_name` |
| `start_url`, `id` | `base_url` |
| `lang` | `cultureKey` |

Заполняются только пустые поля и заглушки сервиса: имя, вписанное в редакторе RealFaviconGenerator, остаётся как есть. Манифест дописывается при каждой выкладке — и после сборки, и при переключении профиля.
