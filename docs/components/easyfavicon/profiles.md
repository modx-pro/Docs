# Профили

Профиль — это картинка, каталог для файлов и результат последней сборки: набор файлов и разметка.

## Активный профиль

Активный профиль один. Его разметку плагин вставляет на страницы, а его файлы лежат в каталоге сайта. Чтобы сменить активный профиль, включите переключатель у другого в столбце «Активный».

EasyFavicon хранит архив каждой сборки в `core/packages/easyfavicon/`. При переключении профиль выкладывает свои файлы заново, поэтому можно держать, например, обычную и праздничную фавиконку и менять их одним кликом.

::: tip
Если архив профиля сохранить не удалось (каталог недоступен для записи), переключение поменяет только разметку, а файлы на сайте останутся от последней сборки. EasyFavicon предупредит об этом — соберите профиль заново.
:::

Два профиля с одним каталогом делят его файлы. Сборка неактивного профиля в тот же каталог сохраняет архив, но на сайт набор не выкладывает, пока профиль не станет активным.

## Результат

Кнопка «Просмотр» показывает результат сборки:

- превью фавиконки в браузерах и на мобильных;
- разметку, которую вставляет плагин;
- список файлов набора;
- версию генератора RealFaviconGenerator.

Разметку можно скопировать, но нужно это, только если автовставка выключена.

## Изменение и удаление

«Изменить» открывает название, каталог, описание и картинку профиля. После смены картинки или каталога соберите профиль заново.

Удаление профиля не трогает файлы на диске.

## Манифест

RealFaviconGenerator кладёт в набор `site.webmanifest` с заглушками вместо имени приложения и без `start_url`. После распаковки EasyFavicon дописывает манифест данными сайта:

| Поле | Откуда |
| --- | --- |
| `name` | `easyfavicon.manifest_name`, иначе `site_name` |
| `short_name` | `easyfavicon.manifest_short_name`, иначе `site_name` |
| `start_url`, `id` | `base_url` |
| `lang` | `cultureKey` |

Заполняются только пустые поля и заглушки сервиса: имя, вписанное в редакторе RealFaviconGenerator, остаётся как есть. Манифест дописывается при каждой выкладке — и после сборки, и при переключении профиля.
