# Экспорт

Вкладка «Экспорт» выгружает товары, категории, производителей или опции в CSV, XLSX, JSON или XML. Файл с товарами можно поправить в Excel и загрузить обратно через [синхронизацию](sync).

На странице категории в менеджере есть кнопка «Экспорт». Она открывает вкладку с уже выбранной категорией.

## Что выгружать

| Тип | Что попадает в файл |
|---|---|
| Товары | Поля товара и ресурса, опции, TV, переводы. Набор полей выбирается. |
| Категории | `id`, `parent`, `path`, `pagetitle`, `longtitle`, `alias`, `url`, `published`, `menuindex`, `context`. |
| Производители | Все колонки таблицы производителей и `products`: число товаров. |
| Опции | `id`, `key`, `caption`, `type`, `categories`, `products`, `values`. |

## Категории

Отметьте категории, из которых нужны товары. Если ничего не отметить, выгрузится весь каталог.

- **С подкатегориями.** Товары вложенных категорий тоже попадут в файл.
- **Включая неопубликованные.** Без флажка выгружаются только опубликованные товары.
- **Модификации отдельными строками.** Каждая модификация msOptionsPrice2 или ms3Variants идёт своей строкой под товаром.

## Поля товаров

Готовые наборы:

| Набор | Поля |
|---|---|
| Основные | `id`, `pagetitle`, `article`, `price`, `old_price`, `vendor`, `category_path`, `published` |
| Цены | `id`, `article`, `pagetitle`, `price`, `old_price` |
| SEO | `id`, `pagetitle`, `longtitle`, `description`, `alias`, `url` |
| Все поля | Всё, что msCatalyst нашёл у товаров каталога |

Набор можно дополнить или сократить вручную. Служебные поля: ID, ID категории, ссылка на товар, главное изображение, все изображения ссылками.

## Формат

- **CSV.** Разделитель: точка с запятой, запятая или табуляция. Кодировка: UTF-8 или Windows-1251. Для Excel на русской Windows выбирайте точку с запятой и Windows-1251.
- **XLSX.** Открывается в Excel и Google Таблицах без настройки кодировки.
- **JSON** и **XML.** Для обмена с другими системами.

Заголовки колонок: названия полей («Цена») или ключи полей (`price`). Ключи удобнее, если файл потом загружается обратно: синхронизация сопоставит колонки сама.

## Загрузка обратно

1. Выгрузите товары с колонкой ID.
2. Поправьте цены, остатки или описания в Excel. Не удаляйте колонку ID: по ней строки связываются с товарами.
3. Создайте профиль синхронизации с источником CSV или XLSX и загрузите файл.
4. Ключом в источнике выберите колонку ID, полем сайта для ключа укажите «ID на сайте». Проверьте план изменений и запустите запись.

Если в файле есть пути категорий от корня каталога, укажите в профиле тот же корневой каталог. Иначе синхронизация создаст категории заново внутри другого раздела.

## Как идёт выгрузка

Большой каталог выгружается частями по 500 строк, страница показывает прогресс. Каждая часть идёт отдельным запросом, поэтому выгрузка не упирается в `max_execution_time`. Готовый файл скачивается по ссылке. Временные файлы задания удаляются через сутки.

::: tip Демо
В [публичной демо-админке](https://chelnysite.ru/admin-demo) выгружается не больше 200 строк, вкладка предупреждает об этом до и после выгрузки. В купленном msCatalyst лимитов нет: в файл попадает весь выбранный каталог.
:::
