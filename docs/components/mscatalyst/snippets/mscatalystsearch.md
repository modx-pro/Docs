# msCatalystSearch

Поле поиска для шапки сайта: выпадающие подсказки, переход на страницу результатов или оба режима сразу. Работает на том же индексе, что и фильтр.

```modx
[[!msCatalystSearch?
  &searchMode=`live+page`
  &searchPage=`10`
  &parents=`5`
  &searchFields=`pagetitle^3, ms:article^5`
]]
```

## Режимы

| Режим | Что происходит |
|---|---|
| `filter` | Ввод сужает выдачу каталога. Режим по умолчанию для сниппета `msCatalyst`. |
| `page` | Отправка формы ведёт на страницу `&searchPage`. |
| `live` | Подсказки появляются под полем без перезагрузки страницы. |
| `live+page` | Подсказки и переход на страницу результатов по Enter. Режим по умолчанию для `msCatalystSearch`. |

На странице результатов вызовите `msCatalyst` с теми же `&parents`: он прочитает запрос из адреса и покажет найденные товары вместе с фильтрами.

## Параметры

| Параметр | По умолчанию | Описание |
|---|---|---|
| `parents` | | ID разделов каталога, по которым идёт поиск. |
| `depth` | `10` | Глубина поиска товаров внутри разделов. |
| `searchMode` | `live+page` | Режим, см. выше. |
| `searchPage` | | ID или адрес страницы результатов. |
| `searchFields` | `pagetitle^3, longtitle, ms:article^5, introtext, description, content` | Поля поиска с весами. |
| `searchParam` | `search` | Параметр адреса для запроса. |
| `searchMin` | `2` | Минимальная длина запроса. |
| `suggestLimit` | `8` | Число подсказок. |
| `tplSuggest` | `msCatalyst.suggest` | Чанк одной подсказки. |
| `toPlaceholder` | | Записать вывод в плейсхолдер. |

## Как работает поиск

- Словоформы: «кроссовки» находит «кроссовок» и «кроссовками». phpMorphy подключается, если стоит на сервере. Без него работает встроенный стеммер.
- Транслит: `krossovki` находит кроссовки. Для брендов, которые пишут по-русски на слух, заведите синоним, например `найк → nike`.
- Опечатки: `кросовки адидас` находит кроссовки Adidas. Слова с цифрами (артикулы, размеры) msCatalyst сравнивает точно или без пробелов.
- Веса полей: совпадение в артикуле или названии поднимает товар выше совпадения в описании.

## Синонимы

Синонимы ведутся на странице «Пакеты → msCatalyst», вкладка «Синонимы». Правило работает в одну сторону: `найк → nike` находит Nike по запросу `найк`, но не наоборот. Синонимы хранятся в системной настройке `mscatalyst_search_synonyms` в виде JSON:

```json
{"шланг": "рукав, hose"}
```
