# Посадочные страницы

Посадочная страница отвечает на запрос вида «красные дрели Bosch»: у неё свой адрес, title, H1, description и текст над и под товарами. msCatalyst хранит посадочные в своих таблицах, SeoFilter для этого не нужен. Посадочные работают на MODX 2 и MODX 3 при `mscatalyst_seo_mode` = `native`, как включить этот режим, описано в разделе [SEO](seo#svoi-chpu-adresa).

Демо: [`chelnysite.ru/belye-krossovki/`](https://chelnysite.ru/belye-krossovki/), английская версия [`chelnysite.ru/en/white-sneakers/`](https://chelnysite.ru/en/white-sneakers/).

## Вкладка «Посадочные»

Выберите каталог и язык. Каталог появится в списке, когда страницу с вызовом msCatalyst хотя бы раз откроют на сайте: так админка берёт те же фасеты, что и сама страница.

- **Страницы.** Выберите фасет или пару фасетов, например «Производитель + Цвет». В таблице видно все сочетания с товарами, их адрес, индексацию и откуда взяты тексты. «Настроить» (у сохранённой «Изменить») открывает редактор: свой адрес, правило индексации, название в блоке ссылок, title, H1, description, HTML над и под товарами. Справа превью сниппета в поиске и блок ссылок этой страницы, они меняются по мере набора.
- **Шаблоны.** Тексты для всех страниц с одним сочетанием фасетов, например для всех «Цвет + Производитель». Шаблон действует в одном каталоге или во всех, на одном языке или на всех. Из подходящих шаблонов выигрывает тот, у которого больше приоритет.
- **Склонения.** Формы значений для подстановок: «красные», «красного», «красных». Серым показана форма по правилам русского языка. Впишите свою, если правило ошиблось.
- **Проверка.** Находит посадочные без товаров, адреса, которые совпадают со страницами сайта или с фильтром, и страницы в индексе без текста.

Кнопки «Экспорт CSV» и «Импорт CSV» выгружают и загружают посадочные каталога. Разделитель `;`, кодировка UTF-8, колонки `key`, `filters`, `url`, `index_mode`, `active` и поля текстов. Колонка `filters` нужна человеку, при загрузке строку находит `key`.

## Откуда берётся текст

Для каждого поля msCatalyst берёт первое заполненное:

1. поле самой посадочной;
2. шаблон этого каталога для того же набора фасетов;
3. шаблон всех каталогов для того же набора;
4. шаблон «любое сочетание»;
5. настройки `mscatalyst_seo_title_filtered`, `mscatalyst_seo_h1_filtered`, `mscatalyst_seo_description`.

## Подстановки

```
{color:plural:lower} {vendor} в Москве{?size}, размер {size}{/size}: {total} шт.
```

- `{pagetitle}`, `{total}`, `{page}`, `{filters}`, `{query}`;
- `{color}`: выбранные значения фасета, `{color.title}`: название фасета;
- падежи через `:`, единственное число: `gen` (красного), `dat` (красному), `acc` (красный), `ins` (красным), `pre` (красном), `about` (о чём);
- множественное число: `plural` (красные), `plural_gen` (красных), `plural_dat`, `plural_acc`, `plural_ins`, `plural_pre`, `plural_about`;
- места: `where` (в Москве), `to` (в Москву), `from` (из Москвы). Их правила не угадывают, впишите формы на вкладке «Склонения»;
- регистр: `lower`, `upper`, `ucfirst`, `title`, например `{color:plural:lower}`;
- `{?size}…{/size}` выводит кусок, если фасет выбран, `{!size}…{/size}`, если нет.

Если язык русский, msCatalyst склоняет по правилам прилагательные и слова во множественном числе. У значения во множественном числе («Экскаваторы», «Буровые установки») падеж даёт форму множественного: `{parent:gen}` выведет «экскаваторов», `{parent:pre}` выведет «экскаваторах». Родительный падеж множественного правила угадывают по окончанию, проверьте его на вкладке «Склонения». Названия производителей по правилам существительных не склоняются: нужные формы марки впишите на вкладке «Склонения». Для других языков берутся формы с вкладки «Склонения».

Форма, вписанная вручную, важнее правила. Форма «Именительный», если её заполнить, заменяет само значение: `{vendor}` выведет её вместо записи в базе. Если формы `about` нет, берётся `pre`, если нет `plural_acc`, берётся `plural`. Старая запись `{{pagetitle}}` в настройках тоже работает.

## Адреса и индексация

- Свой адрес задаётся без раздела: `belye-krossovki` или `obuv/belye`. Страница откроется по `/catalog/belye-krossovki/`.
- Старый ЧПУ-адрес и GET-фильтры отвечают 301 на свой адрес. Ссылки фильтра, крестики, пагинация и карта сайта тоже ведут на него.
- Адрес посадочной в другом регистре или без косой черты в конце отвечает 301 на правильный.
- Если посетитель выбирает ещё один фильтр на посадочной, он уходит на обычный ЧПУ-адрес.
- Индексация: «Авто» следует `mscatalyst_seo_index_max`, «Всегда в индексе» открывает страницу с любым числом значений, «Всегда noindex» закрывает её.
- Что отдаёт страница без товаров, решает настройка `mscatalyst_seo_empty`: `noindex`, `404` или обычная страница.

## Тексты на странице

```modx
<div data-msc-intro>[[!+mscatalyst.intro]]</div>
[[!msCatalyst? ...]]
<div data-msc-text>[[!+mscatalyst.text]]</div>
```

После AJAX-перехода скрипт меняет содержимое блоков с `data-msc-intro` и `data-msc-text` и прячет пустые. Title, H1 и description приходят в те же плейсхолдеры, что и без посадочных, см. [Плейсхолдеры страницы](frontend#pleysholdery-stranicy).

## Блок ссылок

```modx
[[!msCatalystLandings? &mode=`related` &facets=`vendor, color` &limit=`12` &title=`Популярное`]]
```

Ставьте вызов после msCatalyst: сниппет берёт его индекс и выбранные фильтры. Параметры описаны в разделе [msCatalystLandings](snippets/service#mscatalystlandings). С параметром `&catalog` блок можно поставить на любую страницу сайта, например в меню или на главную.

Ссылки ведут на свой адрес посадочной, если он задан. Ссылки без товаров не выводятся.

## Карта сайта

```modx
[[!msCatalystSitemap? &catalogs=`*`]]
```

В карту попадают посадочные со своим адресом или с правилом «Всегда в индексе», в которых есть товары, и ЧПУ-адреса одиночных значений. Параметры описаны в разделе [msCatalystSitemap](snippets/service#mscatalystsitemap).

## Если SeoFilter уже настроен

Правила, адреса и словарь SeoFilter msCatalyst переносит к себе, см. [Переход с SeoFilter](seofilter).
