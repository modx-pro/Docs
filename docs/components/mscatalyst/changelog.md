# История версий

До версии 1.2.0 компонент назывался msFacets.

## 1.3.0-pl1

- Многоязычные каталоги. Язык берётся из `&lang`, адреса Localizator или культуры контекста (Babel). Он входит в ключ кэша индекса и передаётся в AJAX-запросы.
- Localizator: переведённые заголовки, тексты, названия категорий и локализованные TV в фильтрах, поиске и карточках. `` &langStrict=`0` `` показывает товары без перевода с исходными полями.
- Вкладка «Переводы»: названия фильтров и значения по языкам, поиск, фильтр «только без перевода», выгрузка и загрузка CSV. Переводы хранятся обычными записями лексикона.
- Словарь значений: один перевод значения для всех фильтров или для одной группы через `mscatalyst_value_<ключ>_<значение>`.
- Заголовки фильтров подхватывают ключи лексикона mFilter2. Заголовок с вкладки «Переводы» важнее `|title=` в вызове.
- Английские записи лексикона больше не попадают в другие языки.
- Доступные варианты поднимаются наверх группы после каждого выбора. `&hideUnavailable` (по умолчанию включён) скрывает варианты и группы без товаров.
- Вкладка «Экспорт»: товары, категории, производители и опции в CSV, XLSX, JSON или XML в формате, который читает синхронизация. Кнопка «Экспорт» на странице категории.
- Синхронизация и экспорт переводов Localizator. Недостающие переводы создаются, откат их возвращает.
- MODX 3: поддержка localizator3.
- Babel: синхронизация обновляет текстовые поля связанных ресурсов в других контекстах.
- Страница компонента скрывает настройки компонентов, которые не установлены.
- Параметры `&scrollOnUpdate` и `&scrollOffset`: отключить прокрутку к выдаче после «Показать результаты» и перехода по страницам или задать отступ под липкую шапку. Отступ по умолчанию 16px вместо 100px.
- ЧПУ фильтров (`mscatalyst_seo_mode` = `native`) работают на всём пути посетителя: адресная строка, пагинация, крестики, «Сбросить всё», «Назад» и «Вперёд» показывают `/catalog/vendor-nike/color-red/`. GET-фильтры и значения в другом порядке получают 301 на один адрес. Работает каталог на главной и языковые префиксы Localizator.
- Неизвестные пути фильтров отдают 404 вместо каталога или чужой страницы под дублирующим адресом.
- ЧПУ-страницы с числом выбранных значений до `mscatalyst_seo_index_max` (по умолчанию 2) остаются в индексе. Диапазоны, поиск, сортировка и больше значений получают `noindex`.
- Canonical больше не указывает на ЧПУ-путь, когда ЧПУ выключены.

## 1.2.0-pl1

- Новое название msCatalyst. Установка поверх msFacets переносит настройки, синонимы и наборы фильтров. Старые вызовы, плейсхолдеры, CSS-классы и JS-события работают до версии 2.0.
- Синхронизация каталога по профилям: CSV, XLSX, JSON и XML API, Google Таблицы в обе стороны, 1С CommerceML 2 с заказами и статусами, фиды выгрузки.
- Мастер настройки: анализ источника, поиск ключа и модификаций, сопоставление полей с уверенностью и правилами, сопоставление категорий, производителей, опций и значений.
- Версии утверждённой схемы. Запуск по расписанию останавливается при смене структуры источника.
- Пробный прогон с планом изменений и предохранители от массового снятия, скачков цен и обрезанного источника.
- Запись товаров miniShop2 и MiniShop3, модификаций msOptionsPrice2 и ms3Variants, создание категорий, производителей и опций, загрузка картинок.
- Правило для пропавших товаров. Откат любого запуска. История изменений товара.
- Письма на адреса профиля, когда запуск остановился или закончился с ошибками.
- Сниппет `msCatalystSync` для cron.
- Публичная демо-админка `msCatalystDemoAdmin`.
- Картинки: относительные пути, проверка по сигнатуре, без дублей в галерее, повтор неудачных загрузок.
- Пустые ячейки по умолчанию не стирают значения на сайте.
- Исправлено: превью в живом поиске на MiniShop3, порядок картинок галереи на MiniShop3, TV в роли ключа создавал дубли при первом импорте.

## 1.1.1-pl1

- Поле «Найти в списке» у длинных групп оформлено как остальные поля.
- В адресах CSS и JS стоит версия пакета, браузер перезагружает их после обновления.

## 1.1.0-pl1

- Новый индекс для больших каталогов. На 100 000 товаров запрос фильтра занимает 25–40 мс, индекс весит 4,7 МБ.
- Живой поиск на 100 000 товаров отвечает за 60–80 мс.
- Индекс строится частями по 2000 товаров, пик памяти на 100 000 товаров меньше 100 МБ.
- Допуск опечаток не трогает слова с цифрами: артикулы и размеры ищутся точно.
- В ответах AJAX есть статистика и заголовок `Server-Timing`.

## 1.0.0-pl1

- История браузера: каждый переход по фильтрам, страницам и сортировке, «Назад» через AJAX.
- Поиск со словоформами, транслитом, опечатками, весами полей и синонимами.
- Чанк карточки, вид сеткой и списком.
- Режимы поиска `filter`, `page`, `live`, `live+page`, сниппет поиска с подсказками.
- Режимы индекса `memory`, `table`, `auto`.
- SEO: ЧПУ фильтров, шаблоны мета-тегов, карта сайта, мост к SeoFilter.
- Модификации msOptionsPrice2 и ms3Variants.
- REST-коннектор, наборы фильтров, сниппет сброса индекса.
- Страница компонента в админке.
