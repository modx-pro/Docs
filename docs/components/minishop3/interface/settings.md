# Настройки магазина

Откройте **Extras → MiniShop3 → Настройки**.

## Вкладки настроек

| Вкладка | Описание |
| --- | --- |
| [Способы доставки](settings/deliveries) | Настройка методов доставки, стоимости, валидации |
| [Способы оплаты](settings/payments) | Настройка платёжных систем |
| Статусы | Статусы заказов (`#tab-statuses`) |
| [Производители](settings/vendors) | Справочник производителей товаров |
| [Связи товаров](settings/links) | Типы связей между товарами |
| [Опции](settings/options) | EAV-система дополнительных характеристик |

## Интерфейс

Вкладки на Vue 3 и PrimeVue. Страница не перезагружается при правке. Порядок меняете перетаскиванием. Можно выбрать несколько записей для удаления. Поиск идёт по названию и описанию.

## Общие возможности

### Создание записей

Нажмите **Добавить**. Откроется форма с полями выбранного типа записи.

### Редактирование

Дважды кликните по записи в таблице или выберите её и нажмите **Редактировать**.

### Сортировка

Перетащите запись в нужную позицию. Новые позиции сохраняются сами.

### Удаление

Выберите одну или несколько записей и нажмите **Удалить**. Система запросит подтверждение.

::: warning Важно
Удаление способа доставки или оплаты может повлиять на существующие заказы. Рекомендуется деактивировать неиспользуемые методы вместо удаления.
:::
