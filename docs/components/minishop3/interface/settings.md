# Настройки магазина

Откройте **Пакеты → MiniShop3 → Настройки**.

## Вкладки настроек

| Вкладка | Описание |
| --- | --- |
| [Варианты доставки](settings/deliveries) | Настройка методов доставки, стоимости, валидации |
| [Способы оплаты](settings/payments) | Настройка платёжных систем |
| [Статусы заказа](settings/statuses) | Этапы заказа, флаги `final` и `fixed`, порядок переходов |
| [Производители товаров](settings/vendors) | Справочник производителей товаров |
| [Связи товаров](settings/links) | Типы связей между товарами |
| [Опции](settings/options) | EAV-система дополнительных характеристик |

## Интерфейс

Страница открывается на нужной вкладке по хешу в адресе: `#tab-deliveries`, `#tab-payments`, `#tab-statuses`, `#tab-vendors`, `#tab-links`, `#tab-options`. Хеш синхронизируется при переключении, так что ссылку на вкладку можно просто скопировать из адресной строки.

В шапке страницы есть кнопки перехода в «Заказы» и «Утилиты». Они показываются только пользователям с правом `msorder_list`.

- **Создание.** Нажмите **Создать**: откроется форма с полями выбранного типа записи.
- **Редактирование.** Нажмите иконку карандаша в колонке действий — страница не перезагружается. Двойной клик по строке работает только на вкладке «Опции»; отдельной кнопки «Редактировать» в тулбаре нет.
- **Сортировка.** Перетащите запись в нужную позицию, порядок сохранится сам. Так работают доставки, оплаты, статусы, производители и группы опций; связи товаров не сортируются — у `msLink` нет колонки порядка, список всегда идёт по `id`.
- **Массовые операции.** Выделите несколько записей и удаляйте их разом; удаление потребует подтверждения.
- **Поиск и фильтры.** Доставки и оплаты фильтруются по названию и активности. Опции — по выбранным категориям и группе, группы опций фильтруются на стороне браузера. У статусов поиска нет. На вкладке производителей поля фильтра показаны, но ни на что не влияют: грид шлёт `filter_*`, а контроллер читает только параметр `query`.

::: info Права доступа
Весь `/api/mgr` закрыт сессией менеджера, а запись в справочниках доставок, оплат, статусов, производителей, связей, опций и групп опций дополнительно требует права `mssetting_save`. Привязка опций к категориям идёт по `mscategory_save`.
:::

::: warning Важно
Удаление способа доставки или оплаты может повлиять на существующие заказы. Вместо удаления деактивируйте неиспользуемые методы.
:::
