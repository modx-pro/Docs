# Настройки магазина

Откройте **Пакеты → MiniShop3 → Настройки**.

## Вкладки настроек

| Вкладка | Описание |
| --- | --- |
| [Варианты доставки](settings/deliveries) | Настройка методов доставки, стоимости, валидации |
| [Способы оплаты](settings/payments) | Настройка платёжных систем |
| Статусы заказа | `#tab-statuses` |
| [Производители товаров](settings/vendors) | Справочник производителей товаров |
| [Связи товаров](settings/links) | Типы связей между товарами |
| [Свойства товаров](settings/options) | EAV-система дополнительных характеристик |

## Интерфейс

- **Создание.** Нажмите **Добавить**: откроется форма с полями выбранного типа записи.
- **Редактирование.** Дважды кликните по записи в таблице или выберите её и нажмите **Редактировать** — страница не перезагружается.
- **Сортировка.** Перетащите запись в нужную позицию, порядок сохранится сам.
- **Массовые операции.** Выделите несколько записей и удаляйте их разом; удаление потребует подтверждения.
- **Поиск.** Идёт по названию и описанию.

::: warning Важно
Удаление способа доставки или оплаты может повлиять на существующие заказы. Вместо удаления деактивируйте неиспользуемые методы.
:::
