# Утилиты

Массовые операции и настройка MiniShop3.

## Доступ

**Меню:** Приложения → MiniShop3 → Утилиты

## Вкладки

| Вкладка | Описание |
| --- | --- |
| [Галерея](utilities/gallery) | Массовая перегенерация миниатюр изображений |
| [Импорт](utilities/import) | Импорт товаров из CSV-файлов |
| [Поля товара](utilities/product-fields) | Настройка отображения полей в карточке товара |
| [Дополнительные поля](utilities/extra-fields) | Создание новых полей для моделей |
| [Колонки гридов](utilities/grid-columns) | Настройка колонок в таблицах |
| [Поля модели](utilities/model-fields) | Управление полями моделей из БД |

Cookbook: [менеджер](/components/minishop3/manager/) — когда брать extra fields, product fields, model fields или grid columns.

## Обзор возможностей

### Галерея

Массовая перегенерация миниатюр. Нужна после смены настроек превью, миграции сайта или массового обновления изображений.

### Импорт

Пошаговый мастер CSV: автоопределение кодировки, сопоставление колонок, режим отладки первой строки, [Scheduler](/components/scheduler/) для больших файлов.

### Поля товара

Раскладка вкладки «Данные»: секции, visible, порядок. Новые колонки — через [Дополнительные поля](utilities/extra-fields). Cookbook: [поля товара](/components/minishop3/manager/product-fields/cookbook).

### Дополнительные поля

Новые поля для моделей:

- msProductData — товары
- msVendor — производители
- msOrder — заказы
- msOrderAddress — адреса
- msCategory — категории

### Колонки гридов

Видимость, сортировка, фильтрация, ширина и шаблоны колонок в таблицах менеджера.

### Поля модели

Настройки существующих полей: секции, виджеты (`xtype`).
