# Утилиты: Поля товара

Настройка полей на вкладке **Данные** в карточке товара.

::: tip Cookbook
Секции, скрытие полей, связь с дополнительными полями: [Cookbook полей товара](/components/minishop3/manager/product-fields/cookbook). Сквозной пример: [Оптовая цена](/components/minishop3/manager/examples/product-extra-field).
:::

## Назначение

Инструмент управляет **раскладкой** полей на вкладке «Данные»:

- видимость и порядок полей
- группы по секциям
- подписи и xtype виджетов

Новую колонку в `ms3_product_data` создают в [Дополнительных полях](/components/minishop3/interface/utilities/extra-fields). После создания дополнительного поля строка появляется здесь автоматически.

## Интерфейс

### Секции

Левая панель: список секций, сортировка перетаскиванием.

### Поля

Правая панель: поля выбранной секции.

**В строке:**

- Название поля (ключ)
- Подпись (label)
- Тип виджета (xtype)
- Статус видимости

## Управление секциями

### Создание секции

1. Нажмите кнопку **«Добавить секцию»**
2. Заполните форму:

| Поле | Описание | Обязательно |
| --- | --- | --- |
| Ключ секции | Уникальный идентификатор (латиница) | Да |
| Ключ лексикона | Ключ для перевода названия | Нет |
| Название | Отображаемое название | Нет |
| Скрыта | Секция не отображается в карточке | Нет |

::: tip Лексикон
Если указан ключ лексикона, название берётся из файлов локализации. Интерфейс переводится на разные языки.
:::

### Редактирование секции

Кликните иконку редактирования справа от названия или дважды кликните секцию.

### Удаление секции

::: warning Внимание
При удалении секции все её поля перемещаются в раздел «Без секции». Сами поля не удаляются.
:::

## Управление полями

### Редактирование поля

Кликните поле, откроется диалог редактирования.

**Доступные параметры:**

| Параметр | Описание |
| --- | --- |
| Название (label) | Отображаемое название поля |
| Placeholder | Подсказка внутри поля ввода |
| Описание | Подсказка под полем |
| Секция | К какой секции принадлежит поле |
| Тип виджета (xtype) | Только при создании — в диалоге редактирования поле заблокировано |
| Видимость | Отображать ли поле в карточке |
| Ширина | Колонки сетки: 3, 4, 6, 8, 12 |

### Типы виджетов (xtype)

| Тип | Описание |
| --- | --- |
| `textfield` | Однострочное текстовое поле |
| `numberfield` | Числовое поле |
| `textarea` | Многострочное текстовое поле |
| `xcheckbox` | Флажок (чекбокс) |
| `ms3-combo-vendor` | Выбор производителя |
| `ms3-combo-autocomplete` | Автодополнение из списка |
| `ms3-combo-options` | Выбор из опций товара |

### Перемещение полей

Поля перемещаете так:

- **Внутри секции** — перетаскиванием вверх/вниз
- **Между секциями** — изменением секции в диалоге редактирования

## Стандартные секции

По умолчанию (сид `product_data`):

| Ключ | Название | Поля сида |
| --- | --- | --- |
| `main` | Основные данные | `article`, `weight`, `color`, `size`, `vendor_id`, `made_in` |
| `pricing` | Цены и склад | `price`, `old_price`, `stock` |
| `seo` | SEO | пустая секция — поля добавляете сами |
| `additional` | Дополнительно | `tags`, `new`, `favorite`, `popular` |

## Сохранение изменений

- Изменения сохраняются **автоматически** при перетаскивании
- При редактировании поля/секции нажмите **«Сохранить»**
- Для применения изменений в карточке товара **перезагрузите страницу**

## API-эндпоинты

### Получение конфигурации полей

```http
GET /api/mgr/config/page-fields/product_data
```

**Ответ:**

```json
{
  "success": true,
  "data": {
    "fields": [
      {
        "name": "article",
        "label": "Артикул",
        "xtype": "textfield",
        "section": 1,
        "visible": true,
        "sort_order": 0
      }
    ]
  }
}
```

### Получение секций

```http
GET /api/mgr/config/sections/product_data
```

### Сохранение конфигурации полей

```http
PUT /api/mgr/config/page-fields/product_data
```

Право записи: `mssetting_save`. Чтение (GET) доступно любой сессии менеджера без `mssetting_save`.

**Тело запроса** — массив **`fields`** (не одно поле):

```json
{
  "fields": [
    {
      "name": "article",
      "label": "Артикул товара",
      "section": 1,
      "visible": true,
      "sort_order": 0
    }
  ]
}
```

### Сохранение секций

Новую секцию интерфейс добавляет локально, затем сохраняет весь список:

```http
PUT /api/mgr/config/sections/product_data
```

```json
{
  "sections": [
    {
      "section_key": "custom",
      "lexicon_key": "ms3_section_custom",
      "label": "Дополнительно",
      "hidden": false,
      "sort_order": 100
    }
  ]
}
```

### Удаление секции

```http
DELETE /api/mgr/config/sections/product_data/{section_key}
```

Базовые секции удалить нельзя. `POST /config/sections/...` в 1.13.x нет.

## Примеры настройки

### Скрытие ненужных полей

Если цвет и размер задаёте опциями, снимите видимость у полей `color` и `size`.

### Создание секции «SEO»

Секция `seo` уже есть в сиде. Если удалили — добавьте снова (ключ `seo`). Поля вкладки «Документ» (`longtitle`, `description`) в `product_data` не входят: их видимость задаёт `ms3_product_main_fields`. В пустую SEO-секцию переносят свои поля из `main` / `additional` или дополнительные поля.
