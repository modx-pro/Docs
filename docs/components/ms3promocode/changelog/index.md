## ms3PromoCode 1.1.0-beta1

Минорный релиз.

### Ломающие изменения

- Минимальные версии: MiniShop3 ≥ 1.13.0-beta1, pdoTools ≥ 3.0.0, VueTools ≥ 1.2.0. Package Manager откажет на старых версиях.
- Vue-админка больше не прошивает тему — preset берётся из `vuetools.theme` (`aura` / `modx`). PrimeVue через Import Map, бандл ~1 МБ → ~65 КБ.

### Исправлено

- Двойная скидка при смене количества позиции и min_order от уже сниженной суммы.
- GetLog возвращал всегда пустой журнал (status → status_id).
- Статистика установки не отправлялась — резолвер был в репо, но не в сборке.
- JS API: `destroy()` не очищал подписки через `on()`; `remove()` / `validate()` молчали при не-success ответе.
- Диалог удаления кода теперь честно предупреждает про каскадное удаление истории применений.

### Безопасность

- CORS, rate limiting и `ServiceCheckMiddleware` привязаны к `/api/v1/promo/*`.

## ms3PromoCode 1.0.0-beta1

- Скидки в процентах и фиксированных суммах, на всю корзину или на подпадающие позиции.
- Учёт скидки в позициях заказа — корректные суммы в чеках 54-ФЗ, email и личном кабинете без правок шаблонов.
- Правила: товары, категории, бренды, универсальный фильтр по полям, фильтр по опциям.
- Админка Vue 3 + PrimeVue 4: список с фильтрами, редактор кода с тремя вкладками, аналитика.
- Вкладка «Промо-код» в карточке заказа с автопересчётом при изменении состава.
- SSR-форма для покупателя + headless JS API.
- Автоматический откат применения при отмене заказа.
