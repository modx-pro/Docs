# Аналитика

Раздел **Промо-коды → Аналитика** показывает агрегированные метрики и детальный журнал применений.

Сверху — панель фильтров и кнопка обновления. Под ней — две карточки с показателями. Ниже — таблица журнала.

![Страница Аналитика: фильтры по датам и переключатель «Показывать отменённые», карточки «Всего применений» и «Сумма выданных скидок», журнал применений WELCOME10 с красной меткой «Отменён»](/components/ms3promocode/screenshots/interface-analytics.jpg)

## KPI-карточки

Две карточки под панелью фильтров:

| Карточка                | Что показывает                                                  |
|-------------------------|-----------------------------------------------------------------|
| Всего применений        | Сколько раз промо-коды были применены к заказам                 |
| Сумма выданных скидок   | Сумма всех `discount_amount` из таблицы применений              |

KPI учитывают только активные применения в выбранном периоде. Флаг «Показывать отменённые» (см. ниже) влияет только на журнал, не на эти карточки.

## Фильтры

Панель фильтров — вверху страницы:

- **Период** — два поля даты (начало и конец), фильтр по `applied_at`. По умолчанию — последние 30 дней.
- **Показывать отменённые** — переключатель. По умолчанию выключен: журнал показывает только активные применения. Если включён — в выборку попадают и отменённые (с `cancelled_at IS NOT NULL`); на KPI-карточки это не влияет.
- **Обновить** — кнопка-иконка справа от переключателя. Повторно запрашивает KPI и журнал с теми же фильтрами.

## Журнал применений

Таблица с серверной пагинацией. Размеры страницы — `10 / 20 / 50 / 100`, по умолчанию 20.

Колонки:

| Колонка        | Источник данных                                                       |
|----------------|-----------------------------------------------------------------------|
| Дата           | `applied_at`                                                          |
| Код            | `code_value` (жирным) + `code_name` под ним серым, если задано        |
| Заказ          | `#` + `order_num` или `order_id`, если номер пуст — обычный текст, без ссылки |
| Клиент         | Имя (`first_name` + `last_name`) и e-mail покупателя под ним         |
| Сумма заказа   | `order_cost` (со скидкой)                                             |
| Скидка         | `discount_amount`                                                     |
| Отменён        | Прочерк `—` для активной записи или красная метка с датой `cancelled_at` |

## Сортировка

Сортируются только две колонки: «Дата» (`applied_at`) и «Код» (`code_value`).

## Откат применения

Записи в журнале — это снимки. Их нельзя редактировать вручную. Откат происходит автоматически:

- При переводе заказа в один из статусов `ms3promocode.cancel_statuses` запись помечается отменённой (проставляется `cancelled_at`), счётчик `used_count` уменьшается на 1.
- При обратном переходе запись восстанавливается, счётчик увеличивается на 1.

См. [Системные настройки → cancel_statuses](../settings#ms3promocode.cancel_statuses).

## Источники данных

- KPI и журнал работают с таблицей `ms3_promo_code_usages`.
- Структура таблицы — см. [Модели и БД](../development/models).
