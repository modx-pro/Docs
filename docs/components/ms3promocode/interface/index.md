# Интерфейс админки

Админка на Vue 3 + PrimeVue 4 состоит из трёх разделов:

| Раздел                                  | Описание                                                                |
|-----------------------------------------|-------------------------------------------------------------------------|
| [Управление кодами](codes)              | Список кодов, создание, редактирование, генерация по маске, фильтры     |
| [Аналитика](analytics)                  | KPI и журнал применений с фильтрами                                     |
| [Вкладка в заказе](order-tab)           | Применить / снять код у конкретного заказа из карточки заказа           |

## Где находится

В дереве меню MODX, в разделе **Компоненты**, появляется подраздел **Промо-коды** с двумя пунктами:

- **Управление кодами** — список кодов и редактор.
- **Аналитика** — KPI и журнал.

Третий — вкладка **«Промо-код»** в окне редактирования заказа MS3 (**Магазин → Заказы → конкретный заказ**).

## Особенности

- **Компоненты PrimeVue 4** — тема Aura (светлая), вёрстка под админку MODX.
- **Серверная пагинация и сортировка** — большие списки кодов и применений не тормозят.
- **Действия в строке** таблицы — включить/выключить, редактировать, удалить.
- **Двойной клик по строке** открывает редактор кода.
- **Подтверждения и уведомления** — удаление и снятие кода требуют подтверждения через `ConfirmDialog`, результат — toast-уведомления.

## Требования

Vue-админка требует [VueTools](/components/vuetools/). Без него на месте страницы Vue-модуля появится модальное окно MODX с ошибкой о недостающей зависимости.
