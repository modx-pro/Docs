# Сниппеты

ms3PromoCode предоставляет один сниппет — форму ввода промо-кода для покупателя.

| Сниппет                                  | Назначение                                    |
|------------------------------------------|-----------------------------------------------|
| [ms3PromoCodeForm](ms3promocodeform)     | Форма ввода/применения/снятия промо-кода      |

## Применение

В шаблоне страницы корзины:

```fenom
{'!ms3PromoCodeForm' | snippet}
```

У формы два состояния: «поле ввода» и «код применён». Если код уже применён к корзине, сервер сразу отдаёт состояние «применён» — форма не мигает при загрузке.

Логика формы (применить, снять, обработка ошибок) и стили подключаются плагином автоматически — через системную настройку `ms3promocode.frontend_assets_preset`.
