# FAQ

## Payment is not configured

Пустые Public ID или API Secret. Возьмите ключи сайта в [кабинете](https://merchant.cloudpayments.ru/). Виджетный Public ID `test_api_00000000000000000000001` для счетов не подходит.

Проверьте properties способа, затем системные настройки, затем кеш.

## Код 13 на Pay

Подпись не сошлась, тело пустое или сайт отвечает редиректом 301. Проверка подписи выключению не подлежит.

Подпись считается секретом API от сырого тела запроса и приходит в заголовке `X-Content-HMAC`. Адрес должен открываться по HTTPS без 301:

```text
https://ваш-домен.ru/assets/components/msp3cloudpayments/webhook.php?event=pay
```

## Check отвечает кодом 12

Сумма в уведомлении не совпала с суммой заказа MiniShop3. Код `10` значит, что попытка по `ms3_ref` не найдена. Пустое тело Check тоже отвечает `10`.

## Двухстадийный заказ не оплачен

Так и должно быть, пока холд не списан. После Pay со статусом Authorized в данных попытки должен появиться `TransactionId`. Спишите холд во вкладке (`payments/confirm`) или дождитесь уведомления Confirm. До этого возврат не уходит.
