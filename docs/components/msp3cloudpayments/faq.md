# FAQ

## Payment is not configured

Пустые Public ID или API Secret. Возьмите ключи сайта в [кабинете](https://merchant.cloudpayments.ru/). Виджетный Public ID `test_api_00000000000000000000001` для счетов не подходит.

Для счёта, вкладки и `webhook.php`: `properties` способа (`public_id` или `login`, секреты), затем `msp3cloudpayments_*`, затем `mspcloudpayments_*`. После смены настроек очистите кеш MODX.

## Код 13 на Pay

Подпись не сошлась или тело Pay пустое. Проверку подписи выключить нельзя.

На `webhook.php` секрет берётся по той же цепочке, что для счёта. Подпись считается от сырого тела и приходит в заголовке `X-Content-HMAC`. Адрес открывайте по HTTPS без редиректа 301, иначе уведомление может не дойти:

```text
https://ваш-домен.ru/assets/components/msp3cloudpayments/webhook.php?event=pay
```

## Check отвечает кодом 12

Сумма в уведомлении не совпала с суммой попытки оплаты, не с полем `cost` заказа. Код `10` значит, что попытка по `ms3_ref` не найдена. Пустое тело Check тоже отвечает `10`.

## Двухстадийный заказ не оплачен

Заказ не отмечен оплаченным, пока холд не списан. После Pay со статусом Authorized в данных попытки должен появиться `TransactionId`. Спишите холд во вкладке (`payments/confirm`) или дождитесь уведомления Confirm. До этого возврат не уходит.

## Частичный возврат

<!-- MEDIA: Скриншот процесса частичного возврата во вкладке заказа -->

Пакет поддерживает частичный возврат. В ответе на `payments/refund` статус может быть `PARTIALLY_REFUNDED`. В этом случае попытка остаётся в работе, остаток можно вернуть позже. Полный возврат меняет статус на `refunded`.
