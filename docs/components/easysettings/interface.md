# Интерфейс

## Разделы

Слева дерево в стиле MODX: пространства имён — папки, разделы — узлы, рядом число настроек. Клик открывает раздел как отдельную страницу со своим адресом, например `?a=system/settings&ns=core&area=site`. Работают «Назад» и «Вперёд» браузера, ссылку на раздел можно открыть в новой вкладке.

Страница при переходе не перезагружается, поэтому несохранённые изменения не теряются. Настройки раздела загружаются, когда вы в него переходите, так что страница открывается одинаково быстро на сайте с любым числом дополнений. Раскрытые папки и прокрутка дерева запоминаются.

## Поиск

Поле поиска ищет по названию, ключу, описанию и значению во всех пространствах имён сразу и подсвечивает совпадения. Находит и переводы из файлов лексикона, которые поиск ядра не видит.

Быстрый переход в поле поиска: `/` или `Ctrl+K`.

## Изменение значений

Каждая настройка — строка: слева название, описание и ключ, справа поле. Поле зависит от типа настройки:

| Тип | Поле |
| --- | --- |
| `combo-boolean` | переключатель Да/Нет |
| `numberfield` | число с проверкой |
| `text-password` | пароль с кнопкой «Показать» |
| `textfield`, `textarea` | текстовое поле, растёт вместе с текстом |
| JSON | моноширинное поле с проверкой |
| комбобоксы ядра | список с теми же вариантами: язык, контекст, шаблон, медиа-источник и другие |
| xtype дополнений | собственный компонент дополнения |

Текстовые настройки ядра с известным набором значений (`log_level`, `link_tag_scheme` и другие) показываются списком. Нестандартное значение при этом не теряется.

Клик по ключу копирует его.

## Сохранение

Изменённые строки отмечаются, а внизу появляется панель с числом изменений и кнопками «Сохранить» и «Отменить». Сохранить можно и сочетанием `Ctrl+S` — оно работает в любой раскладке.

Каждая настройка сохраняется процессором ядра, поэтому работает вся логика MODX: перезагрузка конфигурации, пересчёт URI при смене `friendly_urls`, проверка прав. Если одна настройка не сохранилась, остальные всё равно сохраняются, а у ошибочной появляется сообщение.

Уйти со страницы, пока изменения не сохранены, можно только после подтверждения.

## Создание, правка и удаление

Меню в конце строки: правка, копирование ключа, возврат сохранённого значения и удаление. В окне правки меняются тип поля, пространство имён, раздел, название, описание и значение. Название и описание записываются в лексикон языка менеджера, и только если их поменяли.

Новую настройку создаёт кнопка создания — окно то же, что при правке.

## События

Вкладка «События» показывает системные события по группам вместе с подписанными на них плагинами. Пользовательские события можно создавать и удалять. События ядра удалить нельзя — как и в штатной таблице.

## Классический вид

Кнопка «Классический вид» открывает штатную таблицу MODX. На ней рядом с кнопкой Help! появляется кнопка «Удобный вид», которая возвращает в EasySettings. Штатную таблицу открывает и адрес `?a=system/settings&classic=1`.

Выключить EasySettings совсем можно настройкой [`easysettings.enabled`](/components/easysettings/settings).
