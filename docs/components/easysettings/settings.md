# Настройки компонента

Пространство имён в MODX: `easysettings`.

## `easysettings.enabled`

- По умолчанию: `Да`

Показывать EasySettings вместо штатной таблицы «Системные настройки». Выключите, чтобы вернуть таблицу MODX целиком.

Разово открыть штатную таблицу можно и без этого: кнопкой «Классический вид» или по адресу `?a=system/settings&classic=1`.
