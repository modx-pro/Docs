# getTickets

Выводит список тикетов.

**Вызывайте некэшированным.** Счётчик комментариев в чанке может ссылаться на `#first_unread`.

## Параметры

| Название             | По умолчанию           | Описание                                                                                                                                                               |
|----------------------|------------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **&depth**           | `10`                   | Глубина поиска ресурсов от каждого родителя                                                                                                                           |
| **&fastMode**        | `0`                    | В чанк попадают только значения из БД. Сниппет вырезает необработанные теги MODX: фильтры, вызовы сниппетов                                                           |
| **&includeContent**  | `0`                    | Выбирать поле `content` у ресурсов                                                                                                                                    |
| **&includeTVs**      |                        | Список ТВ-параметров через запятую. Например, «action,time» даёт плейсхолдеры `[[+action]]` и `[[+time]]`                                                             |
| **&limit**           | `10`                   | Лимит выборки                                                                                                                                                        |
| **&offset**          | `0`                    | Пропуск результатов с начала выборки                                                                                                                                  |
| **&outputSeparator** | перенос строки         | Разделитель между строками                                                                                                                                            |
| **&parents**         |                        | Список ID родителей через запятую. По умолчанию выборка ограничена текущим родителем, при `0` ограничения нет                                                         |
| **&resources**       |                        | Список ID ресурсов через запятую. Отрицательный ID исключает ресурс из выборки                                                                                        |
| **&showDeleted**     | `0`                    | Показывать удалённые ресурсы                                                                                                                                          |
| **&showHidden**      | `1`                    | Показывать ресурсы, скрытые в меню                                                                                                                                    |
| **&showLog**         | `0`                    | Отладочный лог работы сниппета. Доступен только в сессии `mgr`                                                                                                        |
| **&showUnpublished** | `0`                    | Показывать неопубликованные ресурсы                                                                                                                                   |
| **&sortby**          | `createdon`            | Поле сортировки                                                                                                                                                       |
| **&sortdir**         | `DESC`                 | Направление сортировки                                                                                                                                                |
| **&toPlaceholder**   |                        | Если не пусто, сниппет сохраняет вывод в плейсхолдер с этим именем вместо печати на экран                                                                              |
| **&tpl**             | `tpl.Tickets.list.row` | Чанк оформления для каждого результата                                                                                                                                |
| **&tplWrapper**      |                        | Обёртка всего вывода с плейсхолдером `output`                                                                                                                         |
| **&wrapIfEmpty**     |                        | Выводить `&tplWrapper`, даже если результат пустой                                                                                                                     |
| **&tvPrefix**        |                        | Префикс для ТВ-плейсхолдеров, например «tv.»                                                                                                                          |
| **&user**            |                        | Выбрать только элементы, созданные этим пользователем                                                                                                                 |
| **&where**           |                        | Строка, закодированная в JSON, с дополнительными условиями выборки                                                                                                    |

## Примеры

### Список с пагинацией

::: code-group

```fenom
{'!pdoPage' | snippet : ['element' => 'getTickets']}
{$_modx->getPlaceholder('page.nav')}
```

```modx
[[!pdoPage?
  &element=`getTickets`
]]

[[!+page.nav]]
```

:::

### Тикеты раздела

::: code-group

```fenom
{'!getTickets' | snippet : [
  'parents' => $_modx->resource.id,
  'limit' => 10,
  'sortby' => 'createdon',
  'sortdir' => 'DESC',
]}
```

```modx
[[!getTickets?
  &parents=`[[*id]]`
  &limit=`10`
  &sortby=`createdon`
  &sortdir=`DESC`
]]
```

:::
