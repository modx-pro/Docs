# MODX3MCP

**MODX3MCP** — компонент для подключения внешних ИИ-агентов к **MODX Revolution 3.x** через **Model Context Protocol (MCP)**.

Он предоставляет агенту специализированный интерфейс для работы с ресурсами, шаблонами, чанками, сниппетами, TV-полями, системными настройками и другими сущностями MODX.

> [!WARNING]
> **MODX3MCP не является готовым ИИ-агентом и сам по себе не добавляет искусственный интеллект в MODX.**
>
> После установки компонента в менеджере MODX не появляется чат для постановки задач. ИИ-агент и пользовательский интерфейс настраиваются отдельно.

Общая схема работы:

```text
Пользователь → ИИ-агент → MODX3MCP → MODX
```

## Возможности

В версии **1.2.0** реализовано **192 операции**: 81 операция чтения и 111 изменяющих операций.

Поддерживается работа с:

- ресурсами и структурой сайта;
- шаблонами, чанками и сниппетами;
- плагинами;
- TV-полями;
- системными настройками;
- пользователями и группами;
- политиками доступа и шаблонами политик;
- группами ресурсов и их составом;
- источниками файлов;
- пакетами и дополнениями;
- настройками ClientConfig;
- MIGX;
- miniShop2;
- VersionX;
- VirtualPage.

MODX3MCP также позволяет анализировать связи между элементами сайта с помощью графа зависимостей.

В версии 1.2.0 добавлена защита от записи по устаревшему состоянию сайта. Агент может получить текущую ревизию проекта, а перед изменением MODX3MCP проверяет, что состояние не изменилось. Если данные уже были изменены другим агентом или процессом, операция отклоняется с ошибкой `STALE_STATE` вместо записи поверх более свежего состояния.

Часть потенциально опасных возможностей можно ограничивать или отключать настройками компонента.

## Установка

Рекомендуемый способ — установить **MODX3MCP** как обычное дополнение через менеджер пакетов MODX из репозитория **modstore.pro**.

Также транспортный пакет можно скачать вручную из [релизов проекта на GitHub](https://github.com/rumata-estor/modx3-mcp/releases).

Для MODX Revolution 3.x используется пакет:

```text
modx3mcp-1.2.0-pl.transport.zip
```

При первой установке компонент автоматически создаёт API-токен `modxmcp.api_token`, необходимый для доступа к MODX3MCP.

## Совместимость

- MODX Revolution 3.2 и новее;
- PHP 8.1 и новее.
