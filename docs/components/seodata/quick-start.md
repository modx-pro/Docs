# Быстрый старт

## Требования

| Требование | Версия |
| --- | --- |
| PHP | 8.1+ |
| MODX Revolution | 3.0+ |
| VueTools | 1.2.0+ |
| pdoTools | 3.x |
| MiniShop3 | нужен для товаров, категорий, опций и индекса цен |
| Браузер менеджера | Chrome 89+, Firefox 108+, Safari 16.4+, Edge 89+ |

Без MiniShop3 работают шаблоны документов и TV. Поля каталога и вкладка индексации каталога в этом случае недоступны.

Тема панели задаётся системной настройкой `vuetools.theme`. Для вида менеджера MODX поставьте `modx`.

## Установка

В **Приложения → Установщик** должен быть подключён провайдер modstore.pro.

1. Установите **VueTools** версии 1.2.0 или выше.
2. Установите **pdoTools** 3.x.
3. Для каталога установите **MiniShop3**.
4. Установите **SeoData**.
5. Очистите кэш MODX.
6. Откройте **Приложения → SeoData**.

::: warning
Без VueTools и pdoTools установщик SeoData остановится на зависимостях.
:::

Если пункта меню нет, создайте его в **Настройки → Меню**:

| Поле | Значение |
| --- | --- |
| Текст | `seodata` |
| Родитель | `components` |
| Пространство имён | `seodata` |
| Действие | `home` |

На сайте пункт отображается как SeoData.

Повторная установка обновляет меню, плагин, сниппет и события. Системные настройки не затираются.

## Как страница получает текст

Плагин SeoData на `OnLoadWebDocument` ищет правило и записывает результат в ресурс:

1. Активный персональный шаблон этого ресурса.
2. Если его нет — подходящий общий шаблон с наибольшим приоритетом.

Пустое условие общего правила значит «любой». Если заполнены и родитель, и шаблон MODX, должны совпасть оба. Флаг «Включая потомков» распространяет правило на вложенные ресурсы.

Плагин можно выключить и читать поля сниппетом.

## Сниппет

```fenom
{set $seodata = '!SeoData' | snippet}
<title>{$seodata['title']}</title>
<h1>{$seodata['pagetitle']}</h1>
<p>{$seodata['description']}</p>
```

Ключи массива: `title`, `pagetitle`, `description`, `content`, `image`.

`image` берётся из плейсхолдера `{$image}` и подходит для `og:image`. Сниппет не пишет поля в ресурс: это делает плагин.

Если сниппет вызван в базовом шаблоне, массив `$seodata` доступен во вложенных шаблонах и чанках Fenom.
