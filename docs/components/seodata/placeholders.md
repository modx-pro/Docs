# Плейсхолдеры

Шаблоны рендерит Fenom из pdoTools. Переменная пишется в фигурных скобках: `{$pagetitle}`.

Модификаторы регистра: `{$pagetitle|lc}` — строчными, `{$pagetitle|uc}` — с заглавной.

```fenom
Купить {$pagetitle.acc|lc} в «{$site_name}» от {$price.min} ₽
{if $page?} {$page}{/if}
{7 | resource : 'menutitle'}
{$param_event | resource : 'pagetitle'}
{'seoSuffix' | chunk}
{'!pdoField' | snippet}
```

Через Fenom доступны сниппеты, чанки и поля другого ресурса. Если плейсхолдер хранит id ресурса, пишите `{$param_event | resource : 'pagetitle'}`, а не только литерал `{39 | resource : 'pagetitle'}`.

```fenom
{$_modx->getChunk('seoSuffix')}
{$_modx->runSnippet('pdoField', ['id' => 7, 'field' => 'menutitle'])}
```

::: warning
Сниппеты и чанки выполняют код сайта. Ошибка Fenom пишется в журнал, а это поле остаётся пустым.
:::

## Страница

| Плейсхолдер | Значение |
| --- | --- |
| `{$pagetitle}` | Заголовок ресурса |
| `{$longtitle}` | Расширенный заголовок |
| `{$description}` | Описание |
| `{$introtext}` | Аннотация |
| `{$menutitle}` | Пункт меню |
| `{$alias}` | Псевдоним |
| `{$content}` | Контент |
| `{$parent.pagetitle}` | Заголовок родителя |
| `{$site_name}` | Имя сайта |
| `{$site_url}` | URL сайта |
| `{$page}` | Фрагмент номера страницы, если в URL есть `?page=N` |

## Товар MiniShop3

| Плейсхолдер | Значение |
| --- | --- |
| `{$price}` | Цена |
| `{$old_price}` | Старая цена |
| `{$article}` | Артикул, если поле подключено |
| `{$vendor.name}` | Производитель |
| `{$image}` | Картинка, её же сниппет отдаёт как `image` |

## Категория MiniShop3

После индексации на вкладке «Обслуживание»:

| Плейсхолдер | Значение |
| --- | --- |
| `{$price.min}` | Минимальная цена товаров |
| `{$price.max}` | Максимальная цена |
| `{$price.avg}` | Средняя цена |
| `{$count}` | Количество товаров |

## Опции

Несколько значений опции:

| Запись | Результат |
| --- | --- |
| `{$color}` | Первое значение |
| `{$color.joined}` | Все значения через запятую |
| `{$color.list}` | Массив |
| `{$color.gen}` | Первое значение в родительном падеже, если слово есть в словаре |

Свои поля с вкладки «Свои поля» доступны как `{$имя}`.
