# FAQ

## Установка падает с Package provider not found

Пакет платный. Добавьте провайдер [modstore.pro](https://modstore.pro/extras/) с URL `https://modstore.pro/extras/`, email и API-ключом из личного кабинета. Без него зашифрованный transport не установится. Шаги: [Быстрый старт](quick-start).

## Раздел менеджера не открывается / белый экран

Проверьте, что установлен **VueTools** ≥ 1.1.2-pl и у роли есть `msbundles_view`. Откройте `manager/?a=index&namespace=msbundles` и посмотрите ошибки в консоли браузера.

## Пункта меню нет

Чаще всего нет права `msbundles_view` или после установки не очистили кэш. Проверьте политику доступа и сбросьте кэш MODX.

## Карточка комплекта не появляется на товаре

Пройдите по списку:

1. В редакторе включён **Активен**.
2. Текущий товар входит в состав комплекта.
3. В шаблоне есть вызов:

```fenom
{'!msBundles' | snippet : ['product' => $_modx->resource.id]}
```

1. Если остаток по обязательной позиции нулевой, настройка `msbundles_stock_behavior` не стоит в `hide`.

## Кнопка «Добавить комплект» не работает

В `<head>` вызовите `msBundles.initialize`. Без CSS и JS кнопки с `data-msbundles-action="add-bundle"` остаются обычной разметкой.

## Toast есть, блок корзины на странице не обновляется

У `msCart` задайте `selector`, например `#ms-cart`. После добавления фронт запрашивает корзину заново и перерисовывает только зарегистрированные блоки. Без `selector` вы видите уведомление, а HTML на странице остаётся старым.

## В корзине нет бейджа «Комплект»

В чанке корзины под названием товара вызовите `tplMsBundlesCartInfo`. Без хука бейдж и кнопка «Удалить комплект» не появятся. Пример: [Вывод на сайте](frontend#хук-в-tplmscart).

## Нельзя сохранить комплект

В составе нет ни одной строки. Добавьте товары. Для сохранения нужно право `msbundles_save`.

## Комплект пропал с витрины при нулевом остатке

Скорее всего `msbundles_stock_behavior` = `hide`. Поставьте `block` или `message`, либо пополните склад по обязательным позициям.

## После обновления пакета в старых заказах в корзине нет подписей комплекта

У плагина **msBundles** должно быть событие `msOnGetCart`. Откройте **Элементы → Плагины → msBundles → Системные события** и убедитесь, что галочка стоит. Плагин дополняет старые строки данными для бейджа, ключ товара в корзине при этом не меняется.
