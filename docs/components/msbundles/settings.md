# Системные настройки

Откройте **Система → Системные настройки** и выберите namespace `msbundles`.

## Ключи

| Ключ | Тип | По умолчанию | Описание |
| --- | --- | --- | --- |
| `msbundles_stock_behavior` | textfield | `block` | Как витрина ведёт себя, когда обязательной позиции не хватает на складе |
| `msbundles_max_bundle_quantity` | numberfield | `99` | Максимум комплектов в поле количества на карточке и в запросе добавления в корзину |

### Когда какой `stock_behavior`

| Значение | Когда ставить | Что видит покупатель |
| --- | --- | --- |
| `block` | Нужно показать предложение, но не дать оформить без склада | Карточка есть, кнопка «Добавить» неактивна |
| `message` | Хотите объяснить причину текстом | Карточка есть, под ней `stock_message` |
| `hide` | Пустые комплекты лучше совсем не показывать | Сниппет не выводит карточку |

Необязательные позиции при нулевом остатке в расчёт доступности не ломают весь комплект. При добавлении такая строка просто пропускается. В ответе API могут появиться `warnings`.

`msbundles_max_bundle_quantity` режет и поле на карточке, и серверный лимит. Если покупатель пытается взять больше, запрос add не пройдёт.

## Права доступа

| Право | Что открывает |
| --- | --- |
| `msbundles_view` | Пункт меню, список, просмотр комплектов |
| `msbundles_save` | Создание, правка, удаление, копирование, смена порядка |

Без `msbundles_view` пункта **msBundles** в меню не будет.

После установки пакета откройте политику доступа менеджера и отметьте оба права. Затем очистите кэш MODX.
