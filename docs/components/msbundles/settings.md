# Системные настройки

## Ключи

| Ключ | Тип | По умолчанию | Описание |
| --- | --- | --- | --- |
| `msbundles_stock_behavior` | textfield | `block` | Поведение при нехватке обязательной позиции |
| `msbundles_max_bundle_quantity` | numberfield | `99` | Максимум комплектов за одну операцию добавления |

### `stock_behavior`

| Значение | Поведение |
| --- | --- |
| `block` | Карточка есть, кнопка неактивна |
| `message` | Карточка есть, выводится `stock_message` |
| `hide` | Карточка не выводится |

Необязательные позиции при нулевом остатке пропускаются. В API могут быть `warnings`.

`msbundles_max_bundle_quantity` ограничивает поле и серверный лимит. Превышение блокирует add.

## Права доступа

| Право | Доступ |
| --- | --- |
| `msbundles_view` | Раздел, список, просмотр |
| `msbundles_save` | Создание, правка, удаление, копирование, смена порядка |

Без `msbundles_view` пункта **msBundles** в меню не будет. Включите оба права в политике менеджера и очистите кэш.
