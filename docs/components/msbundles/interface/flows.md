# Сценарии

Пять коротких сценариев для менеджера и витрины. Если пакет ещё не ставили, начните с [быстрого старта](/components/msbundles/quick-start).

| Flow | Сценарий |
| --- | --- |
| A | Создать комплект и вывести на товар |
| B | Настроить режимы цены и необязательную позицию |
| C | Скопировать комплект |
| D | Проверить остатки и превью |
| E | Добавить в корзину и удалить комплект |

## Flow A. Создать комплект и вывести на товар

1. Откройте **Компоненты → msBundles** (`manager/?a=index&namespace=msbundles`).
2. Нажмите **Добавить комплект**.
3. Заполните название, описание, картинку. Включите **Активен**.
4. Через поиск добавьте ≥ 2 товара. Для каждой строки задайте количество и режим цены.
5. Сохраните.
6. На странице товара в шаблоне вызовите сниппет:

::: code-group

```fenom
{'!msBundles' | snippet : [
  'product' => $_modx->resource.id,
  'tpl' => 'tplMsBundlesItem',
  'wrapperTpl' => 'tplMsBundlesList'
]}
```

```modx
[[!msBundles?
  &product=`[[*id]]`
  &tpl=`tplMsBundlesItem`
  &wrapperTpl=`tplMsBundlesList`
]]
```

:::

1. Подключите CSS/JS через `msBundles.initialize` и вызовите `msCart` с `selector`. См. [Витрина](/components/msbundles/frontend).

![Список комплектов](/components/msbundles/screenshots/overview.png)

Комплект появится на страницах **всех** товаров из состава.

## Flow B. Режимы цены и необязательная позиция

1. Откройте комплект кликом по названию в списке.
2. Для строки выберите режим:

| Режим | Значение | Результат |
| --- | --- | --- |
| Оригинал | — | Цена miniShop3 |
| Фикс | сумма | Цена за единицу |
| Скидка % | 0–100 | Процент от цены товара |
| Скидка суммой | сумма | Вычитается из цены |
| Бесплатно | — | 0 |

1. Снимите **Обяз.** у позиции, которую покупатель может «потерять» при нехватке остатка. При add такая строка уйдёт в `warnings`, остальной комплект добавится.
2. В футере редактора смотрите **Итого** и **Экономия**. Справа блок **Как на витрине**.

## Flow C. Скопировать комплект

1. В строке списка нажмите иконку копирования.
2. Откроется редактор копии: неактивна, то же имя с суффиксом копии, тот же состав и картинка.
3. Поправьте название, включите **Активен**, сохраните.

Нужно право `msbundles_save`.

## Flow D. Остатки и превью

1. В редакторе меняйте состав. Превью обновляется при каждом изменении.
2. Если обязательной позиции нет на складе, над формой появится предупреждение. Статус зависит от `msbundles_stock_behavior`.
3. При сохранении с проблемами по остаткам менеджер запросит подтверждение.

Настройка: [Системные настройки](/components/msbundles/settings) (`block` / `message` / `hide`).

## Flow E. Добавить в корзину и удалить комплект

1. На витрине задайте количество на карточке и нажмите «Добавить комплект».
2. Проверьте, что `msCart` вызван с `selector` и в шаблоне корзины есть `tplMsBundlesCartInfo`. Без этого toast появится, а блок на странице не обновится.
3. В таблице корзины:
   - у главной строки бейдж «Комплект», название набора и кнопка «Удалить комплект»
   - у остальных позиций текст «Входит в комплект…», количество менять нельзя, крестик поштучного удаления скрыт
   - блок комплекта (`[data-msbundles="cart-info"]`) рисует бейдж и кнопку удаления
4. Смените количество у главной строки. Остальные позиции комплекта подстроятся сами.
5. Удалите любую строку комплекта или нажмите «Удалить комплект». Уйдёт весь набор. По умолчанию без `confirm()`, как у обычного товара miniShop3. Диалог включается через `confirmRemoveBundle: true`.

Полный разбор чанков и CSS: [Вывод на сайте](/components/msbundles/frontend).
