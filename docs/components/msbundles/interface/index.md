# Обзор менеджера

Раздел **Компоненты → msBundles** (Vue 3 + PrimeVue через VueTools).

![Список комплектов](/components/msbundles/screenshots/overview.png)

Сценарии: [Сценарии](flows).

## Экран списка

Панель: поиск, фильтр активности, фильтр **контекста**, счётчик, **Добавить комплект**.

Таблица: порядок, название с картинкой, **контекст**, статус, число товаров, действия.

![Фильтр списка](/components/msbundles/screenshots/list-filter.png)

| Действие | Как сделать |
| --- | --- |
| Открыть редактор | Клик по названию |
| Скопировать | Иконка копирования |
| Удалить | Иконка корзины |

Поиск с задержкой. Пустой список — экран с кнопкой создания.

## Создание и правка

1. Нажмите **Добавить комплект** или кликните по названию.
2. Выберите **Контекст** (обязательно). Комплект виден только в этом контексте. У **активного** комплекта поле заблокировано: выключите **Активен** и сохраните.
3. Заполните **Название** (обязательно). Описание и изображение — по желанию.
4. Включите **Активен**.
5. Добавьте товары поиском (название, артикул, ID). Поиск только по **выбранному контексту**.
6. Для строки: количество, режим цены, **Обяз.**
7. Порядок — перетаскиванием.
8. **Сохранить**. Без товаров кнопка недоступна.

![Редактор](/components/msbundles/screenshots/editor.png)

Карточка появится на страницах всех товаров состава **в контексте**. Для другого языка: копия → смена контекста и состава.

Итог и экономия в футере. При нехватке обязательной позиции — предупреждение. При сохранении в такой ситуации менеджер попросит подтверждение.

## Режимы цены строки

| Режим | Значение | Результат |
| --- | --- | --- |
| Оригинал | — | Цена из miniShop3 |
| Фикс | сумма | Фиксированная цена |
| Скидка % | 0–100 | Процент от цены |
| Скидка суммой | сумма | Вычитается из цены |
| Бесплатно | — | 0 |

Итог = сумма строк × количество. **Экономия** = разница с обычными ценами. Нулевая цена — «Бесплатно».

## Обязательные и необязательные товары

**Обязательная** позиция нужна для доступности: при нехватке срабатывает `msbundles_stock_behavior`.

**Необязательную** позицию при нехватке комплект пропускает. В API могут быть `warnings`.

## Права

| Операция | Право |
| --- | --- |
| Раздел, список, просмотр | `msbundles_view` |
| Создание, правка, удаление, копирование, порядок | `msbundles_save` |

## Комплект в корзине

Плагин `msBundles`:

- при смене количества одной позиции остальные с `bundle_hash` подстраиваются
- при удалении одной позиции уходит весь комплект
- при отдаче корзины добавляет данные для бейджа

Количество в строке должно быть кратно базовому из комплекта.

На витрине: `msBundles.initialize` и `tplMsBundlesCartInfo` в чанке. У главной строки бейдж и «Удалить комплект», у остальных количество заблокировано. У `msCart` нужен `selector`. Подробности: [Вывод на сайте](/components/msbundles/frontend).
