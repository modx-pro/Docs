# Быстрый старт

Установка пакета, первый комплект, вывод на карточку, проверка корзины.

## Требования

MODX 3, miniShop3, VueTools, pdoTools, PHP 8.2+. Права `msbundles_view` и `msbundles_save` включаются на шаге 4.

## Установка

Пакет платный, провайдер [modstore.pro](https://modstore.pro/extras/). Без провайдера установка падает с `Package provider not found`.

1. **Система → Управление пакетами → Провайдеры** — добавьте **modstore.pro**:
   - URL: `https://modstore.pro/extras/`
   - Email и API-ключ из modstore.pro
2. Установите **msBundles**.
3. Очистите кэш MODX.
4. В политике менеджера включите `msbundles_view` и `msbundles_save`.
5. Откройте **Компоненты → msBundles**.

Пакет создаёт таблицы, права, события, маршруты API и привязывает плагин к корзине miniShop3.

## Шаг 1. Создайте комплект

![Список комплектов](/components/msbundles/screenshots/overview.png)

1. Нажмите **Добавить комплект**.
2. Выберите **Контекст** (по умолчанию `web`), введите название. Заполните описание и картинку по желанию.
3. Включите **Активен**. Пока переключатель выключен, витрина комплект не покажет.

![Редактор комплекта](/components/msbundles/screenshots/editor.png)

## Шаг 2. Добавьте товары и цены

В поиске: название, артикул или ID товара. Один товар дважды в комплект не попадёт. Для примера добавьте две позиции.

Для строки: количество, режим цены, **Обяз.** Порядок меняйте перетаскиванием.

| Режим | Значение | Результат |
| --- | --- | --- |
| Оригинал | — | Цена из miniShop3 |
| Фикс | сумма | Фиксированная цена |
| Скидка % | 0–100 | Процент от цены |
| Скидка суммой | сумма | Вычитается из цены |
| Бесплатно | — | 0 |

Итог и **Экономия** в футере редактора.

## Шаг 3. Проверьте превью и сохраните

![Превью «Как на витрине»](/components/msbundles/screenshots/editor-preview.png)

Справа: **Сводка** и **Как на витрине** (цена, экономия, доступность).

При нехватке обязательного товара появится предупреждение. **Сохранить** недоступно без товаров в составе.

## Шаг 4. Выведите на витрину

В шаблоне товара:

::: code-group

```fenom
{'!msBundles' | snippet : [
  'product' => $_modx->resource.id,
  'tpl' => 'tplMsBundlesItem',
  'wrapperTpl' => 'tplMsBundlesList',
  'emptyTpl' => 'tplMsBundlesEmpty',
  'activeOnly' => true
]}
```

```modx
[[!msBundles?
  &product=`[[*id]]`
  &tpl=`tplMsBundlesItem`
  &wrapperTpl=`tplMsBundlesList`
  &emptyTpl=`tplMsBundlesEmpty`
  &activeOnly=`1`
]]
```

:::

В `<head>`:

::: code-group

```fenom
{'!msBundles.initialize' | snippet}
```

```modx
[[!msBundles.initialize]]
```

:::

Откройте товар из состава: карточка комплекта должна появиться.

## Шаг 5. Проверьте корзину

<!-- MEDIA: Корзина с комплектом — главная строка с бейджем «Комплект» и кнопкой «Удалить комплект», вложенные строки с подписью «Входит в комплект…» -->

В корзине:

- главная строка: бейдж «Комплект», кнопка «Удалить комплект»
- остальные: «Входит в комплект…», количество заблокировано
- смена количества у главной строки меняет остальные

У `msCart` укажите `selector`. В чанке: `tplMsBundlesCartInfo`. Разбор: [Вывод на сайте](frontend).

::: code-group

```fenom
{'!msCart' | snippet : [
  'tpl' => 'tpl.msCart',
  'return' => 'tpl',
  'selector' => '#ms-cart'
]}
```

```modx
[[!msCart?
  &tpl=`tpl.msCart`
  &return=`tpl`
  &selector=`#ms-cart`
]]
```

:::

## Если что-то не работает

| Проблема | Что проверить |
| --- | --- |
| Раздел не открывается | VueTools, `msbundles_view` |
| Карточки нет | **Активен**, вызов `msBundles` |
| Кнопка молчит | `msBundles.initialize` в head |
| Корзина не обновляется | `selector` у `msCart` |
| Нет бейджа | `tplMsBundlesCartInfo` в чанке |
