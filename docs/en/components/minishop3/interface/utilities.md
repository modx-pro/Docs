# Utilities

Open **Extras → MiniShop3 → Utilities**.

## Tabs

| Tab | Description |
| --- | --- |
| [Gallery](utilities/gallery) | Thumbnail regeneration after preview setting changes, a site migration, or a bulk image update |
| [Import](utilities/import) | CSV wizard: encoding detection, column mapping, first-row debug mode, [Scheduler](/en/components/scheduler/) for large files |
| [Product fields](utilities/product-fields) | Layout of the product properties tab: sections, visibility, order. New columns go through [Extra fields](utilities/extra-fields) |
| [Extra fields](utilities/extra-fields) | New fields on `msProductData`, `msVendor`, `msOrder` and `msOrderAddress` |
| [Grid columns](utilities/grid-columns) | Visibility, sorting, filtering, width, and templates of columns in manager tables |
| [Model fields](utilities/model-fields) | Setup of existing fields: sections and widgets (`xtype`) |

Cookbook: [manager](/en/components/minishop3/manager/) explains when to use extra fields, product fields, model fields, or grid columns. Step-by-step product field scenarios: [Product fields cookbook](/en/components/minishop3/manager/product-fields/cookbook).
