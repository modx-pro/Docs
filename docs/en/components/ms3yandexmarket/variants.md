# Варианты и остатки

На вкладке **Предложения** задайте **Источник предложений** и **Источник остатков**.

Таблица под деревом тегов показывает цену, остаток, подпись источника остатка, URL и артикул. Предпросмотр одного `offer` берёт **ID товара** и **ID варианта** над таблицей.

## Источник предложений

![Вкладка «Предложения» ms3YandexMarket](/components/ms3yandexmarket/screenshots/variants.png)

| Значение | Что попадает в файл |
| --- | --- |
| `product` | Один `offer` на товар MiniShop3 |
| `variant` | Один `offer` на вариант [ms3Variants](/components/ms3variants/). Цена, артикул и картинка берутся у варианта. В файл попадает адрес товара и параметр `variant` с id варианта. Нет вариантов: товар в прайс не попадает |
| `combination` | Комбинации [ms3Remains](/components/ms3remains/) без варианта: непустые опции. Нет таких комбинаций: товар в прайс не попадает |
| `automatic` | Сначала варианты, иначе комбинации, иначе один `offer` товара |

## Источник остатков

| Значение | Откуда число |
| --- | --- |
| `minishop3` | Поле остатка товара MiniShop3 |
| `ms3variants` | Остаток варианта |
| `ms3remains` | `RemainServiceInterface::getQuantity`. Нет строки остатка и нет identity: в файл уходит пусто. `getQuantity` вернул `null`: в файл тоже уходит пусто. Число `0` пишется, только если сервис вернул `0` |
| `automatic` | Сначала остаток ms3Remains, если товар им учитывается, иначе вариант, иначе остаток товара |
| `custom` | Пункт «Свой источник» в списке формы. Число считается тем же порядком, что `automatic`. Подпись рядом с остатком в таблице равна `custom`, не `ms3remains` / `ms3variants` / `minishop3` |

- Значения `ms3remains`, `ms3variants` и `minishop3` не берут другие источники
- Нет пакета вариантов или остатков: это видно на [диагностике](/components/ms3yandexmarket/logs)
- Остаток товара MiniShop3 всё равно читается

| Поведение | Что происходит |
| --- | --- |
| `out` (старое имя `include`) | Пустой остаток даёт в RSS `g:availability` со значением `in stock`. Ноль даёт `out of stock`, если он не выше `min_stock` |
| `skip` | Порог `min_stock` убирает предложение и из YML дерева, и из RSS |
