# Ready-made scenarios

Solutions for tasks that come up on almost every site. The code can be taken as it is: most examples are set up with attributes in the form markup and need no change to the script for each new form.

## On the page

- [Submit indicator](/en/components/fetchit/examples/scenarios/loading) — a spinner or "Sending…" on the button
- [Thank-you instead of the form](/en/components/fetchit/examples/scenarios/thank-you) — a "Thank you" block in place of the sent form
- [Redirect to another page](/en/components/fetchit/examples/scenarios/redirect) — a redirect after a success
- [Phone mask](/en/components/fetchit/examples/scenarios/phone-mask) — entering a number by a pattern
- [File uploads](/en/components/fetchit/examples/scenarios/files) — checking the size and type before sending
- [Several forms on a page](/en/components/fetchit/examples/scenarios/multiple-forms) — different behaviour for different forms

## Analytics and integrations

- [Goals in Yandex Metrica and Google Analytics](/en/components/fetchit/examples/scenarios/analytics) — Yandex Metrica, GA4, Google Tag Manager, VK Ads
- [Requests to Telegram](/en/components/fetchit/examples/scenarios/telegram) — a FormIt hook that sends requests to a chat

Modals, notifications and client-side field checks are in the neighbouring sections: [modal dialogs](/en/components/fetchit/examples/modals/), [notifications](/en/components/fetchit/examples/notifications/), [validation](/en/components/fetchit/examples/validation/).
