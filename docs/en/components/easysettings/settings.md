# Component settings

MODX namespace: `easysettings`.

## `easysettings.enabled`

- Default: `Yes`

Show EasySettings instead of the standard System Settings grid. Turn it off to bring the MODX grid back for good.

To open the standard grid once, you do not need it: use the Classic view button or the address `?a=system/settings&classic=1`.
